# PR-A06 입력 예시와 등록 상태 안내

버전: v1.0 · 2026-09-16 · 상태: 사용성 개선 제안 · 분류: should-fix · 의존: A03

상위: [검수 결과](../K-DOG_검수결과_v1.0_20260916.md) U03·U04. 목표는 운영자가 내부 필드명이나 문서를 외우지 않고 무엇을 넣을지 판단하는 것이다.

## 근거

`Importer.tsx:24~29`는 참가자 파일에도 설문 설명을 노출하고, CSV에도 Excel 시트명을 묻는다. 41행의 설문 열 연결은 문항 내용 없이 s01 같은 코드만 보인다. `ParticipantFields.tsx:8~20`은 ID/순번·나이·예약 시각의 필수 여부와 빈칸 의미를 충분히 설명하지 않는다.

`Survey.tsx:46`은 NA 포함 등록 완료를 「일부 미응답」이라고 표현한다. `Intake.tsx:22`의 완료는 영상 존재+설문 28개 처리만 뜻하지만 라벨은 「자료 등록 완료」다. `Intake.tsx:62` 새 등록 폼은 값 입력 후 메뉴를 바꾸면 경고 없이 사라진다.

## 입력 안내 제안

| 입력/옵션 | 보일 설명·예시 | 빈칸·선택 처리 |
| --- | --- | --- |
| 행사 ID | 「같은 행사 참가자에게 동일한 값을 넣습니다. 예: KDOG-2026. 영문·숫자·밑줄·하이픈」 | 필수. 자동 생성·추측하지 않음 |
| 참가자 ID | 「설문 파일과 연결하는 번호입니다. 예: 0001. Excel은 텍스트로 입력」 | 필수. 앞자리 0 보존 |
| 순번 | 「행사 안에서 중복되지 않는 진행 순서. 예: 1」 | 선택. 비우면 미지정; ID와 다름 |
| 반려견 나이 | 「정수 세 단위, 현재 허용 0~30」 | 선택. 모르면 빈칸. 개월→세 자동 변환 금지 |
| 함께 산 기간 | 「예: 3년, 8개월」 | 선택. 자유 문구 |
| 동의 확인 | 「동의서에서 촬영 영상·설문 사용 동의를 확인한 경우 표시」 | 미선택=미확인. 동의를 추정하지 않음 |
| 참가자 파일 동의 열 | 「확인 예시: 예 또는 1. 미확인은 빈칸」 | 오탈자 등 알 수 없는 값은 행 오류로 알리는 방식을 권장; 임의 true 변환 금지 |
| 예약 시각 | 「예: 2026-10-31 09:30, 행사 현지 시각」 | 선택. 파일 양식의 실제 허용 형식과 일치시킬 것 |
| 설문 응답 | 「1~5, 빈칸은 미응답. 7~9번만 NA=해당 없음」 | 해당 없음과 0을 혼동하지 않음 |
| Excel 시트 | 파일에서 읽은 시트 이름을 선택. 사용 중인 시트 표시 | XLSX에서만 노출. 임의 시트 자동 전환 금지 |
| 설문 열 연결 | 「1번 · 무언가를 가르칠 때 단계적으로 시도한다」 등 카탈로그 문구 | s01은 보조 정보. 미연결 열 수를 표시 |

양식은 필수/선택, 허용값, 예시, 비우면 어떻게 되는지의 네 정보를 가까이 제공한다. 도움말만 추가하면서 실제 검증은 다르게 두지 않는다. 표준 양식의 survey_version은 사람이 문자열을 72행 복사하지 않도록 내려받은 양식 또는 안내 도구에서 명확히 제공하되, 응답 행을 자동 생성해 저장하지 않는다. 예시 행이 실제 자료로 수입되지 않게 입력 시트와 설명을 구분한다.

## 상태와 입력 보호

- 설문 등록 상태는 원응답 수+해당 없음 수로 표시한다. 예: 「등록 28/28 · 응답 25 · 해당 없음 3 · 미응답 0」. 계산 결과의 partial은 그대로 두고 「A 영역은 해당 없음 3개를 제외하고 계산」처럼 설명한다. 점수나 총점을 새로 노출하지 않는다.
- 접수의 기존 완료 필터는 「설문·영상 등록됨」처럼 실제 조건으로 이름을 바꾼다. 동의 확인·구간 확정은 별도 표시한다. 아직 합의되지 않은 동의 기반 자동 차단 규칙을 추가하지 않는다.
- 새 참가자 등록 폼에 기존 `useUnsaved` 패턴을 적용한다. 이동 취소 시 입력 유지, 저장 성공 시 경고 해제. 자동 임시 저장은 하지 않는다.
- 오류는 「몇 행·어느 칸·허용값·다음 행동」을 보여준다. 서버 원문 오류나 s코드만 보여주지 않는다. 기존 입력값은 유지한다.

## 범위와 완료 조건

`ParticipantFields.tsx`, `Importer.tsx`, `Intake.tsx`, `Survey.tsx`, 필요한 가져오기 템플릿/열 조회 API 및 해당 시험만 변경한다. A03의 정확한 필수 열 검증을 재사용한다.

1. 참가자 CSV·설문 CSV·다중 시트 XLSX에서 해당 형식에 맞는 옵션만 보인다.
2. NA 3개인 완료 설문과 실제 빈칸 3개인 설문이 서로 다르게 안내된다. 계산값·원응답은 바뀌지 않는다.
3. 신규 접수 입력 후 메뉴 이동 취소/허용, 정상 저장, 오류 재입력을 e2e로 확인한다.
4. 설명서 없이 양식 다운로드→필수값 입력→미리보기→오류 수정→저장→현황 확인 흐름을 합성 자료로 완료한다.
5. 빌드·관련 백엔드 시험·전체 e2e 통과, PR에 입력 안내 화면 첨부.
