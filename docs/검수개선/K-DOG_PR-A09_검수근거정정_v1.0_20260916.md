# PR-A09 계산 검수 근거와 인계 문서 정정

버전: v1.0 · 2026-09-16 · 상태: 문서·시험 개선 제안 · 분류: should-fix · 독립 PR

상위: [검수 결과](../K-DOG_검수결과_v1.0_20260916.md) D01. 고객 문서·워크북 원본은 읽기만 하며 이 PR에서 계산 규칙을 바꾸지 않는다.

## 원본으로 확인한 불일치

| 위치 | 현재 설명 | 실제 근거 | 정정 방향 |
| --- | --- | --- | --- |
| `docs/K-DOG_P0_구현계획_v1.0_20260916.md:93`, 검수 인계 `:66` | R5·R6은 6쌍에서 발동하지 않음 | 05 `3_보호자행동!K13=3`. `test_scoring_golden.py:38` 이후 두 번째 쌍의 동조율 invalid, SYN 제외 3개를 기대 | R5는 실제 입력에서 발동한다고 정정. R5/R6과 각 출력의 차이를 개별 설명 |

03의 Z6은 다음 구조다.

```text
IF(동조 국면 수가 빈칸, 빈칸,
   IF(걷기 유효성=3, 무효, 동조 국면 수/6))
```

현재 프로그램은 걷기 유효성=3이면 국면 수가 없어도 invalid다. 이는 숫자 오차가 아니라 결측/무효 상태의 우선순위다. 05 두 번째 쌍은 K13=3이고 국면 수 K25는 빈칸이므로, 그 입력을 03 Z6 구조에 대입하면 빈칸인 반면 현재 골든 기대는 invalid다. 기존 R5 질문에 이 경우를 포함하여 확인해야 한다. 이번 검수에서는 어느 해석이 더 타당한지 결정하지 않는다.

## 변경 범위

- P0 계획·검수 인계·채점규칙 확인 요청에서 잘못된 사실만 수정한다. 역사적 문서는 당시 계획과 현재 구현을 구분해 표시한다.
- 골든 시험 설명에 「원본 수식과 일치하는 값」「라벨/문서 해석으로 달리 정한 상태」를 나누어 적는다. 수식 재계산 결과를 확보하지 않았으면 Excel 실행 검증이라고 부르지 않는다.
- 테스트 기대값의 출처를 03 수식 셀·05 입력 셀·적용된 해석 번호로 남긴다. 코드의 계산 결과를 복사해 독립 기대값이라고 하지 않는다.
- 최소 합성 표: 국면 수 있음/없음 × 시행 유효성 1/2/3/미판독. 현재 결정과 고객 회신 후 바뀔 행을 명확히 한다. 회신 전에 계산·기대값을 임의 변경하지 않는다.
- R5·R6의 3점 라벨 셀도 다시 대조한다. 점수 헤더가 C=1, D=2, E=3이므로 기존 C12/C13 표기는 3점 설명의 정확한 위치가 아니다. 정본의 실제 E12/E13을 확인해 근거 표기를 맞춘다.
- `AGENTS.md` 첫 단락의 「현재 55항목 구현」 표현은 현재 P0·P1 완료 및 남은 legacy 모듈 설명으로 갱신한다. P1 §0의 동결 설명은 PR-5 당시 경과임을 명시하고 현재 라우트 제거와 구분한다.
