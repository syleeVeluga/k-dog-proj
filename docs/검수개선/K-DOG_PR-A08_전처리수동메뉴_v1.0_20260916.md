# PR-A08 전처리 수동 실행 메뉴와 운영 절차

버전: v1.0 · 2026-09-16 · 상태: 구현 제안 · 분류: bug B07 + should-fix U05 · 의존: A05

상위: [검수 결과](../K-DOG_검수결과_v1.0_20260916.md). 기존 전처리 CLI 자체는 P1 계획대로 구현되어 있다. 화면 제공은 사용성 개선이며 기존 화면 요구사항 누락으로 소급 판단하지 않는다.

## 현재 운영 절차의 결함

`docs/PILOT_OPERATIONS.md`의 촬영 당일 5단계는 「앱 실행 중에도」 CLI 전처리를 실행할 수 있다고 안내한다. 그러나 `launcher.py:141`은 serve와 worker를 함께 띄우고, `manage.py:114`의 worker 및 `manage.py:68`의 preprocess가 모두 `runtime_lock(store, 'worker')`를 잡는다.

임시 DB에서 같은 worker 잠금을 보유한 채 실제 CLI를 실행했을 때 종료 코드 2, 「API·worker 또는 유지보수 작업이 실행 중입니다. 종료 후 다시 시도하세요」를 확인했다. 단순히 CLI 호출 버튼만 추가하면 같은 문제가 남는다. 문서의 case_id를 「참가자 화면 주소」에서 찾으라는 설명도 현재 화면이 `/`에 머무는 동작과 맞지 않는다.

## 최소 수정과 화면 개선의 순서

1. B07의 최소 수정은 현재 가능한 CLI 절차를 정확히 안내하는 것이다. 현재 방식으로는 Start.cmd의 API·worker를 종료하고 전처리한 뒤 다시 시작해야 한다. case_id는 참가자 ID와 구분하여 복사 가능한 관리 정보로 제공한다. 운영 안내를 고치는 데 A07 고객 회신을 기다릴 필요는 없다.
2. 다음으로 「전처리」를 촬영과 분리된 업무 메뉴로 제공한다. 별도 클릭으로 시작하며, 영상 등록·구간 확정·메뉴 방문만으로 실행하지 않는다. 이 문서의 한 PR에 화면까지 담기 어렵다면 1번을 작은 선행 수정으로 먼저 반영한다.

교수/검토자는 상태와 결과 목록을 읽기만 한다. 파일 시스템 경로·해시·내부 ID는 상세 정보에 둔다. 연구자가 판단할 근거인 원본 이름·회차·구간은 숨기지 않는다. 07 장비 사양이 없는 상태에서 크롭·해상도를 임의의 추천값으로 채우거나 일반 운영자에게 JSON 편집을 요구하지 않는다.

## 실행 경로와 변경 범위

- 수동 요청을 처리하는 42항목 전처리 실행 경로를 하나 정한다. 기존 legacy 채점 run을 만들어 우회하지 않는다. 런처의 대기 worker와 전처리의 잠금 소유 관계를 명확히 바꿔, 앱을 켠 상태에서 실행 가능한지 통합 검증한다.
- 정리·복원과 전처리의 동시 실행 차단은 유지한다. 잠금 파일 삭제나 잠금 검사 제거로 해결하지 않는다.
- 요청자는 서버 인증 계정에서 결정한다. 사용자가 actor·자료 폴더·출력 경로를 임의 입력하지 않게 한다.
- 결과는 input_revision·기준 영상 해시·규칙 버전에 연결한다. `preprocess.latest`가 단순 최신 감사 기록을 반환하므로, 조회 화면에서 현재 입력과의 일치까지 확인해야 한다.
- 재시도는 명시적 동작으로 새 batch를 만든다. 자동 재시도·참가자 전체 자동 실행·AI 호출·범용 작업 시스템은 범위 밖이다.
- `App.tsx`, 새 전처리 페이지, `api.py`, `preprocess.py`, 선택한 실행 경로의 `manage.py/launcher.py/maintenance.py`, 관련 시험·운영 문서가 변경 대상이다.

## 완료 조건

1. 임시 자료 폴더에서 **런처로 앱을 실행한 상태**에서 수동 전처리→완료 조회가 된다. 별도 API 서버만 띄운 시험으로 대신하지 않는다.
2. 교수/검토자 실행 403, 미확정 거절, 중복 실행 거절, 처리 중 구간 변경·삭제 시 이전 결과를 최신 완료로 공개하지 않음을 확인한다.
3. 앱 종료·실패 뒤 상태와 다음 행동이 명확하고, 미완 파일을 성공 결과로 보이지 않는다. 클립 해시·백업 참조·정리 배타 보호 유지.
4. 실행·재시도는 클릭해야만 발생하고 공급자 키가 필요 없다. 합성 자료로 전체 흐름·기존 백엔드·e2e 시험 통과.
5. A07의 창 배치 결정은 이 PR에서 대신하지 않는다. 확정된 처리 규칙과 화면 설명이 일치한다.
