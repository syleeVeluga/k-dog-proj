# K-DOG 설치 매뉴얼 (사용자용)

버전: v1.0 · 2026-10-05 · 문의: 벨루가 veluga.app@veluga.io

이 매뉴얼은 K-DOG를 처음 설치하는 분을 위한 쉬운 안내입니다. 설치 담당자용 자세한 내용은 [운영 안내](PILOT_OPERATIONS.md)를 보세요.

## 먼저 확인하세요

| 내 컴퓨터 | 설치 가능 여부 |
| --- | --- |
| Windows 11 (64비트) | 가능합니다. 아래 Windows 설치를 따르세요. |
| Mac | **직접 설치할 수 없습니다.** 아래 [Mac을 쓰는 경우](#mac을-쓰는-경우)를 보세요. |

받은 ZIP 파일이 어느 종류인지 확인합니다.

| 받은 것 | 종류 | 따라 할 곳 |
| --- | --- | --- |
| `K-DOG-<고객이름>-....zip` 파일, 그리고 **문자·전화로 따로 받은 발행 키**(`KDOG-XXXXX-...`) | 발행 패키지 (일반적인 경우) | [Windows 설치 A](#windows-설치-a-발행-패키지) |
| `...-online....zip` 파일 (발행 키 없음) | 사용자 설치형 | [Windows 설치 B](#windows-설치-b-사용자-설치형) |

어느 것인지 모르겠으면 받은 곳에 물어보세요.

## Windows 설치 A: 발행 패키지

따로 설치할 프로그램이 없고, 인터넷도 필요 없습니다.

준비물: ZIP 파일, 발행 키, ZIP의 SHA-256 값 (키와 함께 받은 긴 문자열)

1. **ZIP 확인하기**
   - ZIP이 있는 폴더의 빈 곳에서 `Shift` 키를 누른 채 오른쪽 클릭 → "PowerShell 창 열기"(또는 "터미널에서 열기")를 누릅니다.
   - `Get-FileHash .\받은파일이름.zip` 을 입력하고 `Enter`를 누릅니다.
   - 화면의 `Hash` 값이 받은 SHA-256 값과 같은지 봅니다. 대문자·소문자 차이는 괜찮습니다. **다르면 설치하지 말고 문의하세요.**
2. **압축 풀기**
   - ZIP을 오른쪽 클릭 → "모두 압축 풀기"를 누릅니다. ZIP 안에서 바로 실행하지 마세요.
   - 보안 경고가 나오면 ZIP 파일을 오른쪽 클릭 → 속성 → "차단 해제"를 체크한 뒤 다시 압축을 풉니다.
3. **설치하기**
   - 압축을 푼 폴더의 `Install.cmd`를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 나오면 "추가 정보" → "실행"을 누릅니다.
4. **발행 키 입력하기**
   - `KDOG-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX` 형태의 키를 입력하고 `Enter`를 누릅니다.
   - 대소문자, 하이픈(-), 띄어쓰기는 상관없습니다. 숫자 0과 영문 O처럼 헷갈리는 글자는 자동으로 바로잡습니다.
   - 키는 설치할 때 **한 번만** 입력합니다. 틀리면 다시 물어봅니다.
5. **설치 끝**
   - 바탕화면에 **K-DOG** 아이콘이 생깁니다.
   - 압축을 푼 폴더와 ZIP은 지워도 됩니다. 입력한 자료는 따로 보관됩니다.

로그인 아이디와 비밀번호는 담당자에게 따로 받습니다.

## Windows 설치 B: 사용자 설치형

uv와 FFmpeg라는 프로그램을 먼저 설치해야 하고, 처음 설치할 때 인터넷이 필요합니다.

### 1단계: uv 설치

1. 시작 버튼을 오른쪽 클릭 → "터미널"(또는 "Windows PowerShell")을 엽니다.
2. 아래 줄을 그대로 붙여 넣고 `Enter`를 누릅니다.

   ```powershell
   winget install --id=astral-sh.uv -e
   ```

   `winget`이 없다는 메시지가 나오면 대신 아래 줄을 붙여 넣습니다.

   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

### 2단계: FFmpeg 설치

1. 같은 창에 아래 줄을 붙여 넣고 `Enter`를 누릅니다.

   ```powershell
   winget install ffmpeg
   ```

2. 끝나면 **열려 있는 터미널 창을 모두 닫습니다.** 새 창을 열어야 설치한 프로그램이 인식됩니다.

### 3단계: 잘 설치됐는지 확인

새 터미널 창을 열고 아래 세 줄을 하나씩 입력합니다. 셋 다 버전 번호가 나오면 됩니다.

```powershell
uv --version
ffmpeg -version
ffprobe -version
```

"인식되지 않습니다"라는 메시지가 나오면 컴퓨터를 다시 시작한 뒤 다시 확인합니다. 그래도 안 되면 문의하세요.

### 4단계: K-DOG 설치

1. ZIP과 함께 받은 `.sha256` 파일이 있으면 [설치 A의 1번](#windows-설치-a-발행-패키지)처럼 ZIP을 확인합니다.
2. 새 폴더(예: `C:\K-DOG`)를 만들고, ZIP을 오른쪽 클릭 → "모두 압축 풀기"로 그 폴더에 풉니다.
3. 압축을 푼 폴더의 `Install.cmd`를 더블클릭합니다. 보안 창이 나오면 "추가 정보" → "실행"을 누릅니다.
4. 몇 분 동안 필요한 파일을 내려받습니다. 창을 닫지 말고 기다립니다.
5. 계정 만들기 (영어로 물어봅니다)
   - `New admin account name` → 관리자 아이디를 입력하고 `Enter`
   - `새 비밀번호 (12자 이상)` → 비밀번호 입력 (화면에 보이지 않는 것이 정상입니다) → 한 번 더 입력
   - `New developer account name` → AI 키를 등록할 개발자 아이디를 입력합니다. 필요 없으면 그냥 `Enter`
   - **관리자 계정은 꼭 만드세요.** 없으면 로그인할 수 없습니다.
6. `Installation complete`가 나오면 아무 키나 눌러 창을 닫습니다.

이 방식은 바탕화면 아이콘을 만들지 않습니다. 프로그램 폴더의 `Start.cmd`로 실행합니다. 원하면 `Start.cmd`를 오른쪽 클릭 → "바로 가기 만들기"로 바탕화면에 바로가기를 둡니다.

## 실행과 종료 (A·B 공통)

1. **실행:** 바탕화면 K-DOG 아이콘(설치 B는 `Start.cmd`)을 더블클릭합니다.
2. 검은 실행 창이 뜨고 잠시 뒤 브라우저가 자동으로 열립니다. 열리지 않으면 창에 나온 주소(보통 `http://127.0.0.1:8000`)를 Chrome이나 Edge 주소창에 입력합니다.
3. 아이디와 비밀번호로 로그인합니다.
4. **작업 중에는 검은 창을 닫지 말고 최소화**해 둡니다. 브라우저 탭만 닫아도 K-DOG는 계속 실행됩니다.
5. **종료:** 검은 실행 창을 닫으면 K-DOG가 종료됩니다.

이미 실행 중일 때 아이콘을 다시 누르면 새로 시작하지 않고 브라우저만 다시 엽니다.

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| "키가 맞지 않습니다" | 키를 다시 확인해 입력합니다. 계속 안 되면 문의합니다. |
| "손상"이라는 메시지 | ZIP을 새로 받아 새 폴더에 다시 압축을 풀고 다시 설치합니다. |
| "다른 위치나 버전의 K-DOG가 실행 중" | 열려 있는 다른 K-DOG 검은 창을 닫고 다시 실행합니다. |
| "다른 프로그램이 8000 포트를 사용 중" | 그 프로그램을 끄거나 컴퓨터를 다시 시작합니다. |
| (설치 B) "Install uv/ffmpeg ... PATH" 또는 "FFmpeg를 설치하고 PATH에 등록" | 1~3단계를 다시 하고, 새 창에서 버전이 나오는지 확인합니다. |
| (설치 B) "Dependency installation failed" | 인터넷 연결을 확인하고, 터미널에서 `uv self update`를 실행한 뒤 `Install.cmd`를 다시 실행합니다. |
| 비밀번호를 잊음 | 담당자에게 재설정을 요청합니다. 사용자가 직접 바꾸는 기능은 없습니다. |

## Mac을 쓰는 경우

지금 K-DOG는 **Mac에 설치할 수 없습니다.** 설치·실행 프로그램과 AI 키 보호 기능이 Windows 전용이고, Mac에서는 시험하지 않았습니다.

Mac을 쓰는 분은 다음 중 하나를 선택하세요.

- **Windows PC에 설치해서 쓰기:** 위 Windows 설치를 따릅니다.
- **담당자의 K-DOG 서버에 접속해서 쓰기:** 담당자가 Windows PC나 서버에 K-DOG를 설치해 접속 주소(`https://...`)를 알려 준 경우, Mac의 Chrome에서 그 주소로 접속해 로그인합니다. Mac 브라우저 접속은 아직 정식 검증 전이므로 담당자에게 먼저 확인하세요.

Mac 설치가 꼭 필요하면 문의처로 알려 주세요.
