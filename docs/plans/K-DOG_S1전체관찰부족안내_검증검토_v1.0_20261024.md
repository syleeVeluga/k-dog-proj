# K-DOG S1 전체 관찰 부족 안내 검토

- 날짜: 2026-10-24
- 선행: [공급자 스키마 복잡도 보정](K-DOG_S1공급자스키마복잡도보정_검증검토_v1.0_20261024.md)
- 범위: 공급자 요청의 실제 전체 관찰 부족 정보

## 원인과 수정

실제 실행에서 확정된 원본 전체창보다 AI용 파생 영상의 실제 가용 끝이 짧았다. 전체 횟수 항목은 그 부족한 꼬리 구간을 볼 수 없으므로 빈값이어야 한다. 기존 앱 검증은 올바르게 거절했지만 공급자가 재시도에서도 전체 관측값을 반환했다. 원본 끝 시각을 바꾸거나 없는 관찰을 채택하지 않는다.

이미 계산하는 허용 클립 내부 범위를 기준 영상 시각으로 환산하고, 카메라별 범위의 합집합이 각 실제 원본 구간을 전부 덮는지 확인한다. 기존 S1의 무조건 전체 관찰 항목(전체창 필수·발성)에 대해 창 미확정·원본 구간 없음·실제 파생 범위 부족을 `whole_interval_unavailable_item_codes`로 전달한다. 이 목록은 빈값·미관찰·사유를 요청한다. 원점수나 앱 검증을 변경하거나 잘못된 모델 응답을 강제 변환하지 않는다. 목록에 없더라도 가림·음성·사건 근거 등 나머지 검증을 통과해야 한다.

선택한 AI용/원본 FPS 변형과 실제 파일 길이를 구분한다. 여러 카메라의 관찰량을 합산하지 않으며 기준 시각의 구간 피복만 확인한다. 앞선 보정과 동일하게 1ns 이하 산술 잡음만 허용하고 실제 1ms 공백은 부족으로 안내한다. 촬영 입력·전처리·고정 설정·성공 응답과 이전 실패 이력은 보존한다.

## 검증

- 새 합성 회귀 2건: AI용 꼬리 부족과 원본 변형의 전체 피복 구분, 다른 카메라 피복 및 1ns 이하 오차와 실제 1ms 공백 구분.
- 최종 변경의 관련 백엔드 99건 통과(99.756초): 원자료·시트·실행·리포트 장면·Gemini 계약·예비키 경로. 신규 2건을 포함한다.
- 실제 고정 입력을 읽기 전용으로 대조해 전체 관찰 부족 두 항목을 식별했다. `git diff --check`와 Graft 재생성을 통과했다.
- 선행 병합본 전체 백엔드 875건 통과(1289.368초, 3건 건너뜀). 건너뛴 원본 의존 검증을 완료로 간주하지 않는다.
- 라이브러리·의존성 추가 없음. 실제 참가자 시각·자료·결과는 저장소 밖에 보관한다.
