# K-DOG S1 추론·출력 한도 보정 검토

- 날짜: 2026-10-24
- 선행: [조건부 전체 관찰 안내](K-DOG_S1조건부전체관찰안내_검증검토_v1.0_20261024.md)
- 범위: 새 관찰 설정 기본값과 새 AI 애착 판단 요청의 생성 한도

## 원인과 수정

실제 관찰 2회와 애착 판단 1회에서 불완전 응답을 확인했다. 각 시도의 추론·출력 토큰 합계가 기존 16,384/8,192 한도에 도달했다. 불완전 JSON은 채택하지 않고 사용량·과금 미확인·실패 이력을 보존했다.

2026-10-24 [Google 공식 추론 문서](https://ai.google.dev/gemini-api/docs/thinking)에서 `max_output_tokens`가 추론과 최종 출력의 합계 한도임을 확인했다. [Gemini 3.8 Flash 공식 모델 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)는 최대 출력 65,536과 low/medium/high 추론을 지원한다. 모델·라이브러리·추론 수준을 바꾸지 않고 새 관찰 설정 기본값과 새 애착 판단 요청을 32,768로 늘린다. 실제 소비 토큰은 공급자의 사용량 기록으로 확인한다.

이전 저장 파이프라인의 명시 상한과 기존 실행 스냅샷은 자동 변경하지 않는다. 운영에는 별도 새 설정 판본을 저장·활성화한다. 입력·모델·설정 전체 해시가 달라지므로 이전 성공 항목군을 새 설정 실행에 재사용하지 않는다. 기존 재사용 검증을 우회하거나 점수·원자료·채점 규칙을 바꾸지 않는다. 이전 S1 결과와 시도는 보존하고 새 실행으로 전 과정을 재생성한다.

리포트 문장 단계의 기존 low 추론 한도는 변경하지 않는다. 그 단계에서 확인되지 않은 문제까지 확대하지 않는다. 새 의존성 도입은 없고 기존 잠금 파일을 유지한다.

## 검증

- 새 회귀: 새 생성 한도, 저장된 명시 16,384 설정과 기존 8,192 실행 스냅샷의 보존을 함께 검증한다.
- 관련 백엔드 122건 통과(136.648초): 설정·애착·원자료·시트·실행·리포트 장면·Gemini 계약·예비키 경로. 신규 보존 회귀를 포함한다.
- 변경 차이 검토와 `git diff --check`, Graft 그래프 재생성을 통과했다.
- 실제 토큰 상세·참가자 자료·실행 결과는 저장소 밖에 보관한다. 이 사례의 공급자 호환성 검증이 전체 현장 수용성 검증을 대체하지 않는다.
