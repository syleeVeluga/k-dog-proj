# K-DOG S1 근거 시각 변환 보정 검토

- 날짜: 2026-10-24
- 선행: [촬영·전처리 리뷰](K-DOG_촬영전처리리뷰_v1.0_20261024.md), PR #140 병합 후 실제 종단 실행
- 범위: 클립 → 원본 → 기준 영상 시각 변환, 공급자 응답 범위 안내

## 재현과 수정

1. 비정수 클립 시작·카메라 오프셋을 더하고 빼면 20초 관찰이 `19.999999999999996`초 범위로 변환되어 거절될 수 있었다. 변환 과정에서 생긴 1ns 이하 차이만 원본 범위·관찰량 경계에 맞춘다. 원관측의 숫자 값과 S1 계산 정의는 바꾸지 않는다.
2. 같은 원인으로 기준 영상의 관찰창·걷기 국면 경계가 미세하게 벗어나거나 연속 관찰 구간이 끊긴 것으로 판정될 수 있었다. 기존 확정 경계에 1ns 이하로 가까운 변환값을 정규화하며 실제로 분리된 구간은 유지한다.
3. 공급자에 항목별 `clip_id/window_id`의 허용 클립 내부 구간을 명시한다. 원본 절단 범위·파생 파일 길이·분리된 실제 구간을 넘는 범위를 안내하지 않는다. 무음 창과 발성 항목 목록, `value=null/status=unobserved/vocalization=null` 응답 예시를 함께 제공한다. 잘못된 응답을 강제 채택하거나 청취 0초 객체를 허용하지 않는다.

클립 파일·해시·입력 판본·모델·활성 설정과 이전 성공 결과는 보존한다. 공급자 키 선택·교체·예비키·원격 파일 정리 동작은 변경하지 않는다. 중지한 동일 실행의 남은 단계를 재시도하며 성공 단계와 이전 시도 이력을 보존한다.

## 검증

- 수정 전 합성 입력으로 관찰량 초과, 기준 관찰창 이탈, 걷기 국면 이탈, 물리 클립 끝 이탈 및 연속 구간 누락을 재현했다.
- 수정 후 관련 백엔드 93건 통과(86.119초): 원자료 정규화·채점 시트·실행·장면 시각·Gemini 계약·예비키/재시도 검증. 새 회귀 6건을 포함한다.
- 1ms 이상 실제 창 이탈 및 실제 관찰 공백은 계속 거절하고 빈 관찰은 전체 관찰로 취급하지 않는 것을 검증했다. 실제 자료나 실제 공급자 호출은 합성 시험에 사용하지 않았다.
- 후속 리포트 서술·AI 첨부·최종 결과·공유 출력·리포트 실행 72건 통과(135.100초). 관련 검증 합계 165건이 통과했다.
- 변경 차이를 재검토했고 `git diff --check`를 통과했다. Graft 그래프는 병합 전 재생성·동기화 확인한다.

의존성 추가·변경은 없다. 2026-10-24 확인한 공식 최신 버전, Python 3.14 환경과 기존 잠금 유지 근거는 선행 리뷰의 버전 확인을 따른다. 실제 참가자 자료·실행 결과·사용량은 저장소 밖 운영 경로에 보관한다.
