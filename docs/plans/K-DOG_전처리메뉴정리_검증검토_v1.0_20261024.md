# K-DOG 전처리 메뉴 정리 및 처리 조건 검토

- 작성일: 2026-10-24
- 기준: `ec58b34` 이후 중복 전처리 메뉴 제거 요청
- 범위: 독립 메뉴·전체 대상 목록 제거, 참가자별 전처리 탭과 실행 이력 유지

## 변경

주 메뉴의 전처리와 전체 참가자 준비 목록, 중복 실행 대상 선택 화면을 제거했다. 참가자 접수에서 참가자를 연 뒤 영상 등록 → 촬영 기록 → 전처리 탭으로 작업한다. 실행·재사용·상태 확인 기능과 이전 실행 결과는 보존한다.

실행 이력은 선택한 참가자에 대해 현재 계정이 실행한 내역만 표시한다. 서버가 페이지 분할 전에 참가자를 필터한다. 이전 회차 결과를 열 때는 회차를 고정하고, 현재 입력으로 돌아올 때는 최신 회차를 다시 조회한다. 참가자 없는 기존 전처리 주소는 접수 안내를 표시한다.

## 촬영 기록과 전처리 조건

촬영 기록은 원본 영상에서 실제 절차와 시간을 지정하는 입력이다. 전처리는 이 기록을 사용해 분석용 클립을 만든다. 메뉴를 지워도 기록 및 전처리 기능 자체는 필요하다.

| 구분 | 실제 처리 조건 |
| --- | --- |
| 필수 | 해당 회차의 기준 영상 선택, 포함할 카메라 식별 정보, 촬영 기록 확정, 촬영 절차 `현재 절차 확인` |
| 구간 | 표준 8개 구간의 순서·상태를 유지한다. 수행 구간은 실제 시작·종료 시각이 필요하다. 퇴장 종료 시각은 생략 가능하다. 미수행은 시각 없이 사유를 기록한다. |
| 시간 | 종료가 시작보다 뒤여야 하며 구간 순서·겹침·영상 길이 검증을 통과해야 한다. 단축·복지중단 독립 구간과 재회 사이에는 별도 연결 조건이 있다. |
| 선택 | 산책 6단계 상세 시각, 행동 사건, 관찰 범위, 꼬리 선택·메모, 절차 메모, CSV 업로드는 기본 실행의 필수 입력이 아니다. |
| 부분 입력 | 선택 정보라도 입력했다면 해당 정보의 유효성 검증을 통과해야 저장된다. 산책 단계 시각 일부 입력, 사건 시각·메모 누락, 불완전한 오프셋 등이 저장을 막을 수 있다. |
| 추가 카메라 | 동기화가 확정되지 않은 보조 카메라는 사용 대상에서 제외된다. 이것만으로 기준 영상의 전처리 전체를 막지는 않는다. |
| 무결성 | 원본 파일 누락·변조·읽기 실패, 다른 회차 영상 참조, 입력판 변경, 실행 충돌 등은 차단한다. |
| 필요 없음 | 설문 완료, AI API 키, 독립 채점 완료, 표시된 `사용 가능` 영상 수는 촬영 기록 확정이나 전처리의 선행 조건이 아니다. |

주의할 점은 촬영 기록의 `확정`과 `현재 절차 확인`이 별도 조건이라는 것이다. 확정 저장은 되었어도 절차가 미확인 또는 이전 절차이면 전처리는 실행되지 않는다. 이번 변경은 S1 기록·채점 규칙을 완화하지 않는다.

근거: `backend/app/domain/recording_v4.py`, `backend/app/capture_v4.py`, `backend/app/recording_v4.py`, `backend/app/preprocess_v4.py` 및 `frontend/src/RecordingPanelV4.tsx`.

## 검토 및 검증

- 수용: 전체 이력 대신 참가자별 이력이 필요하므로 API에 참가자 필터를 추가하고 페이지 분할 전에 적용했다.
- 수용: 이전 실행을 열 때 참가자 조회가 성공한 뒤 실행 선택을 반영하도록 수정했다.
- 수용: 실행 또는 상태 갱신 후 같은 탭의 실행 이력도 갱신한다.
- 유지: 원본·입력판·회차 보호와 S1 촬영 기록 검증은 메뉴 중복과 무관하므로 변경하지 않는다.
- 빌드: `npm run build` 통과. 기존 500 kB 번들 경고는 남아 있다.
- 백엔드: `python -X utf8 -m unittest tests.test_preprocess_execution_v4 tests.test_recording_v4 -q` — 31건 통과.
- 브라우저: 관련 6개 파일 40건 통과(재검증 39건 통과 + 상태 필터 locator 수정 후 해당 1건 통과). 최초 실행은 33건 통과, 7건 실패였으며 기존 전체 화면 전제 및 참가자 선택 대기·상태 locator를 수정했다. 실제 합성 영상의 FFmpeg 전처리·재사용·입력판 충돌, 이전 회차 결과, 계정 전환, 응답 유실 복구, 페이지 분할·폴링, PC·모바일 탭 이동을 포함한다.
- 로컬: 기존 데이터 경로를 유지해 8000 포트 앱을 재시작했다. 설치 자산 검사와 기존 파일 참조 점검은 통과했으며 진행 중 분석 작업은 없었다. 운영 DB의 입력이나 결과는 수정하지 않았다.
- 배포 범위: 로컬 작업 브랜치 `veluga/preprocess-tab-only`; 이번 변경의 원격 병합은 수행하지 않았다.
