# K-DOG 왼쪽 메뉴 그룹 정리

버전: v1.0 · 2026-10-24 · 기준 `main / ebfb44e`

사용자 요청에 따라 현장 운영·분석·평가·자료 관리의 그룹 제목을 강조하고 리포트를 같은 최상위 수준으로 변경했다. 브랜치는 `veluga/sidebar-groups-20261024`이며 기존 승인 절차에 따라 검증·리뷰·병합·로컬 배포한다.

## 변경

- 그룹 순서는 현장 운영 → 분석·평가 → 리포트 → 자료 관리다. 네 제목 모두 14px·800 굵기·진한 색과 하단 구분선을 적용한다.
- 리포트 발급·비교 조건·연구 내보내기를 리포트 최상위 그룹으로 옮긴다. 기존 URL, 메뉴 순서와 계정별 접근 정책을 유지한다.
- 현재 위치도 `리포트 → 비교 조건`처럼 실제 메뉴 계층과 일치시킨다.
- 더 이상 쓰이지 않는 하위 그룹 분할 함수, parent 속성, routeParent 함수·호출, 하위 그룹 CSS를 삭제한다. DB 변경은 없다.

## 검증·리뷰

- `npm run build` 통과. 기존 번들 크기 안내만 남는다.
- `npm run test:e2e -- tests/navigation.spec.ts tests/location-navigation.spec.ts tests/layout.spec.ts`: **20건 모두 통과(32.0초)**. 최상위 그룹 순서·소속, 모든 업무 계정의 메뉴, 현재 위치, 직접 URL, 새로고침·뒤로가기, 모바일 포커스·서랍·넘침을 확인했다.
- 수동 cold review에서 메뉴만 이동하고 현재 위치에 이전 분석·평가 단계가 남는 문제, 사용하지 않는 하위 그룹 코드 잔존을 점검하여 함께 제거했다. 별도 에이전트 리뷰를 수행한 것은 아니다.
- `git diff --check`, 제거 코드 참조 검색, graft 갱신·동기화 확인. [메뉴 화면](../screenshots/sidebar-groups-20261024/desktop.png)을 시각 검토했다.
- 라이브러리 추가·업그레이드는 없다. 같은 세션의 2026-10-24 [공식 최신판·호환성 확인 기록](K-DOG_설문표와촬영이력정리_v1.0_20261024.md#의존성-확인)을 적용하며 기존 lockfile을 유지한다.

병합 대상은 `syleeVeluga/k-dog-proj`의 main, 배포 대상은 `http://127.0.0.1:8000`이다. 병합본과 검증한 frontend 소스의 일치, 실제 서버 health 및 HTML·JS·CSS 일치를 확인한다.
