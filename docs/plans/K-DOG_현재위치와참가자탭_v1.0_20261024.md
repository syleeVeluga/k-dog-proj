# K-DOG 현재 위치와 참가자 작업 탭

버전: v1.0 · 2026-10-24 · S1.1

## 승인 범위

사용자는 현재 위치 표시, 참가자 내 설문·영상·촬영 기록 탭, 상시 목록 복귀, 촬영 독립 메뉴 제거, 공용 수신 보조 진입을 모두 적용하고 검증 → cold review → 수용 건 반영 → 병합 → 로컬 배포하도록 승인했다.

기준은 `main / 5c2b9a2`이며 브랜치는 `veluga/participant-navigation-20261024`다. 같은 대화에서 승인·검증한 [참가자 중심 흐름 개선](K-DOG_참가자중심흐름개선_v1.0_20261023.md)의 미커밋 변경도 포함한다. 업무 기능의 명칭·진입·위치 안내 범위이며 backend 저장·채점 정책은 변경하지 않는다. [S1 개발 계획](../archive/개발반영_20261003/K-DOG_개발반영계획_v1.0_20261003.md) 및 [인수 대장](../archive/개발반영_20261003/K-DOG_인수검증대장_v1.0_20261003.md)의 실제 공급자·현장 실측 대기는 유지한다.

## 동작

- 왼쪽에는 업무 메뉴만 노출한다. 촬영 제목·영상 파일 업로드·촬영 기록 항목은 제거한다. 기존 촬영 URL은 보존해 주소 직접 진입 시 참가자를 선택할 수 있다.
- 상단 현재 위치는 업무 영역 → 목록 → 참가자 → 현재 작업을 표시한다. 리포트 하위 그룹도 구분한다. 목록 링크와 상시 복귀 버튼은 같은 경로로 돌아간다.
- 참가자 작업 탭은 설문 확인·영상 등록·촬영 기록의 같은 수준 이동이다. 기존 참가자와 촬영 회차를 유지하며 탭 이동 자체는 회차 저장이나 분석 실행을 요청하지 않는다. 일반 탐색 버튼과 `aria-current`로 현재 작업을 표시한다.
- 분석·평가 화면은 별도 메뉴로 유지한다. 분석 목록에서 자료 보완을 열었다면 그 분석 목록으로 복귀한다. 검색·행사 필터와 접수 자료 상태 필터를 유지한다.
- 현재 참가자·회차와 목록 복귀는 접지 않는다. 부가 회차 안내만 펼칠 수 있다. 모바일 입력 보호와 44px 버튼 크기를 유지한다.
- 접수의 「공용 업로드 보관함」은 참가자 등록 전 수신 경로로 바로 연다. 별도 URL `#/recording/shared`로 새로고침 뒤에도 공용 화면을 유지한다.

## 검증 및 cold review

합성 데이터 전용 서버 8765에서 기존 Playwright 회귀를 사용했다. 기존 환경의 `redesign-existing-projects` 및 `webapp-testing` 지침을 적용했다. 초기 관련 검증 26건에서 발견한 기존 버튼 선택자와 모바일 맥락 영역 높이를 수정한 후 **26건 전부 통과(58.6초)**했다.

그 뒤 구현과 분리한 수동 cold review 패스로 호출 관계, 위치와 메뉴 표시의 일치, 복귀, 미저장 입력, 공용 수신, 모바일 화면을 검토했다. 별도 에이전트나 제3자 독립 검토가 수행된 것으로 기록하지 않는다.

### 최종 검증 결과

- `frontend/`의 `npm run build` 통과. 기존 500 kB 초과 번들 안내만 남는다.
- `npm run test:e2e`: 176건 중 174건 통과(12.1분). 위 표의 설정 선택 갱신 대기와 촬영 요약 배치 2건을 수정했다.
- 최종 앱 빌드에서 `npm run test:e2e -- tests/location-navigation.spec.ts tests/navigation.spec.ts tests/participant-workflow.spec.ts tests/context.spec.ts tests/layout.spec.ts tests/importer-upload-v4.spec.ts tests/recording-split-v4.spec.ts`: 43건 중 42건 통과(1.6분). 앞선 2개 실패 항목은 모두 통과했다. 추가 메뉴 선택 시험 1건은 참가자 조회가 끝나기 전에 다음 메뉴를 눌러 정상적으로 조회가 취소된 경우여서, 참가자 표시를 기다린 뒤 메뉴를 선택하도록 보완했다.
- 마지막 `npm run test:e2e -- tests/location-navigation.spec.ts`: 4건 모두 통과(10.9초). 최종 실패 잔여 0건이며 전체 실행과 후속 재검증을 합쳐 176개 고유 테스트를 확인했다. 한 번의 176건 전체 통과로 기록하지 않는다.
- 360·390·768·1440px 배치, 72명 목록, 회차 유지, 미저장 입력 취소, 숨긴 촬영 URL의 직접 진입, 공용 수신 새로고침, 분석 복귀, 메뉴·위치의 일치를 검증했다. backend 코드·resources 변경은 없다.
- `git diff --check` 통과. `graft build` 및 `graft check`의 wiring graph 동기화 확인. 문서 상대 링크 확인.
