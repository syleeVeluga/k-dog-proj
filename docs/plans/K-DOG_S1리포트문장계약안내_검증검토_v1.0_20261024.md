- 선행: [리포트 장면 시각 보정](K-DOG_S1리포트장면시각보정_검증검토_v1.0_20261024.md)
- 범위: 문장 생성 지침과 재시도 오류 안내

## 원인과 수정

실제 문장 생성에서 고정 수치·금지 표현 검증 실패에 이어 실천 제안 배열 개수 검증이 실패했다. 분석과 최종본은 보존됐고, 실패한 문장은 발급되지 않았다. 기존의 통합 오류 메시지는 수치와 금지 표현을 구분하지 못했고, 개수 오류도 필요한 최소·최대와 받은 개수를 알려주지 않았다.

검증 조건은 유지하고 오류 안내를 구분한다. 숫자 직접 기재, 부정문에도 포함될 수 있는 금지 문자열, 필요한 실천 개수 각각의 수정 방향을 전달한다. 생성 지침에는 설문이 없어도 유효 관찰이 있으면 한 개부터 action_capacity 이하의 실천을 작성하고, 영일 때는 빈 배열을 반환하도록 명시한다. 금지 문자열은 한계 설명이나 부정문에도 쓰지 않도록 안내한다.

이전 실행의 지침 스냅샷·해시와 시도 이력을 보존한다. 새 지침 해시로 새 리포트를 생성하며 기존 최종본을 재사용한다. 채점·점수·유형·제안 수용 조건·원자료·의존성은 변경하지 않는다. 문장 생성의 전문적 적절성에 대한 별도 검토 필요 상태도 유지한다.

## 검증

- 기존 지침 스냅샷 재생, 불변 사실·유형·우선 도움, 출처·해시·권한·실행 및 다운로드 보호 검증을 유지한다.
