# K-DOG S1 클립 내부 관찰량 보정 검토

- 날짜: 2026-10-24
- 선행: [근거 시각 변환 보정](K-DOG_S1근거시각보정_검증검토_v1.0_20261024.md), PR #141 병합 후 실제 실행
- 범위: `LocalEvidenceV4` 클립 내부 관찰량 검증

## 재현과 수정

실제 실행의 다른 항목군에서 `local observation amount exceeds its actual range` 계약 오류를 확인했다. 실패 응답 본문은 성공 산출물로 보존되지 않으므로 실제 숫자를 추정하지 않았다. 합성 입력의 시작 29.916초·끝 49.916초·관찰량 20초는 뺄셈 결과가 `19.999999999999996`초가 되어 같은 오류를 재현했다.

원본 시각 변환 전의 로컬 계약 검증에서, 음수가 아닌 실제 구간 길이보다 관찰량이 1ns 이하로 큰 경우에만 관찰량을 실제 구간 길이로 정규화한다. 원점수는 변경하지 않는다. 1ms 실제 초과와 역전 시각(1ns 이내 포함)은 계속 거절한다. 응답 JSON 스키마와 S1 계산 정의는 바뀌지 않는다.

기존 성공 결과와 원본 응답은 보존하며 저장 응답 재검증도 동일 정규화를 거친다. 실패 항목군의 재생성은 검증된 성공 항목군을 명시 재사용하는 새 실행으로 기록한다. 진행 중인 공급자 요청은 검증 중 계속 처리하며, 병합 후 새 코드로 실행하기 전 제어 상태를 확인한다.

## 검증

- 새 회귀 2건: 수정 전 정상 20초 근거 실패 재현, 실제 초과·역전은 계속 거절.
- 관련 백엔드 95건 통과(99.840초): 원자료 정규화·채점 시트·실행·리포트 장면·Gemini 계약·예비키 경로. 신규 2건을 포함한다.
- 불변 모델을 사후 변경하지 않고 필드 검증 단계에서 정규화한다. `git diff --check`와 Graft 재생성을 통과했다.
- 의존성 추가·변경 없음. 버전 확인 근거는 선행 리뷰와 같다.
- 실제 참가자 자료와 운영 산출물은 저장소 밖에 보관한다.
