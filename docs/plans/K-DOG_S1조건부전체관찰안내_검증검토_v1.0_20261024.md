# K-DOG S1 조건부 전체 관찰 안내 검토

- 날짜: 2026-10-24
- 선행: [전체 관찰 부족 안내](K-DOG_S1전체관찰부족안내_검증검토_v1.0_20261024.md)
- 범위: 기존 `보23=-2` 전체 관찰 조건의 요청 안내

## 원인과 수정

낯선 사람 항목군은 각 항목 전체가 항상 전체 관찰을 요구하지 않는다. 기존 S1 검증은 `보23`의 값 `-2`(구간 전체에서 요청 말·손짓 없이 관찰)만 전체창 근거를 요구한다. 무조건 전체 관찰 항목만 안내하던 요청 목록에는 이 조건부 값이 포함되지 않았다. 실제 응답은 기존 전체 관찰 검증에서 거절됐으며 채택하지 않았다.

이미 계산하는 원본 구간과 실제 파생 영상 피복으로 전체 관찰이 부족한 경우 `whole_interval_unavailable_values={"보23":[-2]}`를 별도로 전달한다. 항목 전체를 무조건 미관찰로 만들지 않으며, 실제 근거 없는 다른 값으로 대체하지 말고 부족하면 빈값·사유를 기록하도록 요청한다. 기존 검증·허용 척도·원점수·고정 설정·이전 응답은 변경하지 않는다.

## 검증

- 새 합성 회귀 2건: AI용 꼬리 부족에서 조건부 `-2`만 안내하고 원본 변형에서는 제한이 없음을 검증한다. 부분 근거의 `-1`은 기존대로 허용하며 전체 관찰이 없는 `-2`는 계속 거절한다.
- 관련 백엔드 101건 통과(103.431초): 원자료·시트·실행·리포트 장면·Gemini 계약·예비키 경로. 신규 2건을 포함한다.
- 변경 차이 검토와 `git diff --check`, Graft 그래프 재생성을 통과했다.
- 의존성 추가·변경 없음. 실제 자료와 시각·공급자 사용량은 저장소 밖에 보관한다.
- 불완전 공급자 응답은 채택하지 않으며, 검증된 성공 항목군만 명시 재사용해 남은 요청을 처리한다.
