# K-DOG S1 공급자 스키마 복잡도 보정 검토

- 날짜: 2026-10-24
- 선행: [근거 시각 보정](K-DOG_S1근거시각보정_검증검토_v1.0_20261024.md), [클립 내부 관찰량 보정](K-DOG_S1클립내부관찰량보정_검증검토_v1.0_20261024.md)
- 범위: 관찰 원자료의 Gemini 전송 스키마

## 원인과 수정

걷기와 낯선 사람 관찰의 각 10개 항목군 실제 요청이 추론 단계 HTTP 400으로 거절됐다. 참가자 자료·영상 없는 합성 요청에 걷기 항목군의 같은 고정 스키마를 적용해 공급자의 `too many states for serving` 오류를 재현했다. 같은 스키마에서 최상위 `observations`의 `minItems`·`maxItems`만 제외한 분리 시험은 HTTP 200이었다. 진단 외부 호출은 총 2회이며 별도 감사 이력과 사용량을 운영 결과 폴더에 기록했다. 진단 결과를 참가자의 채점 자료로 사용하지 않았다.

공급자 전송 시 스키마의 복사본에서 이 두 제약만 제외한다. 원래 고정 설정·스키마·해시는 변경하지 않는다. 자료형·필수 필드·상태·근거·나머지 배열 제약은 유지한다. 요청 문맥에 정확한 관측 개수를 명시하며 앱의 `normalize`가 각 요청 항목을 정확히 한 번씩 반환했는지 계속 검증한다. 항목 누락·중복·추가를 허용하지 않는다. 걷기 국면은 저장된 촬영 입력 그대로 전달하며 미확정 시각을 추정하지 않도록 안내한다. 점수·판정 규칙이나 파일 수명·키 교체 동작은 바꾸지 않는다.

2026-10-24 [Google 공식 구조화 출력 문서](https://ai.google.dev/gemini-api/docs/structured-output)의 스키마 복잡도 제한과 배열 길이 제약 설명을 확인했다. 사용 중인 Gemini 3.8 Flash / Interactions v1beta 요청에서 위 분리 시험을 수행했다. 새 라이브러리 도입·의존성 변경은 없다.

## 검증과 실행 보존

- 새 회귀 2건: 전송 복사본의 변경 범위와 고정 스키마 불변성, 앱의 누락·중복 관측 거절.
- 최종 변경의 관련 백엔드 97건 통과(102.480초): 원자료 정규화·시트·실행·리포트 장면·Gemini 계약·예비키 경로. 신규 2건을 포함한다.
- `git diff --check`와 Graft 그래프 재생성을 통과했다. 공식 문서와 위 공급자 분리 시험을 대조해 전송 제약 변경 범위를 검토했다.
- 진행 중인 실제 실행은 다른 항목군을 계속 처리한다. 병합 후 현재 실행이 종료되면 성공 항목군을 명시 재사용한 새 실행에서 남은 실패를 처리한다. 이전 실패·진단·과금 미확인 이력은 보존한다.
- 실제 자료·진단 상세·공급자 사용량은 저장소 밖에 보관한다. 합성 공급자 호환성 시험이 현장 판독 정확도나 전체 S1 수용성 판정을 대신하지 않는다.
