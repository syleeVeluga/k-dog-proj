# K-DOG 행사 신청 설문 Cold Review

버전: v1.0 · 2026-10-23 · 대상 브랜치: `veluga/festival-survey-20261022` · 기준: `main / accab04`

상위: [행사 신청 설문 반영](K-DOG_행사신청설문반영_v1.0_20261022.md). 사용자 지시의 검증 → subagents cold review → 문서 갱신 → 원격·로컬 병합 순서를 따른다.

## 1 독립 검토 범위

| 검토자 | 범위 | 실제 검토 및 결과 |
| --- | --- | --- |
| `/root/review_backend` | 접수 변환·엄격 검증·불변 원행·확정/재시도·시험 | 합성 임시 저장소로 헤더 공백 변형 문제를 재현. 최초 신규 시험 2개, 수정 후 행사 시험 3개 독립 실행 통과(0.528초). 최종 추가 결함 없음 |
| `/root/review_frontend` | 문항 원문 연결·반복 번호·라벨/프로필·수동/프리셋·시트/파일 전환 | 헤더 변형 문제를 중복 확인하고 수동/프리셋 라벨 누락 및 빈 라벨 프리셋 소실을 재현. 두 차례 후속 재검토로 CR01~CR03 수정 확인, 최종 추가 결함 없음 |
| `/root/review_contract_release` | 원본 계약·문구/척도·출처/개인정보·배포 필수 자산·문서 | 원본 hash·헤더만 확인. 로컬 원본 제외와 비식별 자산, 합성 화면, 배포 allowlist/필수 자산/검사를 확인. 신규 결함 없음 |

세 검토자는 읽기 전용으로 수행했고 구현/시험 파일을 수정하거나 운영 DB에 쓰지 않았다. 실제 참가자 이름·응답을 리뷰 출력이나 fixture에 복사하지 않았다. backend 외 두 검토자는 서버 시험을 별도 실행하지 않아 부모의 브라우저 시험과 충돌하지 않았다.

## 2 발견사항과 조치

| ID | 우선순위·위치 | 재현과 영향 | 판단·최종 조치 |
| --- | --- | --- | --- |
| CR01 | P2 · `backend/app/festival_forms.py`의 원본 헤더 비교 | ` 반려견 성별 ` 또는 내부 공백 변형은 프런트가 자동 연결하지만 서버가 `암컷` 변환을 건너뛰어 오류가 됨. 크기/나이/입양 경로도 같은 경계 | 수용·수정. 기존 행사 프로필 조건 안에서 명시적으로 연결한 표준 필드를 변환하고 원본 헤더 비교를 제거. 원행/헤더는 보존. 일반 프로필은 기존 엄격 검증 유지 |
| CR02 | P2 · `FormsImporter.tsx` 라벨 초기화 및 수동/프리셋 연결 | 행사 두려움 열에 `Q10` 보조 열을 추가하면 자동 연결 충돌. 원래 문항을 수동 또는 열 연결만 있는 프리셋으로 선택해도 기본 라벨이 없어 `보통` 응답을 거절 | 수용·수정. 행사 기본 라벨을 최종 열 연결에서 산출하고 명시적 사용자 설정을 그 위에 적용. 최초 행사 문항을 수동으로 연결한 경우 기본 프로필/판본도 행사 것으로 제안 |
| CR03 | P2 · `FormsImporter.tsx`의 빈 라벨 직렬화 | 기본 라벨을 명시적으로 지운 뒤 프리셋 저장 → 파일 재선택 → 설정 불러오기 시 빈 설정이 빠져 `보통=2` 기본값이 복원되고 미리보기 결과가 달라짐 | 수용·수정. 명시적 빈 라벨은 문항별 `{}`로 직렬화. 실제 UI 저장·API 내용·파일 재선택·설정 불러오기 후 빈 값과 동일 오류 상태를 회귀로 확인 |

CR01은 backend/frontend 두 리뷰가 같은 원인으로 확인했으므로 중복 집계하지 않는다. 최종 고유 발견 3건 모두 수용·수정·재검토 완료이며 미해결 발견은 없다. 표현 변경의 측정 동등성, 외부 연구 참고값 및 실제 공급자/현장 품질은 별도 인수 경계다. 이번 합성 회귀나 코드 검토를 해당 인수 완료 근거로 바꾸지 않는다.
