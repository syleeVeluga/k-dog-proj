# K-DOG 촬영·전처리 탭 검증 및 검토

버전: v1.0 · 검증일: 2026-10-24 · 기준: `main / ffa72ac`

## 범위

- 참가자 작업을 설문 확인 → 영상 등록 → 촬영 기록 → 전처리 순으로 연결한다.
- 전처리의 「촬영 기록으로 이동」과 영상 등록·촬영 기록의 「분석 준비 확인」 중복 버튼을 제거한다.
- 촬영 기록 미확정 안내와 서버 실행 조건은 유지한다.
- 전체 준비 상태·실행 이력 조회용 전처리 메뉴는 유지한다. 탭 진입은 원래 목록, 메뉴 진입은 전처리 목록으로 돌아간다.
- 점수·전처리 생성 규칙·원본·기존 실행 이력·권한은 변경하지 않는다.

## 검증 및 cold review

구현자의 재검토이며 별도 에이전트나 외부 검토자의 독립 승인을 뜻하지 않는다. 변경 diff와 호출 관계를 다시 읽고 참가자·회차, 미저장 입력, 목록 출처, 직접 경로, 실행 복원 경로를 검토했다.

| 발견사항 | 판단 | 조치 |
| --- | --- | --- |
| 설문 회귀 시험이 이전 화면의 `빈칸 사유: 관찰하지 못함` 문구를 찾아 실패 | 수용 | 실제 원응답 표에서 문항과 사유 셀을 검증하도록 수정. 제품의 설문 표시·데이터는 변경하지 않음 |
| 전처리를 참가자 탭으로 편입한 뒤 브라우저 뒤로가기·앞으로가기 검증 부족 | 수용 | 촬영 기록↔전처리 이동 후 현재 탭·위치·참가자 맥락 유지 검증 보강 |
| 전체 전처리 메뉴까지 제거 | 미반영 | 이번 요청은 참가자별 연속 작업 개선이며, 전체 준비 상태·실행 이력 접근은 보존 |
| 전체 실행 중 리포트 재사용 ID가 null로 전송된 시험 1건 | 보류 | 관련 제품·시험 코드는 이번 변경에서 수정하지 않았다. 동일 코드 재실행에서 통과했으나 최초 실패를 삭제하거나 원인 해결로 주장하지 않음. 최종본 선택 후 외부 비교 대상의 비동기 초기화와 재사용 선택 순서는 별도 조사 대상 |
| 추가 제품 결함 | 발견 없음 | 서버 실행 조건·입력 보호·참가자/회차 유지 경로 확인 |
