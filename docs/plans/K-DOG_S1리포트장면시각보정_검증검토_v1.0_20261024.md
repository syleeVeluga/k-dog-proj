## 원인과 수정

실제 AI 분석과 최종본 고정은 완료됐으나 리포트 접수에서 근거 관찰량 검증이 실패했다. 장면 어댑터가 원응답의 클립 내부 관찰량을 직접 읽고 소수점 원본 시각을 더해, 이미 채점 정규화에서 처리한 미세 오차를 다시 만들었다.

원응답 재검증과 채택 페이로드 동일성 검증을 먼저 유지한다. 이후 검증된 정규화 사건을 읽고, 원본 시각 매핑에도 채점 경로와 같은 1e-9초 이내 경계·관찰량 보정을 적용한다. 원응답, 점수, 최종본, 파일 해시와 공급자 요청은 변경하지 않는다. 새 의존성이나 채점 규칙 변경은 없다.

## 검증

- 합성 회귀 두 사례: 클립 내부 관찰량 오차와 원본 시각 덧셈 오차. 수정 전 어댑터에서 두 사례 모두 실패하고 수정 후 통과한다.
- 실제 1밀리초 관찰량 초과는 원응답 재검증에서 거부한다. 기존 채택값 변조 거부와 원본 시각 보존 검증을 유지한다.
- 장면·내용·최종본 프로필 검증 40건 통과. 전체 관련 실행 검증 결과는 아래에 기록한다.
- 참가자 자료와 실제 실행 산출물은 저장소 밖에 보관한다. 이미 완료된 분석과 최종본으로 리포트 발급만 재개한다.
- 전체 관련 97건 통과(59.847초): 장면·내용·프로필 검증·발급·채점. `git diff --check` 및 Graft 그래프 정합성 검사 통과.
