## 구현 순서와 계산 계약

1. 계산은 입력 시트·관찰창·규칙 snapshot을 받고 DB 최신값을 암묵 참조하지 않는다. 결과마다 사용 원코드·원값·상태·사유를 남긴다.
2. 걷기 이동 개26/정지 개36은 거리0/1+근접 예외 ‘해당 없음’만 합산하고 개27=(개26+개36)/6. 보호자 접근은 0이며 분모6 유지, 모든 재확인과 가까운 국면 예외 미기록은 보류한다.
3. 보13=2 주의/3 무효, 개37 제외, 앉기·엎드림 자체 제외 금지를 유지한다. 개의 동시 이동을 추가 필수조건으로 넣지 않는다.
4. W=abs(개58)−abs(개18)와 두 방향 원값은 유지한다. 미접촉/보12=3으로 W를 막지 않는다. V·AW·AY·개32 잠재기·구형 꼬리 차이는 S1 결과에서 제거한다.
5. 개9/10은 새 SEP25 표로 설명한다. 개30/34는 같은 물건·보14=1/2에서 회피 감소/동일/증가를 계산하고 보14=2 주의를 표시한다. BY는 개5/6/30 중 유효2개 이상에서 개5≤−1·개6≤−1·개30≥1을 주저, 개5≥1·개6≥1을 전진 근거로 사용한다. 양 근거가 있으면 ‘자극에 따라 다름’이다. 물건 양수를 전진에 더하지 않는다.
6. 사람 묶음은 개13/14/15/51/52/54/55다. BD/BE는 음쪽 절댓값/양쪽 합, BF는 유효 관찰 수이며 n≥4일 때 각 합/n을 구한다. AX=평균(100−50×abs(x))도 유효4개 이상에서만 계산하고 내부 보조값으로 둔다. AE/AF는 개17/19/22 세 값과 보12=1/2일 때 방향 합으로 계산하며 6으로 나누지 않는다. 사회성%·애착 확정식으로 사용하지 않는다. 발성은 실제 전체 구간과 음성 가용/청취량을 사용한다.
7. 보호자 배점 기회 조건→장면 내 평균→장면 합을 유지한다. 최소3항목·2장면 미달이면 비율도 null. 충분할 때 우세≥60%, 차이≥15%p를 반올림 전 정확히 비교한다.
8. 유효 수동 유형·근거·평가자가 갖춰졌을 때 선택을 적용하고 자동값은 보존한다. 애착은 네 이름 또는 판정보류이며 임의 수치 분기식이 없다. D04 상세 AI 반환은 미확정 상태를 유지하고 S08/S09에서 승인 범위만 연결한다.

## 경계와 인계

S08은 이 계산기를 호출하고 자동4개를 모델에 생성시키지 않는다. S09는 기본 결과를 수정하지 않고 최종 해석을 별도 조립한다. 구판 scoring_v3 결과 조회·호환은 제외하고 대체된 계산 경로와 전용 시험은 호출 관계 확인 후 제거한다. 공통 계산 검증은 S1 기대값에 맞춰 유지한다. S1에서 새로 생성한 결과와 그 revision의 백업·복원·삭제를 함께 확인한다.
