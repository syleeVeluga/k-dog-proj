현재 촬영 계약은 고정 8구간 순서와 기준 영상의 시각을 사용한다. S1에 필요한 근접 예외·시선 전환 사건과 실제 구판 동선을 보존하면서, 관찰 가능한 창만 확정한다.

근거: 통합명세 3~6절·부록 A·D01~D03/D05. 인수: T06·T19·T21·T29.

## 구현 순서와 계약

1. 정상 동선은 입장30/기준20/혼자60/재회30/무시20/걷기30/낯선30/퇴장30초의 안내와 실제 경계를 분리한다. 파일을 250초 등분하거나 이동을 고정5초로 만들지 않는다.
2. 촬영 절차 판본이 확인된 신판이면 정상 순서·중단/생략 규칙을 적용한다. 예비촬영/미확인 판본은 실제 창을 보존하고 호환성·이탈 사유를 표시한다. 새 순서에 맞추기 위해 시각을 수정하지 않는다.
3. 기준 영상과 각 camera offset의 확인 근거를 저장한다. 공통시각과 원본시각을 모두 표시하고 미확인 offset을 확정 근거로 쓰지 않는다.
4. 여섯 걷기 국면에 ‘해당 없음 / 보호자 접근 / 재확인 / 미기록’ 근접 예외를 별도 저장한다. 원거리·원메모를 덮지 않으며 보13 조건과 연결한다.
5. 바46~53은 각 구간 전체의 관찰 가능량·사건 근거를 연결한다. 바54/55에는 첫 명확한 시선 전환, 앞2초/뒤3초, 같은 자세·움직임·꼬리 가시성 확인을 기록한다. 선택 관찰이 없으면 그 항목만 미관찰로 남긴다.
6. 개8 기준 탐색과 환경1, 개12 혼자 전체 탐색, 개10 후기50초 창을 반영한다. 폐기된 직후5초 몸털기·꼬리·개32 전용 창은 S1 실행용으로 만들지 않는다.
7. 개21은 실제 관찰 범위와 사건 시각을 저장하지만 전체30초 집계를 확정 S1값으로 자동 채택하지 않는다. 원전반 배치 출처와 D03 미확정 상태를 명시한다. 보5 복수 사건·대표 범주 동률·최소 관찰량도 임의 종합하지 않는다.
8. 분리 중단 시 실제 재회 시작, 실제 접촉 전/중 중단, 안전조치·요원 지시·가림·음성 손실을 기록한다. 보12/13/14 외 새로운 무효 문턱은 D05 확인 전 추가하지 않는다.
9. R11 안전기지 설명을 위해 접근→실제 접촉→접촉 뒤 탐색 재개의 사건 시각을 선택적으로 기록한다. 개8/12 범주만으로 접촉 후 탐색의 순서를 만들지 않는다. 단계가 관찰되지 않으면 미확인이다. R15의 전환동조·시간근접·머리방향 시계열 및 3초 성공/1초 표집 기준은 미채택 후보로 분리한다.

## 검증과 완료 조건

- 정상·생략·단축·즉시재회·미접촉·접촉 중 중단을 합성 시각으로 검증한다.
- 구판 ‘낯선 사람→재회’ 순서가 새 정상 절차로 오표시되지 않고 실제 시각 그대로 보존된다.
- camera offset 확인 여부와 원본/공통 시각 왕복, 영상 길이를 넘는 사건을 검사한다.
- 재확인·가까운 국면 예외 미기록을 계산 보류로 전달한다. 앉기·엎드림만으로 무효 처리하지 않는다.
- 선택 꼬리 창 앞/뒤가 부족할 때 null, 전체를 못 본 몸긁기는 관찰 사건을 남겨도 0 확정 금지.
- T29의 개21 미승인30초가 정책 대기인 상태를 검사한다. UI 360px·미저장 변경·409·사례 전환을 시험한다.
- 탐색 범주가 있어도 접촉 후 탐색 시각이 없으면 안전기지 순서를 확정하지 않는다. 실제 순서와 반대인 사건·시각 누락도 S10에 미확인으로 전달한다.
