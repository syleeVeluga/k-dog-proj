## 구현 순서와 입력 경계

1. 직접 입력 86개를 숫자83/메모3으로 구분하고 자동4개는 쓰기 금지다. 개59 연결 메모는 별도 보존한다. 필수 입력 부족과 선택 꼬리 미관찰을 구별한다.
2. 구간 순서로 화면을 구성하고 개9 −2→+2, 보10·11·23 +2→−2를 표시한다. 선택 순서가 값·배점을 바꾸지 않도록 원값으로 저장한다.
3. 보5·6·9·14는 입장·퇴장 원근거를 보존하고 퇴장 종합값을 한 번 확정한다. D03 미확정 복수 사건 종합은 자동 규칙으로 만들지 않는다.
4. 값/상태/빈값 사유/관찰 가능량/영상·카메라·시각/평가자를 기록한다. F 관찰 근거와 G 양식 검토메모는 서로 다른 필드이며 G는 분석·보호자 문장의 입력에서 제외한다.
5. 사람/AI 배정·자기 시트만 수정·제출 잠금·명시 공개·실제 열람 노출을 S1 시트에서 검증한다. 과거 비교표 import를 ‘독립 사람 채점’으로 자동 표시하지 않는다. 이전 앱 점수 조회·변환 경로는 두지 않는다.
6. S1 Excel은 문서상 주소와 실제 파일의 D→J 연결·H10:H15·E40 완료 수식·개58/23/보12 문구·예시 메모 여부를 검증한 승인 프로필로만 읽는다. 참가자 이름으로 평가자 빈칸을 메우지 않는다.
7. G01 빈양식이 없으면 수기 입력과 합성 파일 구조 시험까지 완료할 수 있다. **실제 Excel import는 비활성·미검증으로 남기고 운영 완료로 체크하지 않는다.** 이후 원본 수령 시 같은 PR 범위의 검증 기록 또는 후속 원본 연결 변경으로 대장을 갱신한다.
8. 저장·제출·import 확정 전 대상/회차/판본/hash/revision/삭제를 확인한다. 다른 카메라 같은 사건의 원자료 출처는 유지하되 같은 항목의 독립 점수로 중복 합산하지 않는다.

## 검증과 완료 조건

- 숫자83/메모3 입력, 자동4·폐기33·미사용4 입력 차단, 0/null·범주 우선순위·미관찰 사유를 시험한다.
- 전체 관찰 부재0과 일부 관찰 null+실제 사건을 구별한다. 선택 꼬리 없음이 다른 항목 제출을 막지 않는다.
- 합성 Excel의 D/F/G/J 및 예시 메모 잔재를 검출한다. 실제 빈양식 없이 G01/G04 통과라고 기록하지 않는다.
- 같은 슬롯·다른 batch/파일을 분리한다. S01 초기화 뒤 S1 시트는 전 항목 null이며 같은 정의를 포함한 이전 앱 점수가 현재값으로 유입되지 않는다.
- 미공개 타평가 기록·AI 결과가 시트/import/다운로드 경로에서 누출되지 않는다.
- 동시 수정·제출 후 수정·재개방·삭제·복원과 360px 입력 화면을 검증한다.

## 경계와 인계

S07에 유효 S1 원자료 snapshot을 전달한다. 세 비교 파일의 누적 AI/사람 값을 정식 검증 쌍으로 분류하는 도구는 S14에서 구현한다. 완료 의견은 S09의 별도 레코드로 저장하며 원점수를 덮지 않는다.
