## 문제와 결과

현재 report_v3는 비활성이고 새 리포트 메뉴가 없다. S09 최종 결과를 선택해 S10 작성/검증→S11 HTML/PDF 생성으로 이어지는 명시 실행과 불변 발급 이력을 제공한다.

근거: 통합명세 1·9~12절, 운영 요청 4항. 기존 C07A 실행 보호·C10 계획을 재사용한다.

## 구현 순서와 실행

1. 생성 요청은 대상/회차와 FinalResult·설문·문장/선택 기준·템플릿·비교집단(없으면 명시 없음)·모델/프롬프트 snapshot을 고정한다. 최신 의견·설문을 실행 중 다시 읽어 섞지 않는다.
2. 계획 단계는 내용 작성→내용 검증→렌더→출력 검증→게시다. 프로그램 단계와 공급자 호출을 구분하고 비용/시간을 각각 기록한다. 구조는 S08 공통 실행 보호를 재사용한다.
3. 조회·메뉴 재방문은 실행을 만들지 않는다. 명시 request ID는 중복 생성에 대해 동일 실행을 반환한다. 중지·재시도는 고정 입력을 유지하고 입력 변경 후 재생성은 새 실행이다.
4. 출력 검증 실패는 실패/검토 필요 상태로 남기며 정상 발급 버튼을 열지 않는다. 유효한 영역이 일부뿐인 리포트는 명세의 부족 안내를 사용하여 생성할 수 있다.
5. HTML/PDF/사진/출처 manifest를 불변 폴더에 저장하고 hash를 고정한다. 파일이 전부 준비되기 전 최신 정상 출력으로 게시하지 않는다.
6. 원본·의견 수정 후 기존 발급본은 ‘이전 기준/이전 입력’으로 표시하고 새 발급본과 구분한다. 철회된 동의·삭제 상태에서는 과거 파일 다운로드도 서버에서 차단한다.
7. UI에 4결과 요약, 생성 상태·오류 사유·재시도, HTML 조회·PDF 저장·인쇄와 이력을 제공한다. 발급 시점·사람 승인 대기는 운영 확인대장의 정책이며 모든 출력에 사람 승인을 일괄 강제하지 않는다.
8. 외부 전달/메일 자동 발송은 포함하지 않는다. 메인 PC가 중앙 서버의 결과를 조회·인쇄하는 요청 범위를 구현한다.

### 2026-10-04 구현·독립 검토 결과

`report_runs_v4.py`와 도메인, 공통 Worker/analysis/API를 연결했다. 명시 FinalResult·입력·의견·설문·프로그램 기준·템플릿·사진 원본을 고정하고 내용 작성/내용 검증/렌더/출력 검증/게시의 다섯 단계를 수행한다. S13 비교 집단 선택을 고정하는 계약과 backend 기반은 상호 의존성을 깨지 않도록 함께 선행 반영했다. 실제 연구 승인은 포함하지 않는다.

- 독립 cold reviewer가 실행·도메인·Worker 채택·API 다운로드를 대조하고 `tests.test_report_runs_v4` 20개를 별도로 실행해 통과했다(90.769초). 실제 렌더러를 쓰는 `tests.test_report_api_v4` 1개도 통과했다(6.717초). hash 변조·입력 변경·삭제/동의 철회·늦은 점유권·중지/재시도·명시 내용 재사용·원자적 게시·이전 발급 bytes 보존을 포함한다. 공급자 호출은 0회다.
- `npm run build`와 `tests/report-v4.spec.ts` 3개를 통과했다(29.3초). 실제 API로 단일 큐·응답 유실 멱등·중지/고정 재시도·타인 최종본 명시 공개를 검증했다. 발급 완료 UI는 명시한 합성 응답과 실제 S11 HTML로 4카드·6섹션·PDF 저장·인쇄·이전 발급·360px·403 후 출력 비움을 검증했다. 브라우저 서버는 Worker를 실행하지 않으므로 실제 게시 검증은 앞의 Worker/API 시험과 구분한다.
- 리뷰에서 생성 전 `normal_publish_available` 표시, iframe 인쇄 뒤 focus 갱신이 첫 클릭을 가리는 문제, 다운로드 오류 처리와 사유 라벨을 수정하고 재검증했다. 독립 최종 검토의 추가 P1/P2는 없었다.
- G02 문장은행 승인이 없다는 이유로 모든 정상 출력을 막지 않는다. 명세로 검증한 프로그램 설명과 완료된 사람 원문은 정상 발급하며, 내용 검증 오류는 게시를 막는다. 원문 자유서술 전반의 진실성·실제 AI 품질은 S16 실측/검수 대상이다.
- HTML은 외부 자원 없이 생성하며 inline 보기에서 script를 금지하고 내장 CSS/font/image만 허용한다. PDF·HTML·manifest 다운로드는 매번 현재 권한·삭제·동의·명시 공개를 확인한다. 메일/외부 전달은 수행하지 않았다.
