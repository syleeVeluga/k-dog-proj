버전: v1.0 · 2026-10-03 · 상태: 구현·자동 검증 완료, 실검수 별도 · 선행: S02·S05·S08·S09 · 기준: main 3654596

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20261003.md). 공통 검증·리뷰·버전 확인·저장 보호는 상위 §7을 적용한다.

## 문제와 결과

계산·유형이 같아도 리포트 문장과 장면이 각각 생성되면 모순이 생긴다. 하나의 최종 결과에서 출처가 연결된 문장·장면·총평·실천1~3개를 만드는 검증 가능한 중간 데이터를 만든다.

근거: 통합명세 10절, 산출근거 ‘리포트 출력 연결’·‘피드백 전체목록’, G02. 인수: T16·T21~T24·T27·T31.

## 구현 순서와 중간 계약

1. 입력은 FinalResult/설문 집계/촬영 batch/허용 장면/승인된 비교 데이터의 고정 snapshot이다. 타평가 독립 시트·G 검토메모·예시 관찰 메모는 입력하지 않는다.
2. 출력은 4개 결과 카드, 장면 최대3, 설문/영상 비교, 관계·걷기·환경 상세, 총평과 실천 제안이다. 각 수치/유형/주요 서술에 근거 참조를 붙이고 부족한 부분은 상태·범위 안내로 표시한다.
3. 장면 후보는 같은 개체·회차의 유효 원본/카메라/실제 시각/항목을 요구한다. 완료 의견 지정 장면 우선→전후 변화와 서로 다른 영역 우선→다중 카메라 중복 제거→동률 이른 시각을 적용한다.
4. 겹친 시각만으로 다른 행동을 같은 사건으로 합치지 않는다. S05/S08의 공통 사건 근거를 이용하고 모호한 중복은 선택 검토 상태로 남긴다. 1~2개는 있는 만큼, 0개는 안내이며 장면을 창작하지 않는다.
5. 피드백126개는 후보 데이터로 취급한다. 근거 조건과 선택 규칙을 버전 관리하고 전부 출력하지 않는다. 실제 문장 은행이 아직 없어도 명세가 허용한 AI 설명을 검증 후 사용할 수 있으며 이를 교수님 확정 문구로 표시하지 않는다.
6. D39의 완료 도움 의견을 우선하고 같은 최종 결과에서 실천1~3개를 연결한다. 수치·진단·사건을 추가하지 않으며 몸 표현은 관계·장면에만 통합한다.
7. 허용 유형·값/분모·단위·출처·null 표현·금지 내부 문구·서로 다른 척도 합성·최종 유형과의 명시적 모순을 검증한다. 근거 ID만 붙였다고 모든 자유문장의 사실성이 입증됐다고 보지 않는다.
8. 실패한 문장/장면을 분리해 제한된 수리 또는 재검토로 돌린다. 오류가 남은 설명을 정상 발급으로 게시하지 않는다. 정상 결과에 일괄 사람 승인을 새 필수조건으로 추가하지 않는다.
9. R11은 S04의 접근·접촉·탐색 재개 시각이 있을 때만 순서대로 설명한다. R12의 개19는 음쪽 붙음/양쪽 물러남, 개51은 반대 방향이므로 행동 문구로 비교한다. 보호자15초/낯선사람최대3초와 기회 차이를 병기하고 코드 차이를 선호량으로 만들지 않는다. R15 후보와 R23 옛 견본 점수는 현재 점수·검증된 지표로 출력하지 않는다. Q12 소음은 직접 대응 영상 과제가 없음을 유지한다.

## 검증과 완료 조건

- 교육태도 의견으로 유형이 달라지면 카드·본문·총평·조언이 같은 최종 유형을 사용하고 원비율은 유지한다.
- 네 카드 중 일부 자료 부족, 사회성 한 하위영역만 유효, 선택 꼬리 없음, 전부 결측을 각각 시험한다.
- 같은 사건3CAM/서로 다른 사건/동률/유효 장면0·1·2·3이 선택 규칙을 따른다.
- ‘찾고, 차분히 재회’가 제5애착 유형이 되지 않고 ‘작성 필요’·예시 메모·G열 메모가 출력되지 않는다.
- 없는 수치·타영상 시각·존재하지 않는 사건·미정 기준 확정·근거와 모순된 문장을 넣은 오류 주입 fixture를 검출한다. 의미 검증의 잔여 한계는 S16 실검수에 남긴다.
- 같은 content/selection 버전과 입력 snapshot은 선택 결과·계산값이 재현된다. 모델 문장 변동은 별도 실행 이력으로 남긴다.
- 개19=−1·개51=+1을 모두 붙는 방향의 관찰로 해석하고 −2의 선호 차이로 출력하지 않는다. 탐색 시각 없는 안전기지 순서, Q12의 가상 소음 과제, 옛 83% 전환/90% 시간 지표의 개27 대체를 거절한다.

## 경계와 인계

S11은 이 데이터를 렌더할 뿐 재판정하지 않는다. S12가 네트워크 호출·재시도·비용 상한과 저장을 담당한다. 실제 문장 은행의 제공/수정은 G02 대장에 기록한다. 자유문장 완전 자동 사실 검증을 보장하지 않는다.
