## 1 이번 작업과 후속 작업의 구분

2026-10-03 사용자는 `docs/개발반영_20261003`의 구현 완료를 목표로 단계별 구현·cold review를 진행하되, 실측이 필요한 항목은 별도 정리하고 이후 샘플 영상 등으로 진행하도록 지시했다. 이 대장은 그 후속 범위를 기록한다. S00~S15의 실측 외 구현·자동 검증·cold review와 S16 준비 도구, S17 승인 조건부 출력 구조는 완료했다. 최종 전체 backend685개·브라우저41개·현재 Windows의 실제 ZIP 새 설치를 통과했다. 문서 작성만으로 완료 처리하지 않고 [구현 실행 기록](K-DOG_구현실행기록_v1.0_20261003.md)과 [인수 검증 대장](K-DOG_인수검증대장_v1.0_20261003.md)에 실제 근거를 연결했다. 아래 실측·자료·정책 확인의 남은 부분은 계속 후속이다.

- **구현·검증 범위:** 확정된 규칙의 코드, 합성 입력·공급자 fixture를 통한 계약/회귀 검증, UI/PDF 시각 검수, 배포·복구 구조, 실측 준비 도구와 결과 기록 틀. 단계별 완료 근거는 해당 문서와 인수 검증 대장에 기록했다. 최종 전체 회귀·배포물 검증은 S15 기록을 따른다.
- **실측 후속:** 실제 영상·장비·네트워크·사람 확정 관찰을 필요로 하는 품질·시간·호환성·운영 검수. 이번에 실행하지 않은 결과를 합성 시험으로 대체하지 않는다.
- **자료·정책 확인 후속:** 고객 원본 부재, 미확정 산식/관찰창, 연구자 확인과 사용 조건. 실측을 뒤로 미룬 지시는 이 항목의 승인 또는 임의 규칙 확정을 뜻하지 않는다. 해당 기능만 보류하고 나머지 확정 기능은 진행한다.

완료 상태는 `코드·합성 통합`, `실제 LAN·설치`, `참가자 영상 품질·시간`, `정책·원본 확인`, `외부 비교 승인`으로 구분한다. S16 실측과 S17 실제 활성화를 다른 구현 단계의 순환 선행조건으로 만들지 않는다. [S15](K-DOG_PR-S15_배포와통합인수_v1.0_20261003.md)의 현장 운영 인수와 [S16](K-DOG_PR-S16_원본압축본과360도실증_v1.0_20261003.md)·[S17](K-DOG_PR-S17_외부비교활성화_v1.0_20261003.md)의 완료는 각각 독립된 근거가 필요하다.

아래 E/P번호는 이 후속 대장만의 관리 번호이며 고객 원문의 D/G번호, 요구사항 R번호, 인수 T번호, 운영 O번호를 대체하지 않는다.

## 5 후속 재개 순서와 기록

1. **접수와 사용 범위 확인:** 후속 관리 ID를 선택하고 필요한 자료·장비·확인 회신을 받는다. 대상/회차 대응·촬영/설문/채점 판본·평가자/동의·외부AI 허용 범위를 확인한다. 동의나 규칙을 추정하지 않는다.
2. **입력 고정:** 보호된 원본 위치·hash·파일/시트/셀·실제 관찰창과 카메라/파생 계보를 기록한다. 참가자 자료는 저장소와 배포물에 포함하지 않는다. 확인된 원본과 실행 snapshot을 고정한다.
3. **조건 고정:** 앱 commit·모델/API·프롬프트·설정·카탈로그/계산·설문/집계·촬영·문장/선택/템플릿 버전을 기록한다. 필요한 반복 횟수·호출예산·측정 범위와 허용된 실행 조건을 먼저 정한다.
4. **부분 시험부터 수행:** E01 파일 호환성→E02/E03 부분 파이프라인→E04/E05 종단 실측 순으로 진행한다. 자료가 있는 조건만 수행하고 없는 조건은 부족 자료와 함께 미실행으로 유지한다. E09/E10 현장 운영과 P06 연구 확인은 각자의 조건이 충족되면 별도로 진행한다.
5. **독립 검수와 수정:** 실행자와 구분한 cold review로 원문 기대·출처/분모·시각 대응·출력·계량을 확인한다. 발견사항의 수용/보류/거절 이유, 수정 위치, 관련 재시험 결과를 남긴다.
6. **대장 반영:** 본 대장과 인수 검증 대장·해당 S계획의 실제 결과를 연결한다. 정책 변경은 결정 근거와 새 판본의 기대값을 추가하고 기존 결과를 소급 덮어쓰지 않는다. 고객에게 자동 발송하지 않는다.

각 후속 실행은 다음 필드를 사용한다.

### 2026-10-04 E01~E07 준비 도구

S16의 `scripts/benchmark_s1.py`는 읽기 전용 입력/설정/hash·짝지음·계량 검증과 비식별 요약 틀을 제공한다. 25개 합성 회귀에서 필수 세 행의 미측정 사유, 중첩 시간/벽시계 분리, 실제 대응 구간/FPS·계보·판본·현재 동의/권한, S14 최초 AI/독립 사람의 항목별 분모를 확인했다. 독립 검토에서 발견한 offset 부호/확인 출처 오류를 수정하고 재검증했다. 명령과 입력 계약은 [S16 구현 기록](K-DOG_PR-S16_원본압축본과360도실증_v1.0_20261003.md)에 있다.

이 기록은 E01~E07, P01/P09의 실측·확인을 종료하지 않는다. 재개 시 실제 파일과 확정 사람 근거, 같은 시계로 수집한 시작/종료 로그, 실행 환경·반복/예산을 먼저 채운다. 약1GB×1·약1GB×3·200~300MB×3의 일부가 없으면 다른 행의 시간으로 대체하지 않는다. 실제 INSV 변환/판독 및 사건·문장 의미 검수도 계속 별도 후속이다.
