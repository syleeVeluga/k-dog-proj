## 구현 순서와 조건

1. 자체 집단은 같은 설문 원문 판본과 집계 정책의 명시한 실제 응답으로 구성한다. 개체 중복과 여러 회차는 포함 규칙이 확인된 선택 목록으로 고정하고 카메라 수를 표본수로 세지 않는다.
2. 영역별 유효 평균과 n, 포함/제외 사유·선택한 회차/hash를 저장한다. 전체 등록 수를 모든 영역의 n으로 재사용하지 않는다. 응답 변경 후 집단 재계산은 새 snapshot이다.
3. 4쌍 예비 사례를 전체 규준·정규분포·백분위로 제시하지 않는다. 예비 1~5 편안함과 새0~4 두려움 집단 혼합을 차단한다.
4. 외부 출처는 원논문·표·원문 문항·척도·방향·유효 n·사용/번안 조건·확인자·확인일·적용 범위를 기록한다. 값만 입력했다고 활성화하지 않는다.
5. 명세 참고값 0.66±0.91/n42,926와 1.03±0.78/n42,764, 전체43,517은 서로 다른 필드다. 미승인 상태로 보존하고 사용자 리포트에 내보내지 않는다.
6. 국내 교육/친밀감 참고값을 미국 두려움 그래프나 S1 영상 지표에 혼합하지 않는다. 필요한 대상 정보가 없으면 국내 대상 적합성을 추정하지 않는다.
7. HTML/PDF/API/export 모두 같은 승인 gate를 사용한다. 승인 철회/범위 변경은 새 출력에 적용하고 기존 발급 이력·당시 출처는 남긴다.
8. 관리자 설정을 통한 기술 활성화와 연구자의 문항 동등성/사용 조건 확인을 구분한다. 문헌 확인을 앱이 자동 승인하지 않는다.

## 검증과 완료 조건

- 같은 원응답·같은 선택 집단에서 평균/n이 재현되고 중복 개체·카메라가 n을 늘리지 않는다.
- 일부 결측은 해당 영역의 n에만 영향을 주고 미정 부분평균은 산출되지 않는다.
- 구판/수정 문항/서로 다른 방향·척도를 혼합하면 차단 사유가 남는다.
- 미승인 외부 값은 API·HTML·PDF·연구 export의 최종 비교값에 나오지 않는다.
- 승인 범위와 정확히 일치하는 합성 fixture만 통과한다. 이 시험이 실제 연구 승인으로 기록되지 않는다.
- 집단 변경·대상 삭제·동의 변경·손상 hash·백업/복원을 검증한다.

## 경계와 인계

실제 활성화는 S17의 문헌/연구 확인 자료가 갖춰진 뒤 수행한다. 그 전에도 외부 비교를 제외한 정상 리포트는 생성 가능하다. 통계 유의성·진단 정확도·백분위·ICC 계산은 이 PR에 추가하지 않는다.
