버전: v1.0 · 2026-10-03 · 현재 상태 갱신: 2026-10-07 · 상태: 기존 구현·검증 이력 유지, 리포트 요구사항 재확정 필요

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20261003.md), [원본 자료](K-DOG_원본자료목록_v1.0_20261003.md), [인수 검증](K-DOG_인수검증대장_v1.0_20261003.md). R번호는 산출근거 Excel의 ‘산출 규칙’ 시트다. 아래 담당 S번호는 새 PR 번호이며 Excel의 S01~S07 **출처 문서 번호와 다르다**. Excel 리포트 T01~T04도 통합명세의 인수 T01~T32와 별도 식별자다.

S00~S15의 실측 외 구현·검증·cold review를 완료했다. 최종 전체 backend685개(780.886초)·브라우저41개(3.7분), 현재 Windows의 새 경로·가상환경에서 실제 ZIP 설치 검증을 통과했다. S16 준비 도구와 S17 승인 범위의 조건부 출력 경로도 구현·합성 검증했다. 실제 영상 실측·깨끗한 OS/물리3PC와 D06 연구 승인·활성화는 완료하지 않았다. 아래 R25개는 요구사항 연결표이며 개별 시험 결과는 인수 검증 대장 §5, 단계별 commit·최종 근거는 [구현 실행 기록](K-DOG_구현실행기록_v1.0_20261003.md)을 따른다.

**2026-10-07 추가 지시:** 리포트의 상세 요구사항은 재확정이 필요하며 상당수 항목이 축소·취소될 수 있다. 대상 미정 상태를 일괄 취소로 처리하지 않는다. ‘오늘의 장면들’ 제거와 예시 디자인·레이아웃 미준용은 확정됐으며 HTML/PDF 산출은 유지한다. [확인사항과 적용 경계 §0](K-DOG_확인사항과적용경계_v1.0_20261003.md#0-2026-10-07-리포트-요구사항-재확정-기록)에 확정 변경·미정 범위·영향을 기록한다. 아래 기존 구현 연결과 시험 이력은 새 리포트 개편 완료를 뜻하지 않는다.

주요 영향은 S10~S12의 리포트 구성·문장·출력과 S13/S17의 비교다. D04/R05는 애착 해석·최종 판정, D05/R02는 설문 부분 응답 계산까지 연결되므로 리포트 항목 축소와 별도로 판단한다.
