## 문제와 결과

기본 계산·수동 판정은 있으나 완료 의견과 행사 최종 결과는 없다. 영역별로 완료 의견→유효 유형 선택·근거·작성자→AI 기본 결과 순서를 적용하고 원점수·자동비율을 보존한다.

근거: 통합명세 9절·10절, D04. 인수: T11~T13·T16·T24·T32. S08의 실제 AI가 없어도 S07 기반 결과 fixture로 구현할 수 있다.

## 구현 순서와 상태

1. 영역은 애착·교육태도·사람 반응·비사회적 반응·환경·성향의 6개다. D39 우선 도움은 부속 정보이며 일곱 번째 완료 필수 영역이 아니다.
2. S1 C31 평가자·D33~38 의견·D39 도움·B40 요청 상태·E40 실제 완료 판정에 대응한다. 완료는 평가자와 여섯 영역 중 하나 이상 또는 유효 입장 선택/근거가 필요하다. B40만 완료/D39만 작성은 불충분하다.
3. 전체 기록의 완료 여부와 영역별 의견 유무를 구분한다. 한 영역만 완료돼도 그 영역만 우선 적용하고 나머지 영역의 유효 선택값을 확인한 다음 AI 기본값으로 내려간다.
4. 유형을 명시한 의견은 허용 이름·근거·작성자를 검증한다. ‘찾고, 차분히 재회’는 관찰 요약으로만 보존한다. 유형 없는 서술의 최종 유형 자동 추출은 D04 확인 전 검토 상태로 보관하고 승인된 기능처럼 확정하지 않는다.
5. 하나의 FinalResult snapshot에 기본 시트/계산/판정, 사용 의견 revision/hash, 적용 출처, 보류 사유를 고정한다. 의견 때문에 원비율을 100%로 바꾸거나 사람 점수를 AI 원자료에 덮지 않는다.
6. 의견 철회/재개방 후 다음 최종 결과는 남은 유효 선택/기본 결과로 돌아간다. 이전 최종 결과와 발급본은 불변이며 새 결과에서만 반영한다.
7. 독립 전문가 시트를 ‘가장 최근 사람 final’로 자동 채택하지 않는다. 행사 기본 입력은 명시적으로 선택하고 연구 노출 정책을 우회하는 조회를 만들지 않는다.
8. 조립 중 수정·삭제·hash 불일치는 충돌/중단으로 처리한다. 최종 결과·의견·부모 참조를 maintenance에 함께 등록한다.

## 검증과 완료 조건

- 의견 없음/교육태도만 완료/작성중/D39만/유형 변경/철회 6경로를 검증한다.
- 완료 의견 없는 영역의 유효 수동 선택이 AI보다 우선하고, 근거/평가자 누락 선택은 적용되지 않는다.
- E40에 대응하는 완료가 false이면 B40 요청만으로 최종 결과에 반영되지 않는다.
- 6영역 전부 완료·사람 final·유형 확정을 리포트 생성의 추가 필수조건으로 만들지 않는다.
- 기본 시트·계산 hash와 비율이 의견 전후 동일하다. 최종 결과의 출처와 이전 발급본이 보존된다.
- T32는 D04의 승인 전/후를 분리해 시험한다. 미확정일 때 전체 출력 대신 해당 유형 자동화만 보류되는지 확인한다.
- 권한·AI 공개 정책·동시 수정·삭제·백업/복원과 모바일 의견 입력을 검증한다.
