## 범위

사용자가 독립 리뷰 에이전트 사용과 발견사항 수용 검토 후 로컬·원격 병합을 요청했다. 독립 리뷰어는 구현 설명을 받지 않고 diff와 현재 S1 계약을 읽기 전용으로 검토했다. graft의 코드 범위·호출 관계와 합성 재현을 사용했으며, 참가자 영상·상세 응답·개인정보를 읽거나 공급자에 보내지 않았다.

공급자 응답 스키마, 기본 프롬프트, 실제 계약 오류 전달, 공통 사건 근거 정규화와 장면 연결을 검토했다. 기존 영상 변환 도구 및 그 문서·ignore 변경은 별도 사용자 작업으로 보존한다. 앞선 영상 진단의 원요청·응답·수치는 변경하지 않는다. 현재 리뷰는 실제 행동 정확도·S16 인수·운영 앱 배포 검증이 아니다.

## 검증과 재검토

- 수정 전 합성 재현: 동적 추가 필드 마스킹 시험 실패와 다른 설명의 공통 사건 리포트 시험 오류를 확인했다. 기존 일반 장면 ID 시험은 통과했다.
- 수정 부위: 정규화16·장면15, 총31개(2.826초) 통과. 다른 설명의 3CAM 연결·사람 지정 우선순위·단일 공통 장면·두 설명 보존과 기존 일반 장면 ID를 검증했다. 원본 ID/hash·카메라·창·시작/끝·관찰초 변경 7종은 계속 거절한다.
- 수정 전 관련 회귀: 정규화·실행·공급자·설정·제품 API·장면56개(72.681초) 통과. 이 통과만으로 새로 발견한 두 결함을 검증한 것으로 보지 않는다.
- 수용 수정 후 관련 회귀: 정규화·실행·공급자·설정·제품 API·장면59개(86.090초) 통과.
- 독립 재검토: 정규화·장면31개(2.657초) 통과. 추가 필드의 민감 이름 제거를 루트와 중첩 위치 8종에서 확인했다. 두 P2 모두 해결했고 검토 범위에 미해결 결함은 없다. `graft check`와 `git diff --check`도 통과했다.
- S1 원본 대조: `python -X utf8 -m app.import_catalogs --spec 20261002 --check`로 자산8개 통과. G01/G04 실제 입력 workbook 미수령·주소/산식 미확정·Excel import 비활성 경계는 유지한다.
- 참가자 실영상/유료 공급자 호출0. 합성 공급자·로컬 제품 API 시험과 실제 외부 Gemini 검증을 구분한다. 기존 사용자 작업의 파일 해시를 따로 보존하여 병합 후 대조한다.

## 의존성과 병합 범위

2026-10-05 [공식 PyPI](https://pypi.org/project/pydantic/)의 최신 안정판과 선택한 잠금은 Pydantic2.13.5이다. [공식 BaseModel API](https://docs.pydantic.dev/latest/api/base_model/)의 `model_dump(exclude=...)`와 [Gemini 구조화 출력](https://ai.google.dev/gemini-api/docs/structured-output)의 `required`·`enum`·`anyOf` 지원을 확인했다. 패키지·잠금·SDK 추가나 업그레이드는 없다.

이번 제품 변경과 시험·S08/리뷰 기록만 commit한다. 원격 기본 브랜치는 `main`이며 시작 시 로컬/원격 기준 commit이 같았다. 최종 commit·PR 및 원격 상태 확인은 병합 준비 후 기록한다. UI·배포 ZIP·운영 앱 활성 설정과 점수는 변경하지 않는다.
