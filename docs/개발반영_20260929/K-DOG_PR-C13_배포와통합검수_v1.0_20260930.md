# PR-C13 배포와 통합 검수

버전: v1.0 · 2026-09-30 · 상태: 구현 전 · 선행: C00~C12(C07A·C07B 포함) · 추정: 2~3개발일

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20260930.md). 근거: 00 §7의 출력 8사례, 기존 설치·복구·삭제 보호. 권장 제목: `release: 새 판본 설치 패키지와 통합 리허설 검증`.

## 문제와 결과

현재 리허설은 구판 8구간 순서, 전 문항 1~5·해당 없음, 설문 분리 유형과 전처리까지 시험한다. 기존 시험이 통과해도 새 채점·의견·리포트를 검증한 것은 아니다. 깨끗한 설치와 신구 판본이 섞인 자료로 입력부터 출력·복구까지 확인한다.

## 구현 순서와 경계

1. 운영 전환판 C00~C04가 완료될 때 설치·판본·전처리·백업/복원 검사를 앞당겨 수행한다. 전체 기능 구현까지 기다리지 않고 촬영 전 설치 문제를 확인한다. C13 완료 시에는 추가된 채점·의견·출력까지 다시 통합 검수한다.
2. 합성 정상 절차와 분리 생략·단축, 미접촉·접촉 전/중 중단, 복지 신호 뒤 안전조치의 태도 배점 제외, 먹이 사용·경로 이탈, 물건 제거·걷기 무효·설문 부분응답을 리허설에 추가한다. 먹이 사용 등 불명확한 추가 무효 조건은 임의로 만들지 않고 C03·C06의 확정 기준과 보류 상태를 따른다. 같은 창의 AI·전문가 2인 시트, 일부 영역의 완료 의견, 유형 변경·재발급·연구 내보내기를 연결한다.
3. 새 실행자료 폴더·DB 표·manifest의 백업/복원, 미참조 파일 정리, FK 삭제 순서, 삭제 기록 재적용을 확인한다. 실행자료·키·영상·참가자 정보는 ZIP와 소스에 넣지 않는다. 합성 시트·영상·메모가 실참가자 자료와 섞이지 않도록 리허설은 임시 데이터 폴더를 사용한다.
4. HTML·CSS·SVG·폰트·문장 JSON, 카탈로그·연결자료·규칙을 패키지에 포함한다. 필수 자산 누락은 시작 점검에서 알린다. 실제 ZIP를 새 폴더와 한글 경로에 설치해 접수부터 출력·재시작까지 수행한다. 앱 미리보기와 다운로드한 단독 HTML의 로컬 자산·글꼴 대체·인쇄도 확인한다.
5. 데이터 이관은 지원하는 DB 버전과 원본 해시를 검증하며 미래 버전 DB의 쓰기를 차단한다. 새 계약의 데이터를 구판 앱에 그대로 되돌리지 않는다. 실행파일을 되돌려야 하면 직전의 검증된 백업과 함께 복원하는 절차를 문서화한다.
6. 문헌 미승인 비교, 실제 영상 미검증, 동의·발급 운영 조건 미확정 상태를 운영 안내에 남긴다. 가짜 공급자 응답을 실제 모델 검증처럼 표시하지 않는다. 유료 공급자 호출은 리허설의 기본 동작에 넣지 않는다. 비활성 기능은 UI뿐 아니라 API·HTML·인쇄·내보내기에서도 차단되는지 확인한다.
7. 본촬영 인원과 처리량은 재확인한다. 합성 대량 시험은 목록·입력·출력·백업 처리와 화면 응답을 검증한다. 실제 영상 AI 처리시간과 72쌍의 당일 처리 가능성은 실측 전에 보장하지 않는다. 리허설·최종 확인 담당자·발급 조건을 임의로 확정하지 않는다.

## 검증과 완료 조건

- 백엔드 전체 시험, 신구 원본 대조, 프론트 빌드·e2e, `git diff --check`가 통과한다. 구현에서 사용한 라이브러리·공급자 API의 버전 확인 기록과 리뷰 수용 기록이 갖춰진다.
- 00 §7의 출력 8사례를 시험 입력·문서/셀 기대값·실제 계산/리포트로 대조한다. AI 계약 시험, 합성 리허설, 실제 자료 검증 기록을 구분한다.
- 깨끗한 ZIP 설치에서 자산·기동·DB 이관, 신구 목록, 접수·설문·촬영·전처리·시트·의견·리포트·내보내기, 재시작·백업/복원이 동작한다.
- 삭제 요청 중 실행·다운로드, 손상 해시·자산 누락·디스크 부족·중단, 이전 점유 토큰·이전 기준 출력·재발급 이력을 시험한다.
- 실제 브라우저 인쇄에서 한글 글꼴·긴 문장·그래픽·페이지 나눔·잘림을 확인한다. 원문이 확정하지 않은 A4 2~3장 제한을 강제하지 않는다.
- Q09·Q11·Q12의 운영 조건과 리허설·최종 확인 기록을 남긴다. 미확정·미검증이 남으면 해당 기능의 운영 사용을 보류한다. 구조 구현과 합성 통합 검수는 독립적으로 완료할 수 있으며, 보류 기능·이유를 인계한다.
