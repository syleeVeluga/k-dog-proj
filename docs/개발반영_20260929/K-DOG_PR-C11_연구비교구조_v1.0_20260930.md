# PR-C11 연구 비교 구조

버전: v1.0 · 2026-09-30 · 상태: 구조 구현 전, 실제 비교값 미승인 · 선행: C02·C09·C10 · 추정: 1~2개발일

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20260930.md). 근거: 00 §6, 03의 설문 집계·비교 조건, 07 §3.4. 권장 제목: `feat: 승인 전 비교값을 차단하는 리포트 비교 구조`.

## 문제와 결과

미국·국내 연구값의 원문 검증과 번안·적용 조건 확인이 완료되지 않았다. 비교 데이터 구조와 검증·승인 차단을 구현하되, 보호자 출력의 실제 비교값 표시는 비활성으로 둔다. 구판 34명 자료, 7개 하위영역 평균, 정규분포 곡선을 재사용하지 않는다.

## 구현 순서와 경계

1. 데이터에 문헌·표·원문 문항·번안·척도·집계/결측 정책·표본 n·기준일·원문 검증자/일자·승인 상태를 둔다. 고객 수치가 있다는 이유로 승인된 값으로 간주하지 않는다. 검증된 적용 범위가 없으면 비교 정책을 비활성으로 유지한다. 내부 확인 화면의 출처 자료와 보호자에게 표시하는 운영값을 구분한다.
2. 미국 비교는 Q10·11과 Q12~14의 각 0~4 축에서 당사자·동일 판본 조사집단·미국 연구 평균의 세 점을 표현한다. 두 하위척도를 합치거나 영상 원코드를 같은 축으로 환산하지 않는다. 조사집단 평균이 없으면 그 점을 생략한다. 국가 정상치·백분위·진단 경계를 만들지 않는다.
3. 당사자와 조사집단은 문항·번안·척도·결측 규칙이 일치해야 한다. 두려움 하위척도 내 한 문항이라도 비면 해당 척도는 결측이며, 유효한 응답 0은 완전응답 집계에 포함한다. 하위척도마다 유효 응답자 수를 따로 계산하고, 원응답·집계 스냅샷·해시·기준일을 고정한다. 비교 표시가 비활성이어도 원응답 저장과 승인되지 않은 집계 결과의 내부 검증은 가능하다.
4. 조사집단의 표본 단위와 회차 선택은 명시한다. 재촬영·여러 카메라를 독립 참가자로 중복 계수하지 않는다. 관리 주체나 포함할 회차가 정해지지 않았으면 임의로 최신 회차를 골라 운영 평균을 만들지 않고, 조사집단 평균을 미확정으로 둔다. 구판 설문·서로 다른 문항 구성·기준일 밖 자료는 포함하지 않으며 제외 사유를 남긴다.
5. 국내 네 값은 Table 8의 두 집단 n=159·141을 가중하고 문항 수로 나눈 재구성 참고값이다. 국가 규준으로 명명하지 않는다. 수정된 Q7·8·20, 늦게 데려온 대상, 원문·번안·사용 조건의 비교 허용 범위를 확인한다. SD나 분포도 검증 없이 재구성 평균에서 추정하지 않는다.
6. 국내 사회화 비교는 나이와 함께 산 기간으로 데려온 시기를 구분한다. 현재 정수 `age_years`와 자유문자 `years_together`만으로는 월 단위 데려온 나이를 확정할 수 없다. 월 단위 값·대상 구분 기준이 확인되지 않으면 비교 적합성을 ‘미확인’으로 둔다. 자유문자를 임의 파싱하거나 ‘어릴 때’의 나이 문턱을 만들지 않는다. 후속 입력에서 월 단위 값이 확보되더라도 기존 결측을 자동으로 채우지 않는다.
7. 원문 수치·수정 문항 적용·사용 조건이 확인된 뒤 별도 [C14 확정 PR](K-DOG_PR-C14_비교근거확정_v1.0_20260930.md)에서 해당 영역만 활성화한다. C11은 비활성 구조와 차단 시험이 통과하면 완료할 수 있으며, 운영 비교값 승인 완료로 표시하지 않는다.

## 검증과 완료 조건

- 비활성·미승인 값이 보호자 HTML·요약·인쇄·전달용 내보내기에 노출되지 않는다. 연구 원자료 내보내기와 내부 출처 메타데이터에서도 미승인 값을 최종 규준으로 표시하지 않는다. 승인 상태 시험에는 합성 자료를 사용하며 실문헌 승인과 구분한다.
- 0을 포함한 완전응답, 한 문항 결측, 구판·혼합 판본, 빈 조사집단, 중복 회차·카메라, 대상 집단 미확인, 월 단위 나이·기간 누락을 시험한다. 유효 n과 집계 분모가 일치한다.
- 미국 두려움 두 축이 분리되고 영상 점수를 섞지 않는다. 국내 재구성식·수정 문항·사용 조건과 제외 사유가 별도 메타데이터로 남는다.
- 리포트 스냅샷이 비교자료 판본·승인 상태·조사집단 해시를 고정한다. 이후 활성화나 조사집단 갱신이 이전 출력 수치를 소급 변경하지 않는다.
- 원문 수치를 실제로 승인하지 않아도 전체 시험이 가능하다. 조사집단 가져오기·자동 갱신·통계 분석 UI를 별도 합의 없이 추가하지 않는다.

## 추가 확인과 인계

Q08·Q10·Q11. 2026-09-30 검토에서는 Wilkins 원문 확인과 Serpell·Powell 및 국내 출판사 자료 식별을 진행했으며, 후자의 Table 1·8 수치 검증은 완료하지 못했다. C14는 추가 근거 수령 또는 공식 원문 접근 후 진행한다. 문서가 ‘원문 확인’을 서술한 사실과 개발팀이 실제로 원문을 대조한 기록을 구분한다.
