## 구현 순서와 규칙

1. 새 순서인 입장→기준→분리→재회→무시→걷기→낯선 사람→퇴장을 촬영 판본에 둔다. 시각은 항상 구간 ID로 조회한다. 각 구간의 약 30/20/60/30/20/30/30/30초, 합계 약 250초는 안내이며 고정 시각을 자동 생성하는 기준이 아니다. 전환의 실제 경계는 별도로 기록한다.
2. 구간의 정상 실시·단축·미실시·복지 중단 상태와 사유·실제 시작/끝·영상 ID를 저장한다. 미실시 구간에 0초 창을 만들지 않는다. 분리 생략이면 재회도 미실시다. 실제 분리 후 중단하면 분리 길이와 즉시 이어진 재회를 기록한다.
3. 분리의 초기 0~10초·이후 10~60초·전체 관찰창, 재회의 전반 0~15초·후반 15~30초·실제 접촉창·전체 발성창을 구분한다. 예정된 15초 신호와 실제 부름/접촉을 구분한다. 개18은 후반 15초 전체의 몸 상태이며 실제 접촉창만의 상태가 아니다. 개10은 원항목의 단축 시 빈칸 규칙을 따르고 후기 50초의 문턱을 짧아진 구간에 비례해 조정하지 않는다.
4. 걷기 전 이름 1회·S로 이동과 종료 후 착석은 전환이며, S에서 첫걸음을 뗀 뒤의 6개 국면은 본 구간이다. 출발 거리 개37과 이동/정지 3쌍의 실제 경계를 저장한다. 거리 등급의 몸길이 측정·보정은 Q08 확인 사항이며 자동 측정은 이 PR 범위가 아니다.
5. 낯선 사람 구간은 보호자가 착석한 뒤 전환 대기 5초를 거쳐 시작한다. 안전문 밖 0~10초, 입실 10~12초, 접근 12~16초, 16초 부름 뒤 20초까지 대기, 접촉 20~23초와 25초까지 대기 또는 미접촉 대기 20~25초, 퇴장 25~30초를 안내하고 실제 사건을 저장한다. 개53의 중단 코드만으로 이미 관찰된 접촉값을 지우지 않는다.
6. 바닥 첫 접촉·물건 앞 정지/첫 코 접촉·물건 제거·보호자 말/손짓·직원 신호·먹이·경로 이탈·가림·중단을 시각과 영향받은 항목에 연결한다. 복지 중단 뒤 조치와 직원 중단 신호 뒤 보22 대응을 교육태도 배점에서 제외할 수 있도록 시각과 맥락을 남긴다.
7. 기준 영상 선택과 다른 영상의 확인된 수동 오프셋을 명시한다. 확인되지 않은 카메라 동기화를 자동 확정하지 않는다. 별도 06 보호자 안내자료가 제공되지 않았으므로 04와 일치하는 운영 안내를 먼저 마련한다.

## 검증과 완료 조건

- 구판 stranger/reunion 시각이 새 순서의 다른 구간으로 표시되지 않는다. 신판 정상 실시·분리 생략·10초 이전/이후 단축·미접촉·접촉 중 중단 사례의 저장/재조회가 일치한다.
- 잘못된 순서·영상 범위 밖 시각·음수·국면 중복/누락·잘못된 사건창은 거절하거나 확정할 수 없는 초안 상태로 유지한다. 예정값으로 실제값을 덮지 않는다.
- 복지 중단·물건 제거·먹이 사건의 원문·시각·영향 범위를 유지한다. 전환이 본 구간의 분모에 들어가지 않는다.
- 확정/수정·409·미저장 이탈 보호와 reviewer 읽기 동작을 유지한다. 일부 구간 미실시도 사유가 갖춰지면 기록 확정 가능하다.

## 추가 확인과 인계

Q01·Q02·Q05·Q08을 연결한다. C04는 유효한 실제 관찰창, C05/C06은 기회·조건·사건, C07은 명시한 원본 시각을 사용한다. 일부 예외가 계산 보류라는 이유로 촬영 원자료 저장을 막지 않는다.
