원본 문서·셀은 수정하지 않는다. 확정 규칙과 앱의 상태 보존 차이를 리뷰 기록에 남기고, Excel 표시 문자열을 그대로 내부 상태로 채택하지 않는다.

## 5 통합 출력 사례와 기록 양식

00 §7의 8사례를 다음처럼 유지한다. 시험에는 입력 fixture, 기대값의 문서/셀, 실제 계산·리포트, 차이·수용 여부를 함께 보관한다.

1. 의견 없음 / 일부 완료 / 작성 중 / 완료 후 유형 변경: 적용 출처와 요약·상세·총평·조언 일치, 기본 수치 보존.
2. 정상 관찰0 / 미관찰 / 기회없음 / 미실시 / 무효 / 중단: 저장·조회·내보내기에서 구분.
3. 보13 미입력·1·2·3와 한 국면 누락: 6국면 분모·주의·무효·조건미확인 유지.
4. 분리 생략·단축·재회 미접촉·낯선 접촉 전/중 중단: 실제 창·원값·판정보류 연결.
5. 개32=99: 미발생 원코드 보존, 실제99초·평균으로 처리하지 않음.
6. 구판 설문·하위척도 부분응답·본 적 없는 상황: 원응답 저장, 비교 차단, 빈칸 사유 자동추정 금지.
7. 반대 반응 혼재와 개9→10의 25조합: 원방향·실제 행동 순서, 수치 차이·총점으로 대체하지 않음.
8. 최종 유형·총평·조언의 일관성과 원자료 보존: 수정·재발급·삭제·백업 복원까지 추적.

추가 인프라 사례는 구판 시각 보존, 재시작 이관 멱등, 새 worker 계약·비용 상한·점유 만료, 기존 출력 보존·stale, 삭제 요청 중 실행/다운로드, ZIP 자산 누락과 깨끗한 설치다.
