# PR-C12 연구 내보내기

버전: v1.0 · 2026-09-30 · 상태: 구현 전 · 선행: C05·C06·C08·C10 · 추정: 2~3개발일

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20260930.md). 근거: 00 §4~6의 연구 원자료 보존, 03의 분석 구분, 07 §1·§6·§7의 독립 기록·반복 표본 기준. 권장 제목: `feat: 독립 원자료와 행사 결과를 구분한 연구 내보내기`.

## 문제와 결과

남아 있는 `exports.py`는 55항목 선택지와 구판 영역·주제를 사용한다. 평가자별 원코드·상태·근거, 자동 산출물, 독립 유형 판정, 검수·행사 결과를 구분해 고정된 스냅샷으로 내보낸다. 통계 분석법이나 합격 정확도를 임의로 정하지 않는다.

## 데이터 구조와 구현 순서

1. 스냅샷은 참가자·회차, 선택한 시트·판정 revision/해시, 영상·관찰창·절차, 설문 판본, 계산 규칙, 평가 목적·AI/타평가 노출 상태를 고정한다. 요청 후 ‘최신 시트’로 교체하지 않는다. 같은 영상·항목·창·기준의 비교 쌍을 확인한다. 원자료 표에는 불일치를 상태와 함께 보존하고, 일치도 분석 대상표에서는 부적합 쌍의 제외 사유를 남긴다.
2. 직접 원자료는 참가자×회차×평가자×항목/관찰창당 한 행인 긴 표를 기본으로 한다. 코드 목록에 원항목 117행·사용 113행·직접 채점/메모 109행·자동 4행·미사용 4행의 역할을 표시한다. 원행 코드·자료형·원값/null·사유·기회·관찰 가능 초·실제 시각·원본/클립 근거를 보존한다. 자동값을 직접 관찰값 표에 섞거나 사용하지 않는 행을 0으로 채우지 않는다.
3. 자동 계산, 기본 유형·근거, AI 공개 후 검수·합의, 완료된 행사 의견, 최종 리포트는 각각 별도 표로 구분한다. 사람이 AI 결과를 본 뒤 고친 기록은 전문가 독립 일치도 자료에 포함하지 않는다. 기본 시트·독립 판정은 행사 수정으로 덮어쓰지 않는다. 배점 규칙·의견 판본·출력에 사용한 최종 스냅샷까지 추적한다.
4. 연구의 기본 표본은 같은 참가자·개체이며 카메라 파일을 별도 표본으로 세지 않는다. 재촬영·여러 회차의 포함 규칙은 Q10·Q12에 따라 고정한다. 범주·횟수·초·유형에 일률적으로 ICC를 적용하지 않는다. 자동식 재계산 일치, 행동 원코드 일치, 유형 판정 일치를 하나의 ‘정확도’로 합치지 않는다. 이 PR은 분석 가능한 자료를 제공하며 통계 결과를 산출하는 PR이 아니다.
5. 설문 원응답과 역채점·하위영역 평균을 구분하고, 문항 25 단독값·미응답 사유·하위척도별 유효 n·집계 정책을 포함한다. 부분응답 집계가 미확정인 영역은 원응답을 보존하고 집계 보류를 표시한다. 연구 비교가 미승인이면 참고값을 최종 규준 열로 내보내지 않는다. 비교 기능 없이도 독립 원자료 내보내기는 가능해야 한다.
6. 이름·연락처·API 키는 연구 파일에 넣지 않는다. 참가자·평가자의 연구 식별자 범위와 필요한 접수 항목은 Q11의 동의·관리 조건을 따른다. 0·−2·99·null을 손실 없이 내보낸다. 개32의 99는 미발생 원코드와 함께 보존하며 실제 99초로 변환하지 않는다. CSV 빈칸은 상태·사유 열로 구별하고 문자열의 Excel 수식 주입은 막는다. 숫자 음수를 문자 수식으로 오인해 원값을 바꾸지 않는다.
7. 생성·채택·다운로드 직전에 삭제 상태와 스냅샷·파일 해시를 검증한다. 부모 시트·판정·의견·리포트와 출력 파일을 참조 탐색·백업·복원·삭제 정리에 연결한다. 완료된 내보내기는 입력이 나중에 바뀌어도 파일을 덮지 않으며, 다음 요청은 새 스냅샷과 이력을 만든다.
8. 기존 02의 20개 슬롯은 Excel 배치 위치다. 참가자 수 제한이나 표본 ID로 사용하지 않는다. 앱 연구 파일이 원본 Excel 레이아웃까지 재현해야 하는지는 별도 확인하며, 원본 파일 자체는 수정하지 않는다.

## 검증과 완료 조건

- AI·전문가 2인의 독립 기록, AI 노출 후 검수, 완료 행사 의견의 출처를 저장값과 대조한다. 원점수·기본 판정이 행사 수정으로 바뀌지 않는다. 미완료 시트와 노출 후 기록은 독립 분석 대상에서 제외되며 이유가 남는다.
- 0·음수·99·정수 횟수·초·메모·null, 기회 없음·무효·중단이 각 표에서 정확히 보존된다. 슬롯 20개를 참가자 한도로 사용하지 않는다.
- 혼합 판본·다른 영상/창·중복 회차/카메라, 원자료 보존과 비교 대상 제외, 포함 n·분모, 개인정보·수식 주입을 검증한다.
- 생성 중 수정·삭제, 같은 스냅샷의 재현, 손상 해시, 백업·복원, 새 FK와 파일 정리가 통과한다. 내보내기 완료를 실제 통계 검증 완료로 표시하지 않는다.
- 독립 채점 공개 정책을 내보내기로 우회할 수 없다. 미공개 타평가 결과가 포함된 파일의 생성·다운로드 권한도 C05의 업무별 권한과 Q07을 따른다.
