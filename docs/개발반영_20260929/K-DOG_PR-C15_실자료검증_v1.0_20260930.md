# PR-C15 현행 실자료 검증 — 자료 수령 후

버전: v1.0 · 2026-09-30 · 상태: 현행 영상·독립 채점 대기 · 선행: C07B·C12·C13, Q02·Q08·Q12의 해당 기준 및 Q11 동의 확인 · 초기 검토: 5~10개발일

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20260930.md), [검증 자료대장](K-DOG_확인사항및검증자료_v1.0_20260930.md). 실행 연결은 [C07B](K-DOG_PR-C07B_AI채점연결_v1.0_20260930.md)를 따른다. 조건부 후속 PR이며 기본 구현의 개발일 합계와 별도다. 기간은 초기 판독·일치·성능 검토의 추정이며, 정식 연구 표본과 통계 검증 완료 기간이 아니다.

## 목표와 선행 자료

현행 정상·예외 원본 영상과 음성, 같은 항목·시간창·판본으로 작성한 두 전문가의 독립 채점을 확보한다. 실제 시각·장비 정보·몸길이 기준·카메라 오프셋·평가자 출처와 AI/타평가 미노출 여부를 함께 확인한다. 영상·시트·동의 자료는 소스 밖의 접근이 제한된 데이터 폴더에서 관리한다. 예비 6쌍이나 루키 3/6을 현행 판독 정답으로 이식하지 않는다.

자료 수령·화질/음성 점검·독립 채점 준비는 C13 이전에도 진행할 수 있다. 자동 실행·연구 내보내기까지 연결한 통합 검증은 선행 PR 이후 수행한다. 특정 항목의 기준이 미확정이면 그 항목을 보류하고, 확인 가능한 범위의 검증은 계속한다. 복지 중단·대표값·판정 완료·평가자 공개 조건은 Q05~Q07의 확정 범위도 따른다.

1. 원본↔클립↔AI 근거 시각을 대조한다. 실제 접촉, 여섯 걷기 국면, 단축·생략, 전체 발성 비중 판단에 필요한 음성, 작은 몸 신호, 몸길이·원근에 따른 거리 등급을 실측한다. 근거 시각이 허용창 안에 있다는 계약 검사와 실제 행동을 정확히 읽었는지의 검증을 구분한다.
2. AI·전문가1·전문가2가 같은 영상·항목·관찰창·판본을 독립 채점했는지 확인한다. AI를 본 뒤 수정한 기록, 합의 판정, 행사 의견은 독립 원자료 비교에서 분리한다. 사람 채점도 절대 정답으로 가정하지 않고 전문가 간 불일치와 AI 대 각 전문가의 차이를 따로 기록한다.
3. 원코드·상태/사유·기회·대표값 선택, 자동 계산식, 다중 근거 유형을 구분해 비교한다. 범주·횟수·초·유형에 맞는 통계법, 표본, 포함/제외 및 수용 기준은 연구 분석계획으로 확정한다. 평균 일치율 하나를 전체 정확도로 부르거나 자동식 재계산 일치를 전문가 유형 판단 일치로 대신하지 않는다.
4. 항목군별 비용·처리시간·재시도·실패·미판독률과 전체 소요를 측정한다. 해상도·fps·음성·카메라 오프셋·요청 설정을 함께 기록한다. 측정 결과로 현장 처리량을 재산정하며, 한 사례의 시간을 전체 참가자 처리시간으로 단정하지 않는다.
5. 기준·프롬프트·샘플링 개선에 사용한 예비/개발 자료와 확정 후 평가 자료를 구분한다. 실자료를 보며 기준을 바꿨다면 변경 판본·시점·사용한 표본을 남긴다. 같은 평가 세트에서 유리한 문턱을 골라 원결과를 덮거나 이를 독립 검증으로 보고하지 않는다.
6. 개선은 확인된 문제에 필요한 파일만 변경하고, 새 프롬프트·샘플링 판본으로 새 run을 만든다. 불일치를 모델 오류·사람의 기준 차이·촬영 품질·미확정 규칙으로 구분하며, 기존 run·시트·원점수·독립 판정을 덮어쓰지 않는다. 코드 변경이 없으면 억지로 수정 PR을 만들지 않고 검증 결과 문서와 인계 기록을 남긴다.

## 검증과 완료 조건

- 검증 대상·포함/제외·독립 출처·문서/원항목 기대값·실측 결과·불일치 원인·남은 한계를 보고서에 남긴다. 정상·예외 유형별 확보·미확보 여부도 기록한다.
- 기준 미확정·표본 부족·촬영 판독 불가이면 해당 영역을 검증 완료로 표시하지 않는다. 계약·합성 시험 통과, 초기 실자료 검토, 정식 연구 통계 검증의 상태를 구분한다.
- 실제 모델·프롬프트·샘플링·비용·처리시간이 실행 기록과 일치한다. 모델 호출 비용과 외부 AI 전송·보관은 명시한 검증 계획 및 동의 범위 안에서 관리한다.
- 발견한 결함은 합성 회귀로 재현하고 수정 후 같은 조건에서 확인한다. 수정에 사용한 사례의 재확인은 독립 평가 자료에서의 검증과 구분한다.
- 초기 검토 결과와 검증되지 않은 범위를 운영 담당자·최종 확인자에게 인계한다. 초기 검토 완료를 정식 연구 타당화나 본행사 당일 처리 보장으로 표시하지 않는다.

## 운영 인계

현장 적용 여부는 확인된 항목군·촬영 품질·발급 운영 조건과 남은 위험을 기준으로 결정한다. 자동 생성·전달 정책은 Q09에 따르며, 미검증 영역의 보류 표시를 임의로 해제하지 않는다. 추가 표본과 정식 통계 검증의 일정은 연구 분석계획에서 별도로 정한다.
