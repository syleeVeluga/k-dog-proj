## 문제와 결과

활성 채점 저장 API·화면은 없고 reviewer는 읽기만 가능하다. AI·전문가 1·전문가 2가 같은 영상·항목·관찰창을 독립적으로 기록할 시트와 화면을 마련한다. 독립 기록, AI 공개 후 검수/합의, 행사 의견은 다른 출처로 보존한다. 가장 최근에 완료한 사람 시트를 자동으로 리포트 입력에 채택하지 않는다.

## 구현 순서와 경계

1. 각 시트에 case/session·카탈로그/절차 판본·입력 revision/해시·영상 해시·관찰창 snapshot·평가자 ID·평가 목적·AI/다른 평가 결과의 노출 상태를 고정한다. 슬롯 번호나 카메라별 파일을 독립 참가자로 삼지 않는다.
2. 로그인 계정의 입력 행위자와 실제 평가자 ID를 별도로 기록한다. 교수의 대리 입력 허용 여부는 Q07이다. 계정과 평가자의 1:1 관계를 임의로 고정하거나 아무 평가자 이름으로 입력할 수 있게 열지 않는다.
3. reviewer를 기존 일반 writer에 추가하지 않는다. 배정된 자기 채점 작성/제출, 타평가 결과 조회, 행사 의견 작성, 운영자 재개방을 별도 업무 권한으로 검증한다. UI 숨김 외에 API에서도 제한한다.
4. 직접 채점·메모 109행만 입력할 수 있다. 미실시·기회 없음·가림·미청취는 null과 사유·기회·관찰 가능량으로 기록한다. 메모는 수치 점수로 검증하지 않으며, ‘완료’는 모든 항목이 숫자라는 뜻이 아니다. 자동 계산 4행과 미사용 4행은 편집하지 않는다. 복지 중단 뒤 조치와 직원 중단 신호 뒤 대응은 배점 제외 근거로 남긴다.
5. 독립 기록 확정 전에는 AI/다른 평가자의 값과 행사 의견을 노출하지 않는 흐름을 마련한다. 공개/노출 시점과 재개방을 기록하고, 다른 결과를 본 뒤 수정한 시트는 독립 원자료와 구분한다. 완료 원본을 덮어쓰지 않고 새 revision·사유를 남긴다. 공개 시점은 Q07로 확정하며 독립 제출 직후 자동 공개를 기본으로 정하지 않는다.
6. 시트 API는 expected revision과 삭제 상태를 검증한다. 시트 파일은 불변으로 저장하고 DB 채택 전 입력/배정 상태를 재확인한다. 새 파일/표가 생기는 즉시 maintenance의 참조 탐색·백업·삭제를 연결한다.
7. 화면은 구간/주제별 필터와 실제 관찰창 재생을 제공하되 동일한 원코드를 저장한다. 원본에 표시된 순서와 실제 촬영 순서는 구분한다. 한 항목이 여러 구간이나 사건에 걸치면 해당 창을 모두 확인할 수 있게 한다. 초기 연구 운영에 필요하지 않은 범용 배정 알고리즘·ICC 통계 UI·Excel 직접 편집 연동은 추가하지 않는다.

## 검증과 완료 조건

- 두 평가자의 같은 참가자 기록이 서로 덮어써지지 않는다. 자기/타인/미배정/운영자/API 우회·AI 노출 전후 권한을 시험한다.
- 음수·0·메모·횟수·99·null/사유 입력과 자동/미사용/알 수 없는 코드 거절을 검증한다. 접촉 중 중단 시 실제 관찰된 원값은 보존하고 유효 상태를 별도로 기록한다.
- 시트 제출·잠금·재개방·독립 출처 변경·동시 수정 409·참가자/세션 전환을 검증한다. 보존한 관찰창이 실제 영상 범위와 일치하며 여러 창의 근거가 같은 원본 시각으로 연결된다.
- 새 시트/초안/제출본의 백업·복원, 손상 해시·삭제 요청 뒤 조회/수정 차단·파일/표 삭제를 검증한다. 기존 v1/v2 조회와 백업 회귀를 유지한다.
- C06에서 사용할 시트 ID/revision/hash를 명시적으로 선택할 수 있다. AI 시트를 항상 draft로 제한하거나 사람 시트만 결과 입력으로 강제하지 않는다.

## 추가 확인과 인계

Q01·Q02·Q07을 연결한다. 이 PR에서는 저장·독립성·권한과 사람이 입력하는 화면을 완성한다. 기본 계산은 C06, 자동 AI 채점은 C07, 행사 의견은 C08이다. 원자료가 없으면 합성 독립 시트로 흐름을 검증하며 실제 채점 일치도를 확인한 것으로 표시하지 않는다.
