# PR-C14 비교 근거 확정 — 자료 확보 후

버전: v1.0 · 2026-09-30 · 상태: 근거자료 대기 · 선행: C11·C13, Q10 회신과 해당 영역의 Q04·Q08·Q11 확인 · 추정: 증빙 확보 후 1~2개발일

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20260930.md), [C11](K-DOG_PR-C11_연구비교구조_v1.0_20260930.md). 조건부 후속 PR이며 기본 구현의 개발일 합계에 포함하지 않는다. 자료 수령·원문 접근·번안 및 사용 조건 확인에 걸리는 시간은 현재 산정할 수 없다.

## 목표와 선행 자료

고객이 추가 제공할 논문·근거와 공식 출판사 원문을 대조해 문항별 비교 적합성이 확인된 영역만 활성화한다. 미국 평균 0.66·1.03과 국내 재구성 네 값은 전달 문서의 주장값이며, 이 계획만으로 승인하지 않는다. 문헌 대조와 증빙 정리는 C13 이전에도 가능하지만 운영 활성화는 C13의 패키지 확인 후 진행한다.

- Serpell·Powell의 Methods·Table 1에서 표본·척도·하위 문항·결측 처리, 유효 n·평균·SD를 확인한다. 낯선 사람 두려움과 비사회적 두려움의 두 하위척도에 대한 적용 여부를 각각 기록한다.
- Shim 등의 Methods·Table 4·Table 8에서 19문항 구성, 집단 n=159·141, 재구성식, 역채점과 원문 문항을 확인한다. 재구성 평균을 별도 국가 규준이나 확인하지 않은 SD·분포로 확대하지 않는다.
- Q7·8·20의 수정, 늦게 데려온 집단, 월 단위 나이·함께 산 기간과 대상 구분 기준, 번안·사용 조건을 확인한다. 자료가 없어 비교 적합성이 미확인이면 해당 대상의 비교는 계속 차단한다.
- 조사집단 관리 주체, 포함할 회차, 같은 판본·문항·결측 규칙, 하위척도별 유효 n·기준일을 확정한다. 미국 두려움 비교에는 해당 하위척도의 완전응답자만 포함한다. 국내 자료는 원문과 Q04에서 확정한 해당 영역의 집계·결측 정책을 확인하며, 미확정 부분평균을 임의로 적용하지 않는다. 재촬영·카메라 파일을 독립 참가자로 중복 계수하지 않는다.

Wilkins의 설문 장문판·축약판 검증과 미국 두려움 참고 평균의 출처를 구분한다. 설문 연구를 AI 영상 채점 정확도 근거로 표시하지 않는다. 원문 확인, 번안 의미 확인, 사용 조건 확인, 운영 적용 확인은 각각 증빙을 남긴다.

일부 영역만 확정되어도 그 영역만 승인한다. 새 비교자료 판본을 다음 생성 출력에 고정하며, 과거 HTML·인쇄본·내보내기 스냅샷을 소급 변경하지 않는다. 원문자료의 저장·재배포는 사용 조건을 따르고, 참가자 명부를 소스에 추가하지 않는다.

## 검증과 완료 조건

- 원문 표 수치·재구성식·문항/번안·수정 문항 조건·사용 증빙·검증자·검증일이 기록된다. 승인 근거 없이 비활성 상태만 해제하는 변경은 허용하지 않는다.
- 승인·미승인·대상 미확인, 구판·불완전 응답·빈 조사집단을 실제 출력에서 확인한다. 미국 두려움 하위척도 결측을 부분평균으로 채우지 않는다. 국내 묶음의 집계 정책이 미확정이면 해당 비교를 보류한다. 자료가 확정되지 않은 영역은 계속 비활성이다.
- 국가 정상치·백분위·진단 경계·AI 영상 정확도라는 해석이 출력되지 않는다. 표본 n·척도·적용 조건·비교의 한계가 승인된 범위에 맞게 표시된다.
- 같은 조사집단 스냅샷과 비교자료 버전으로 출력이 재현되며, 새 승인·새 집계가 이전 출력값을 바꾸지 않는다.

원문이나 사용 조건을 확보하지 못한 영역은 보류한다. 비교 구조 구현 완료와 운영값 승인 완료를 구분하여 완료 기록에 남긴다.
