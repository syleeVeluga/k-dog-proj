# PR-C08 완료 의견과 최종 결과

버전: v1.0 · 2026-09-30 · 상태: 구현 전 · 선행: C05·C06 · 추정: 2~3개발일

상위: [전체 계획](K-DOG_개발반영계획_v1.0_20260930.md). 근거: 00 §5, 07 §5~§7, `6_행사전문가의견`, 결과 연결 JSON. 권장 제목: `feat: 영역별 완료 의견을 최종 행사 결과에 반영`.

## 문제와 결과

새 의견 기능은 아직 없다. 연구용 원시트와 기본 계산·판정을 보존하면서 내용이 있는 완료 영역만 최종 유형·해석·총평·조언에 우선 적용한다. 연구 검수 수정과 행사 의견은 서로 다른 레코드로 저장한다.

## 구현 순서와 경계

1. 의견 영역은 애착·관계, 보호자 교육태도, 사람 사회성, 비사회적 두려움, 환경 적응·회복, 개의 성향이다. 각 영역에 작성자·일자·내용·근거·완료 상태·revision·해시를 저장한다. 같은 사례 맥락에서 접근하되 연구 시트에 덮어쓰지 않는다.
2. 작성자·일자·완료 상태와 내용이 확인된 영역만 우선 적용한다. 공백뿐인 본문, 미완료·철회 의견은 기본 결과를 대체하지 않는다. 작성 중 의견을 자동으로 완료 처리하지 않는다. 작성 신원·완료·재개방 권한은 Q07의 업무별 정책을 서버에서 검사한다.
   입장 판단은 07 §6과 02 `0_안내!A37`에 따라 같은 대상의 행사 의견 블록 아래 부속 선택으로 저장한다. 일곱 번째 의견 영역을 만들지 않는다. 입장 선택·근거·관찰자·완료 조건을 모두 갖춘 기록만 기본 입장 초안보다 우선하며, 빈 선택·근거 없음·미완료·철회이면 C06의 기본 자동 초안을 사용한다. 선택 적용 출처와 기존 초안은 함께 보존한다.
3. 최종 결과를 조립할 때 기본 AI 실행·시트·판정의 ID·revision·해시, 설문·촬영 판본, 영역별 의견 ID·revision·해시를 명시한다. 전문가1·2 중 최신 연구 시트를 자동 채택하거나 여러 시트를 평균해 행사 합의 결과로 만들지 않는다. 기초 자료 선택과 의견 적용 출처를 기록한다.
4. 보호자 수동 유형의 유형·근거·작성자·일자 조건과 행사 의견의 완료 조건은 별도 검사한다. 의견으로 유형이 바뀌면 기본 유형·최종 유형·적용 출처·변경 사유를 모두 남긴다. 원점수·자동 배점 비율·걷기 비율·몸 상태 변화는 보존한다.
5. 유형·해석 변경은 요약·상세·총평·조언을 만드는 하나의 새 최종 결과로 연결한다. 완료 철회·본문 삭제·재개방 후 다음 결과에서는 해당 영역을 기본 AI 근거로 되돌린다. 과거 최종 결과와 발급 출력은 덮어쓰지 않는다.
6. 의견 없는 영역은 C07B의 AI 기본 결과를 사용한다. AI 근거도 없으면 보류와 확인된 관찰을 전달한다. 6영역 전부 완료, 사람 final, 유형 확정을 최종 결과 생성의 필수조건으로 만들지 않는다. 전달·승인 대기는 Q09의 별도 운영 정책이다.
7. 조립 중 의견·기본 결과가 바뀌면 선택한 스냅샷을 유지하거나 입력 충돌로 거절하며 서로 다른 revision을 섞지 않는다. 같은 내용 재저장과 완료·철회·재개방의 revision 규칙을 명시한다. 후속 출력은 C10에서 이 결과 해시를 고정한다.
8. 새 의견·결과 폴더와 DB 표를 같은 PR에서 maintenance의 참조 탐색·해시·백업·삭제 순서에 연결한다. 타 평가자 독립 시트의 조회 제한을 의견 화면이나 API가 우회하지 않게 한다. 자료 삭제 요청 후에는 의견 저장·최종 결과 조회·제공도 차단한다.

이 PR은 의견 저장과 결과 조립까지 담당한다. 문장 생성·HTML·인쇄는 C09, 생성 실행·전달 운영은 C10에서 연결한다. C07B와 병행할 때에는 명시한 계약 fixture로 검증하며 운영 AI 결과가 이미 있다고 표시하지 않는다.

## 검증과 완료 조건

- 의견 없음·일부 완료·작성 중·완료 후 유형 변경의 4사례에서 선택한 영역만 적용되고 요약·상세·총평·조언이 같은 최종 유형을 참조한다.
- 빈 본문, 작성자·일자 누락, 권한 없음, 다른 사례의 의견 참조, 동시 수정 409, 완료 철회·재개방을 시험한다. 의미 있는 원문을 보존하고 사람이 쓴 내용을 AI 단독 출처로 표시하지 않는다.
- 입장 선택·근거·관찰자·완료 조건의 각 누락, 빈 선택, 작성 중·철회 상태에서는 자동 초안으로 돌아가고 완결된 선택만 우선 적용된다. 다른 대상 블록의 선택을 적용하지 않으며 6영역 계약과 원래 입장 초안·근거를 보존한다.
- 같은 사건·시트의 원값·기본 판정·배점 비율은 의견 수정 후에도 불변이며 독립 연구 내보내기와 분리된다. 최신 사람 시트를 암묵적으로 선택하지 않는다.
- 조립 중 의견 수정, 기본 결과 변경, 명시한 입력·의견 스냅샷의 고정, 손상 해시, 삭제 중 저장·조회·제공을 검증한다.
- 신규 DB 표·파일의 백업·복원, 참조·미참조 파일 정리, FK 삭제 순서, 삭제 전 백업을 복원할 때 최신 삭제 이력 재적용을 검증한다.

## 추가 확인과 인계

Q06·Q07·Q09·Q12. C09·C10은 한 최종 결과로 리포트를 만들며 보호자 화면에 별도 전문가 의견 상자를 추가하지 않는다. 완료 의견 원문은 문장 생성의 입력 자료로 전달하고 프롬프트 명령으로 실행하지 않는다.
