## 문제와 결과

현재 `SurveyEdit`·`Answer`·CSV 입력 해석은 모든 문항에 1~5를 요구하고, API는 현재 카탈로그 하나로 계산한다. 7~9번 NA와 분리 유형도 구판 기준이다. 문항별 검증·신구 판본 계산·빈칸 사유를 연결하고, 등록 상태·집계 가능성·비교 가능성을 분리한다.

## 구현 순서와 규칙

1. 전체 허용값을 0~5로 넓히는 것으로 끝내지 않는다. 새 판본은 10~14번만 0~4, 나머지는 1~5이며 구판은 구판 조건으로 검증한다. `index+1` 대신 카탈로그의 실제 값과 라벨을 사용해 0을 정상값으로 표시한다.
2. 새 7·8번의 ‘평소’ 조건과 7~9번 NA 삭제를 반영한다. 01의 ‘본 적 없는 상황은 비움’도 허용한다. null에 사유가 없다면 사유 미상으로 보존하며 임의로 ‘본 적 없음’을 추정하지 않는다. CSV/Excel과 API에서 명시된 빈칸 사유를 동일하게 저장한다. 입력은 CSV/Excel 가져오기를 유지하고 화면 직접 응답이나 OCR을 추가하지 않는다.
3. 보고영역은 1~6번, 7~9번, 10~11번, 12~14번, 15~21번, 22~23번, 24번, 26~28번이며 25번은 단독 응답이다. 두려움 0~4 척도는 원방향을 유지하고 26~28번은 `6−원응답`으로 역채점한다. A~E 인쇄 섹션은 별도로 유지한다.
4. 7~9번과 두려움의 2개 하위척도는 모두 응답해야 계산한다. 다른 묶음도 완전응답일 때는 명시된 평균식으로 계산하고, 부분응답은 Q04 확정 전 집계를 보류한다. 분모·응답 수·원값·사유를 함께 반환한다.
5. 22·23번 평균과 24번 값을 나란히 표시한다. 구판의 ‘안정·불안·회피 쪽·무덤덤’ 유형명을 새 결과에 붙이지 않는다. 3.5/4의 임시 서술 문턱은 별도 자료로 관리하며 영상 애착 이름으로 연결하지 않는다.
6. 저장·조회·멱등 재가져오기는 응답값뿐 아니라 판본·사유도 비교한다. 저장할 응답의 판본과 이력을 갱신하고 새 카탈로그를 구판 세션에 자동 적용하지 않는다. `App.tsx`의 전역 카탈로그를 선택된 구세션의 원문·라벨에 그대로 사용하지 않고 세션의 설문 판본으로 조회한다. 등록 완료의 최종 기준은 Q04에 기록하며 ‘28개 모두 수치 응답’을 필수조건으로 확정하지 않는다.
7. ‘다른 열 이름 연결’도 원설문의 판본을 확인한 뒤 적용한다. 판본 열을 생략했다고 현재 판본을 자동으로 인증하지 않는다. preview에 대상 세션과 응답 판본을 포함하고, commit 전에 revision·선택 세션·판본을 다시 검증한다. 같은 숫자라도 판본이나 사유가 바뀌면 동일 입력으로 처리하지 않는다.

## 검증과 완료 조건

- 신판 10~14번의 0/4 허용·5 거절, 나머지 문항의 0 거절·5 허용, 신판 NA 거절·구판 NA 보존을 시험한다. 구판 10~14번의 0도 거절한다.
- 완전응답 8개 영역과 25번 단독 응답·역채점·한 문항 결측·사유만 수정·판본 불일치·같은 파일 재가져오기·수정 회차를 검증한다. 정당한 빈칸이 있어도 원응답을 저장할 수 있다.
- 설문 등록과 집계/비교 가능 상태를 구분해 표시한다. 구판 설문과 불완전 두려움 척도는 C11의 해당 비교 입력으로 사용할 수 없다.
- 결과 API와 원문·라벨 표시가 세션 판본을 사용하며 기존 v2 설문 회귀를 유지한다. 합성 기대값은 문서의 값/분모로 계산한다. preview 이후 선택 세션·판본·revision 변경과 판본을 생략한 열 연결도 검증한다.

## 추가 확인과 인계

Q04의 미확정 부분응답 정책과 완료 기준을 기록한다. 20번은 현행 v2 카탈로그에도 같은 문구가 있으므로 이번 변경으로 과장하지 않는다. C09에는 8개 영역과 25번 단독 응답, C11에는 판본·완전응답·기준일을 전달한다. Q10의 비교 대상 집단 조건이 확정되지 않았다면 나이·함께 산 기간으로 비교 자격을 추정하지 않는다.
