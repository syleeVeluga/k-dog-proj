## 문제와 결과

현재 `scoring.py`의 6영역 통계와 구판 지표·유형은 새 기준을 대신할 수 없다. 순수 계산과 다중 근거 판정 기록을 분리해 새 수치·조건·완결성을 구현한다. 의견 반영 전의 기본 결과는 평가자별로 고정한다.

구판 `stranger_calming`이나 전 영역의 mean/lean/width/degree를 새 계약에 남기지 않는다. 정상 원값 0과 미관찰·미실시·무효 상태는 계산 후에도 구분한다. 접촉 전·중 중단은 관찰된 원자료·시각을 보존한 뒤 항목별 유효성을 판단한다. 메모·빈값·미발생 코드를 숫자 평균에 포함하지 않는다.

## 보호자 배점과 관계 판정

1. 보6·9(줄), 보22·39(재회), 보23·24(낯선)의 v0.2 항목 배점만 사용한다. 입장·퇴장의 자유 이동을 한 원항목으로 종합하며, 물건 앞 지시 구간과 복지 중단·직원 신호 뒤 안전조치는 배점 근거에서 제외한다. 보5·10·11은 보조다.
2. 보22는 보38=2·3, 보39는 보38=1·3, 보24는 보40=1·2의 기회를 확인한다. 기회 없음과 모든 유형의 배점이 0인 범주는 근거 항목 수와 장면 평균에서 제외한다. 사용·제외한 사건·항목·이유를 저장한다.
3. 장면별 평균→합산→3유형 근거 비율로 계산한다. 최소 3항목·2장면, 1위 60% 이상, 1·2위 차이 15%p 이상일 때 자동 초안이다. 임시 연구 배점이며 성격 확률이 아니다. 동률·문턱 미달은 보류한다. 수동 유형 적용은 유형·근거·작성자·일자의 완결성을 검사한다.
4. 애착의 네 관계 이름과 판정보류 계약을 구현한다. 접근·몸 상태·발성·실제 접촉·무시·기회·사건의 근거와 반대 근거를 저장한다. 개21 한 건, 꼬리, 누움, AU·BK 단독으로 유형을 결정하지 않는다. 사람이 입력한 기본 판정과 C07B의 AI 판정은 같은 완결성 검증을 사용한다.
5. 분리 생략→재회 미실시→관계 판정보류를 연결한다. 보12=3이면 무시 구간의 영향만 표시하고 다른 유효 근거를 삭제하지 않는다. 수치 없음·유형 미선택·판정 미완료·완료된 판정보류를 구분한다. 원본 M의 미완성 유형 연결을 그대로 복제하지 않는다.

계산 요청은 시트 ID·revision·해시, 카탈로그·규칙 판본, 실제 관찰창을 명시한다. 계산 중 시트가 수정돼도 기존 결과의 입력은 바뀌지 않는다. 판정 입력·조회에는 C05의 평가자별 권한과 AI 공개 정책을 적용한다. 행사 의견에 따른 최종 유형 변경은 C08의 책임이며 이 PR에서 기본 결과를 덮어쓰지 않는다.

## 검증과 완료 조건

- 걷기 보13의 미입력·1·2·3, 6개 값 누락, 거리 등급 0·1·2·3, 개32의 실제 초·99·null, 발성 0·1/3·2/3 경계, 부분 청취, 단축 분리, 25조합을 독립 기대값으로 검증한다.
- 교육태도의 모든 배점 범주·기회 조건·0배점 제외·복지 신호 뒤 제외, 1·2·3장면, 동률, 60%·15%p 경계를 검증한다.
- 무효가 자료 부족으로 바뀌지 않고 사용 근거·제외 사유·기본 유형이 시트별 스냅샷에 고정된다. 판정 미완료 상태가 최종 유형으로 노출되지 않는다.
- 음수·양수가 함께 있는 경우 각 원값·방향별 합계·관찰 수·접촉 여부가 보존된다. 정상 0만 관찰된 경우와 미관찰을 구분하고 기본 입장 판단 초안·근거·보류 사유를 검증한다. 합계 상쇄나 대소 비교로 새 능력 점수·총점을 만들지 않는다.
- 시트 수정 중 계산, 다른 평가자 결과 조회 제한, 수동 판정 동시 수정 409, 정상 원값 0·음수·빈값의 보존을 검증한다.
- 수식 해석 골든 시험과 Excel 재계산 실대조를 구분한다. 기본 결과 수정 이력·백업·복원·삭제와 기존 v2 계산 회귀를 통과한다. 새 파일·DB 표는 참조 탐색·해시·삭제 순서에 함께 연결한다.
