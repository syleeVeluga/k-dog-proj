| UXR-11 | 낮음 | 비교집단 후보가 있는 화면의 「S1 설문 원문」·회차 ID 기본 표시. 빈 후보로만 실행한 단독 문구 시험에서는 보이지 않음 | 수용. 현재 설문 원문·촬영 회차 이름으로 표시, 조회 불가 대상 ID는 기술 정보로 보존. 문구 시험의 시드에 동의·설문 응답 추가 |

## 검증 기록

- 재현: UXR-01~03 수정 전 실패 확인, 수정 후 통과. UXR-04는 820px 리허설 화면에서 확인하고 세 폭의 화면 시험 추가.
- 관련 회귀: U01~U06 관련 25개 통과. 전체 98개 중 96개 통과, 2개는 독립 서버의 8876 포트를 8765로 고정한 시험 실패. 주소 수정 후 외부 비교·채점 시험 재통과.
- U07 수용 복사본: 문구·검수 기록·스태프/교수/관리자 시나리오·외부 비교·채점·설문·반응형 관련 18개 통과. 최종 전체 검증 결과는 완료 후 아래 갱신.
- `npm run build` 통과. 기존 큰 번들 경고는 동일하며 이번 범위의 결함으로 취급하지 않음.
- `python -X utf8 -m app.import_catalogs --spec 20261002 --customer-dir <소유자 로컬 원본 폴더> --check` 통과. G01/G04 입력 workbook 미수령·실주소/수식 대조 대기는 기존과 같음.
- `git diff --check`, `graft build` → `graft check` 통과. 검토용 서버·설정·로그는 커밋 대상에서 제외.

## 버전 확인

확인일: 2026-10-11. 새 의존성 없음. 공식 npm registry로 최신 안정판 React 19.3.0, Vite 8.3.4, Playwright 1.64.0, TypeScript 7.0.2를 확인했다. 선택 버전은 기존 잠금 React 19.2.8, Vite 8.2.2, Playwright 1.63.0, TypeScript 7.0.2를 유지한다. 이유는 UI 리뷰에 관계없는 업그레이드를 제외하기 위해서다. 실행 Node v24.13.0은 프로젝트의 >=22.12.0 조건을 만족한다.
