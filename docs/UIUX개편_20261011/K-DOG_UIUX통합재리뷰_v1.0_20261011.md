## 병합 직전 동시 작업 통합

U07 원 구현자의 PR [#69](https://github.com/syleeVeluga/k-dog-proj/pull/69)가 재리뷰 병합 준비 중 main에 반영되어, 후속 PR [#70](https://github.com/syleeVeluga/k-dog-proj/pull/70)에 이 변경도 보존해 통합했다. 문구 점검의 동의·설문 시드와 원 구현자의 정리·카나리 시험을 함께 유지하고 완료 기록도 양쪽 근거를 보존했다. 원 구현자의 검수 파일·영상·최종본·원자료 해시 접기, 복구 안내 노출, 교수 빈 목록 검증 및 운영 안내 정정을 수용한다.

추가로 발급 요약의 실행 ID·입력 판본과 선택·발급 당시 비교집단 식별자/해시 기본 노출도 문구 기준 §7에 따라 기술 정보로 이동했다(UXR-05 확대 수용). 미리보기 이름의 개발 코드도 제거했다. 발급 요약 시험은 실제 형식의 32자리 실행 ID로 기본 숨김과 기술 정보 펼침을 확인한다. 다운로드 출처와 평가 규칙은 유지한다.

최종 통합 검증: `npm run build` 통과, **전체 e2e 105개 통과(5.0분)**. 첫 통합 실행의 104개 통과·1개 실패는 실행 시작 시 읽힌 이전 iframe 제목을 찾은 시험 선택자였으며, 선택자를 맞춘 뒤 전체 재실행으로 해소했다. 선택 비교집단 이름이 보이고 ID/해시는 기본 숨김인 것도 회귀 시험으로 확인했다. backend는 앞선 689개 검증 이후 변경이 없으며 기존 검증 결과를 유지한다. `graft build/check`, `git diff --check`, 완료 기록의 상대 링크 검사 통과.
