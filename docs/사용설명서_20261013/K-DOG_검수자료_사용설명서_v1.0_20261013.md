# K-DOG 검수 자료 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 제품 기준: `main / 53889b7` · 평가 기준: S1.1

메뉴 경로는 **자료 관리 → 검수 자료**입니다. 운영자·교수자·관리자·개발자 모두 Excel의 원본 셀과 전달 상태를 참고 자료로 등록하고 보존 기록을 열 수 있습니다.

## 1 언제 사용하나요

고객이나 연구자가 전달한 기존 검수 Excel의 특정 셀을 출처와 함께 보관할 때, 현재 채점과 비교할 참고값의 평가자·확정 상태·노출 여부를 기록할 때 사용합니다. 이 기능은 설문 일괄 등록이나 현재 채점표로 점수를 가져오는 기능과 다릅니다.

등록한 값은 현재 점수에 복사되지 않고 독립 정답에도 자동 반영되지 않습니다. 실제 빈 채점 Excel 양식의 승인·검증과도 별개입니다. S1 점수 Excel import는 관련 원본 검증이 끝나기 전까지 비활성 상태입니다.

## 2 준비할 자료와 조건

- **20 MiB 이하의 XLSX 파일**을 준비합니다. XLS·CSV는 이 화면의 입력 형식이 아닙니다.
- 참고로 남길 시트·셀 주소·원본 대상 표기·항목 코드·전달 판본을 확인합니다.
- 평가자를 실제로 확인했는지, 확정 상태와 AI·다른 평가 노출 상태가 어떻게 전달되었는지 정리합니다. 모르면 미확인으로 남깁니다.
- 앱 참가자와 연결할 경우 행사·참가자 ID·촬영 회차 및 대응 근거를 준비합니다.

앱은 Excel 수식을 실행하지 않습니다. 저장된 수식과 캐시 값은 원본에 기록된 상태이며, 실제 Excel 재계산 결과나 앱 실측 결과로 간주하지 않습니다. 보호자 이름을 평가자 이름으로 자동 지정하지도 않습니다.

## 3 파일 검사하고 참고 셀 선택하기

1. **검수 자료** 메뉴를 열고 **검수 XLSX 파일**에서 파일을 선택합니다.
2. 파일명과 시트 목록이 표시되면 **원본 시트**를 선택합니다.
3. **원본 셀 주소**에 `B2`와 같은 주소를 입력합니다. 표시되는 셀 주소 목록은 일부이므로 목록에 없는 주소도 직접 입력해 확인할 수 있습니다.
4. 원본 셀의 값·수식·캐시·상태를 확인합니다. 해당 주소에 저장값이 없으면 결측 `null`로 보존됩니다. 잘못 입력한 주소를 실제 결측으로 기록하지 않도록 원본과 대조하세요.
5. **원본 대상 표기**에 원본 파일이 사용한 대상 식별을 적습니다. **원본 항목 코드**에는 예를 들어 `개8`처럼 실제 전달 코드를 적습니다.
6. **관찰창 (알 때만)**은 실제로 확인된 경우에만 입력하고 **전달된 판본**을 적습니다. 모르는 판본을 현재 S1으로 추정하지 않습니다.
7. **평가자 확인**이 **명시 확인**이면 **확인한 평가자**를 입력합니다. 확인하지 못했으면 **미확인**으로 둡니다.
8. **전달된 확정 상태**와 **평가 독립·노출 상태**를 원본 전달 내용대로 선택합니다.
9. **셀 선택·상태 판단 사유**에 어떤 자료를 근거로 상태를 선택했는지 적습니다.
10. **참고 행 선택에 추가**를 누릅니다. 같은 대상·시트·셀은 중복 선택할 수 없습니다. 추가할 셀마다 반복합니다.

상태 이름의 의미는 다음과 같습니다.

| 항목 | 선택과 해석 |
| --- | --- |
| 전달된 확정 상태 | 미확정, 사람 확정으로 전달됨, 재확인 필요, AI 잠정값, 예시, 구판 의미, 미관찰 중 전달 사실에 맞게 선택 |
| 독립·노출 상태 | 노출 여부 미확인, 독립 평가로 전달됨 (미검증), AI 노출 후, 다른 사람 평가 노출 후 중 선택 |
| 사람 확정으로 전달됨 | 전달받은 상태의 기록이며 앱이 독립 정답으로 검증·승인했다는 뜻은 아님 |
| 독립 평가로 전달됨 | 독립이라는 전달 주장을 보존하며 실제 독립성을 확인한 것으로 바꾸지 않음 |

## 4 앱 참가자와 회차 대응표 만들기

선택한 원본 대상마다 **명시 대상·회차 대응표**가 나타납니다. 이름만 같은 대상을 연결하지 말고 식별 근거를 확인하세요.

1. **대응 대상**에서 행사·참가자 ID·반려견을 확인하여 선택합니다. 확인이 안 되면 **대상 미연결**로 남길 수 있습니다.
2. 연결했다면 **대응 회차**를 선택합니다. 한 회차만 있는 경우 선택값이 채워질 수 있으므로 실제 회차도 확인합니다.
3. **대응 근거**를 **운영자 직접 확인**, **안정 식별번호**, **표기 차이 직접 확인** 중 실제 근거에 맞게 고릅니다.
4. **원본 참여 상태**를 **참여**, **참여 중단**, **미확인** 중 전달 사실에 맞게 선택합니다. 이는 참고 출처 분류이며 현재 참가자 업무를 차단하는 동의·삭제 정책이 아닙니다.
5. **대응 확인 사유**에 어떤 식별 자료로 확인했는지 적습니다.
6. **선택한 입력 r숫자**를 확인합니다. 입력이 이후 바뀌었다는 안내가 있으면 대상·회차를 다시 확인하고 명시적으로 선택을 교체합니다.

미연결·미확인·참여 중단 자료는 독립 정답 분모의 정상 자료로 취급하지 않습니다. 현재 기능에서는 검수 참고 자료 전체가 확정 독립 정답과 별도로 유지됩니다.

## 5 미리보기하고 참고 자료 등록하기

1. **참고 등록 사유**를 입력합니다. 예: `전달 검수표의 1차 촬영 참고값과 확정 상태를 원본 그대로 보존`.
2. **선택 자료 미리보기**를 누릅니다.
3. **등록 전 분류 확인**에서 대상·코드·원값·확정 및 노출 상태·원본 목록 대응을 확인합니다.
4. 확인 후 **참고 자료로 등록**을 누릅니다.
5. **검수 참고 자료를 등록했습니다. 현재 점수와 독립 정답에는 반영하지 않습니다.** 알림을 확인합니다.
6. 등록 목록에서 **참고 기록 열기**를 누르고 보존 셀·대응 근거·등록 시각을 다시 확인합니다.

미리보기 후 선택값·상태·대응표·사유를 바꾸면 미리보기를 다시 해야 합니다. **미등록 선택 비우기**는 아직 등록하지 않은 파일과 선택을 버립니다. 이미 등록한 참고 기록을 삭제하는 버튼은 아닙니다.

목록 제목에 **내가 등록한 참고 자료**라고 표시되더라도 현재 정책과 API의 참고 자료는 공통 조회 대상입니다. 다른 직원이 등록한 보존 자료도 열 수 있으며 별도 공개 허가는 없습니다.

## 6 문제 해결

| 상황 | 해결 방법 |
| --- | --- |
| 파일 검사 실패 | 확장자가 XLSX인지, 20 MiB 이하인지, 실제 파일이 손상되지 않았는지 확인합니다. |
| 참고 행 추가가 안 됨 | 원본 대상·코드·셀 주소·판본·선택 사유를 확인합니다. 평가자 명시 확인을 선택했다면 이름도 입력합니다. |
| 등록 버튼이 비활성 | 현재 선택으로 미리보기했는지 확인합니다. 연결한 대상에는 회차와 대응 사유가 필요합니다. |
| 셀 값이 없음 | 주소와 시트를 먼저 대조합니다. 실제 빈 셀만 결측으로 남기며 0으로 바꾸지 않습니다. |
| 제공 차단 표시 | 원본·참고 파일 유실이나 해시 오류 등 사유를 담당자가 확인합니다. 정상 다른 참고 자료는 계속 이용합니다. |
| 등록했는데 채점표 값이 그대로 | 정상입니다. 참고 등록은 채점값 변경이 아니므로 실제 관찰·채점은 독립 채점 화면에서 별도로 합니다. |
