# K-DOG 개발 설정 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 제품 기준: `main / 53889b7` · 평가 기준: S1.1

메뉴 경로는 **자료 관리 → 개발 설정**이며 **개발자 로그인에서만** 사용합니다. 운영자·교수자는 AI 실행 준비 안내에 키·활성 설정 부족이 나오면 개발자에게 해당 내용을 전달합니다. 공통 업무용 계정을 개발자로 바꿀 필요는 없습니다.

## 1 언제 사용하나요

새 PC에 공급자 키를 등록할 때, 키를 교체·폐기할 때, AI 관찰 항목군의 입력 방식·프롬프트·예산을 조정하고 적용할 때 사용합니다. 복원 후 키 재등록도 이 화면에서 수행합니다.

설정 변경은 이후 새 실행의 기준이 됩니다. 이미 시작한 실행은 고정된 설정을 보존하므로 설정을 바꾸었다고 진행 중 실행이나 이전 결과가 다시 계산되지는 않습니다.

## 2 공급자 키 등록과 연결 시험

1. 개발자 계정으로 로그인하고 **개발 설정**을 엽니다.
2. **공급자 키 관리**에서 **키 공급자**를 선택합니다. 화면의 Gemini·OpenAI·Anthropic은 키 보관 대상이며, 키 등록만으로 모든 공급자가 현재 분석 파이프라인에 연결되는 것은 아닙니다. 실행에서 실제 요구하는 공급자를 확인합니다.
3. **새 API 키**에 실제 키를 입력하고 **키 등록·교체**를 누릅니다.
4. **키를 보호하여 저장했습니다** 알림과 해당 공급자의 **등록됨** 표시를 확인합니다. 저장한 키 원문은 다시 조회할 수 없습니다.
5. **키 연결 시험**을 눌러 연결 상태를 확인합니다. 이는 공급자의 모델 목록 API에 실제 접속하는 시험으로, 영상 판독 품질 시험은 아닙니다.

키는 서버의 Windows 실행 계정에 연결된 DPAPI로 보호됩니다. 중앙 서버를 이용하면 키는 촬영 브라우저 PC가 아니라 서버에 저장됩니다. 앱을 실행하는 같은 Windows 계정에서 등록·사용하세요. 백업에는 키가 포함되지 않습니다.

키를 폐기할 때는 선택한 공급자를 확인하고 **선택 공급자 키 폐기**를 누릅니다. 폐기 후 환경 변수의 키로 자동 복귀하지 않습니다. 다시 사용할 경우 새 키를 명시적으로 등록합니다.

## 3 항목군 AI 설정 확인하기

**관찰 원자료 AI 설정**에서 활성 설정·항목군·예정 호출 수·비용 상태를 확인합니다. 자동 산출 항목은 앱이 계산하며 규칙 확인 대기 항목군에는 외부 공급자 호출을 하지 않습니다. ‘미측정’ 비용을 0원으로 해석하지 마세요.

1. **설정할 항목군**에서 조정할 코드와 관찰창을 선택합니다.
2. 영상·오디오 여부, 전체 창 관찰 필요 여부, 기회 조건과 표시 모델을 확인합니다. 모델은 현재 화면에서 표시값이며 자유 입력란이 아닙니다.
3. **입력 클립**에서 AI용 또는 원본 FPS 클립을 선택합니다.
4. **영상 읽기 방식**을 선택합니다. **정적 읽기**는 요청 FPS를 지정하고 **동적 읽기**는 공급자가 선택합니다.
5. 정적 읽기라면 **공급자 요청 FPS**를 확인합니다. AI용 클립은 최대 1 FPS, 원본 클립 요청은 최대 10 FPS입니다. 클립 제작 FPS와 공급자 요청 FPS는 다른 값입니다.
6. **입력 해상도**, **추론 수준**, **출력 토큰 상한**, **항목군 프롬프트**를 필요한 범위만 변경합니다.

기존 영상에 없는 프레임을 설정으로 늘려 관찰량이 늘었다고 볼 수는 없습니다. 오디오는 연속 구간을 사용합니다. 규칙 확인 대기 항목군의 공급자 입력은 비활성 상태로 두고 임의 산식이나 확정값을 프롬프트에 추가하지 않습니다.

## 4 호출과 시도 상한 설정하기

| 설정 | 허용 조건과 의미 |
| --- | --- |
| 전체 호출 상한 | 화면의 예정 공급자 호출 수 이상, 최대 1000의 정수. 호출 예산 상한이며 진행률이 아님 |
| 단계 시도 상한 | 1~3의 정수. 단계의 재시도 한도 |
| 스키마 수리 상한 | 0~1. 응답 형식 보정의 한도 |
| 항목군 출력 토큰 상한 | 256~65536의 정수 |
| 항목군 프롬프트 | 빈 문자열 불가. 코드·관찰 범위·기회·결측 조건을 유지 |

변경 뒤 **관찰 원자료 적용 범위를 확인했습니다** 체크의 의미를 읽고 실제 범위를 확인한 경우에만 선택합니다. AI 애착 판단의 실제 적절성은 별도 교수 테스트 대상입니다.

## 5 초안을 저장하고 활성화하기

1. 변경 내용을 확인하고 **설정 초안 저장**을 누릅니다.
2. **활성 설정과의 차이**에서 바뀐 항목을 확인합니다. 초안 저장만으로 활성 설정이 바뀌지 않습니다.
3. 필요한 경우 **합성 스키마 검증 · 외부 호출 없음**을 누릅니다. 선택한 항목군의 형식 계약을 합성 자료로 확인하며 실제 영상을 공급자에게 보내지 않습니다.
4. 적용할 저장본을 **보존 AI 설정**에서 선택합니다. 미저장 변경이 있으면 먼저 저장하거나 명시적으로 버립니다.
5. 저장본의 범위 확인과 차이를 확인한 뒤 **선택한 설정 활성화**를 누릅니다.
6. **관찰 원자료 설정을 활성화했습니다** 알림과 활성 설정 표시를 확인합니다.

합성 스키마 통과는 실제 영상 판독 정확도·처리시간·문장 품질이 검증되었다는 뜻이 아닙니다. 실제 검수 상태는 [실측 후속 대장](../archive/개발반영_20261003/K-DOG_실측및확인후속대장_v1.0_20261003.md)을 따릅니다.

## 6 문제 해결

| 상황 | 해결 방법 |
| --- | --- |
| 메뉴 접근 불가 | 상단 계정 표시가 개발자인지 확인합니다. 일반 계정은 공통 업무를 사용하며 개발 설정은 열 수 없습니다. |
| 키 연결 실패 | 공급자 선택·등록 상태·서버 네트워크·실행 Windows 계정과 반환 오류를 확인합니다. 키 원문을 업무 기록에 붙이지 않습니다. |
| 설정 저장 거절 | 프롬프트·토큰·호출 및 시도 상한·FPS 범위를 확인합니다. |
| 활성화 버튼이 비활성 | 보존 설정 선택·범위 확인 체크·미저장 수정 유무를 확인합니다. |
| 다른 활성 설정이 저장됨 | 현재 입력과 편집 시작 판본을 보존한 채 **AI 설정 새로고침**으로 확인합니다. 필요하면 **미저장 설정 버리고 최신 조회** 후 다시 입력합니다. |
| 활성화했는데 과거 실행이 그대로 | 정상입니다. 과거 실행은 고정 설정을 사용합니다. 새 설정 검토는 명시적으로 새 실행을 만들어 진행합니다. |
