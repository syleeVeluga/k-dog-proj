## 1. 이 화면은 언제 사용하나요?

행사에 참가하는 보호자와 반려견의 기본 정보를 한 명씩 등록하거나, 이미 접수된 참가자의 ID·진행 순번·반려견 정보를 정정할 때 사용합니다. 참가자 접수는 설문·영상·촬영 기록을 연결할 대상부터 만드는 단계입니다.

명단이 CSV나 Excel에 이미 정리되어 있거나 보호자 설문 응답 파일을 받았다면 [일괄 등록](K-DOG_일괄등록_사용설명서_v1.0_20261013.md)을 사용하세요. 이 화면의 참가자 등록 양식에는 설문 응답 입력 칸이 없습니다.

| 하려는 일 | 이 화면에서 할 일 |
|---|---|
| 현장에서 한 참가자를 새로 접수 | `참가자 등록`을 펼쳐 기본 정보 저장 |
| 같은 행사 참가자를 연속 접수 | `참가자 저장`을 누르고 다음 참가자 계속 입력 |
| 접수 직후 정보를 확인 | `저장하고 상세 열기` 선택 |
| 순번·견명·예약 시각 오타 수정 | 목록에서 대상 열기 → `참가자 기본 정보 정정` |
| 설문이나 영상이 부족한 참가자 찾기 | `자료 상태` 필터 사용 |
| 설문 파일 등록·설문 응답 수정 | `일괄 등록`으로 이동 |
| 영상·8구간·촬영 메모·재촬영 관리 | 영상 파일 업로드·촬영 기록 메뉴로 이동 |

## 2. 로그인별 사용 범위와 시작 조건

| 로그인 계정 | 접수에서 가능한 작업 |
|---|---|
| 운영자 `operator` | 전체 참가자 조회, 새 참가자 등록, 기본 정보 정정 |
| 교수자·검토자 `reviewer` | 운영자와 같은 작업 |
| 관리자 `admin` | 운영자와 같은 작업 |
| 개발자 `developer` | 같은 접수 업무 수행, 개발자 설정은 별도 메뉴 |

운영자·교수자·관리자의 현재 화면상 계정 이름은 모두 **업무 계정**입니다. 교수자 전용 접수 화면이나 관리자 승인 절차는 없습니다. 다른 직원이 등록한 참가자도 조회하고 수정할 수 있으며, 저장한 실제 로그인 계정이 기록됩니다.

시작 전에 다음을 준비하세요.

1. 사용 중인 계정으로 로그인합니다. 비활성 계정은 로그인할 수 없습니다.
2. 행사의 공통 **행사 ID**를 확인합니다. 같은 행사를 `KDOG-2026`과 `KDOG_2026`처럼 다르게 적으면 서로 다른 행사로 취급됩니다.
3. 참가자에게 사용할 **참가자 ID**와 **반려견 이름**을 확인합니다. 이름이 같은 사람이나 반려견은 ID로 구별합니다.
4. 같은 행사에 이미 접수된 대상인지 먼저 검색합니다. 중복 접수를 피하려면 이름만 보고 새로 만들지 말고 행사와 참가자 ID를 함께 확인하세요.

동의 입력·배정·소유자 허가·공개 승인은 접수 조건이 아닙니다. 이 화면은 연락처를 받지 않습니다. 과거 동의·삭제 관련 기록은 현행 접수의 차단 조건으로 사용하지 않습니다.

## 3. 한 명씩 참가자를 등록하는 방법

### 3.1 등록 양식 열기

1. 메뉴에서 **참가자 접수**를 엽니다.
2. 목록 아래의 **참가자 등록**을 누릅니다. 등록된 참가자가 없는 경우에는 양식이 처음부터 열려 있습니다.
3. 다음 표를 참고해 정보를 입력합니다. 모르는 선택 정보는 비워 두거나 `미기재`를 선택해도 됩니다.

| 입력 항목 | 필수 여부·입력 방법 | 실수하기 쉬운 부분 |
|---|---|---|
| 행사 ID | 필수. 영문·숫자·밑줄·하이픈, 최대 100자. 예: `KDOG-2026` | 한글·공백을 넣지 않습니다. 행사 내 공통 값을 사용합니다. |
| 참가자 ID | 필수. 영문·숫자·밑줄·하이픈, 최대 100자. 예: `0001` | `0001`과 `1`은 다릅니다. 앞자리 0을 그대로 적습니다. |
| 순번 | 선택. 행사 안에서 중복 없는 1~9999의 정수 | 참가자 ID와 별개인 현장 진행 순서입니다. 비우면 미지정입니다. |
| 반려견 이름 | 필수. 최대 200자 | 보호자 이름을 잘못 넣지 않았는지 확인합니다. |
| 보호자명 | 선택. 최대 100자 | 같은 이름이어도 참가자 ID는 각각 사용합니다. |
| 견종 | 선택. 최대 100자 | 모르면 빈칸으로 둡니다. |
| 성별 | `미기재`, `암`, `수`, `중성화` 중 선택 | 실제 확인한 값을 선택합니다. |
| 나이(세) | 선택. 0~30의 정수 | `8개월`을 넣는 칸이 아닙니다. 개월을 자동 변환하지 않습니다. |
| 크기 | `미기재`, `소형`, `중형`, `대형` 중 선택 | 모르면 `미기재`를 사용합니다. |
| 함께 산 기간 | 선택. 예: `3년`, `8개월`, 최대 50자 | 문자로 기간을 적을 수 있습니다. |
| 입양 경로 | `미기재`, `분양`, `입양`, `기타` 중 선택 | 확인되지 않은 정보를 추정하지 않습니다. |
| 예약 시각 | 선택. 날짜와 시각 입력 | 행사 현지 시각입니다. 비우면 미예약으로 표시합니다. |

같은 행사에 이미 순번을 지정한 참가자가 있으면 현재 가장 큰 순번의 다음 번호를 제안합니다. 이 값은 제안이므로 다른 순번으로 고치거나 지울 수 있습니다. 예를 들어 순번이 1·3·5라면 6을 제안하며, 비어 있는 2를 자동으로 채우지는 않습니다.

### 3.2 저장 버튼 선택

1. 행사 ID·참가자 ID·반려견 이름을 다시 확인합니다.
2. 다음 참가자도 이어서 받을 경우 **참가자 저장**을 누릅니다.
3. 저장되면 `참가자를 등록했습니다.` 알림과 마지막 등록 참가자 표시를 확인합니다. 화면에 머물러 다음 참가자를 입력할 수 있고, 참가자 ID 칸으로 입력 위치가 이동합니다. 행사 ID는 계속 유지됩니다.
4. 등록한 대상의 상세 정보를 바로 확인하려면 **저장하고 상세 열기**를 누릅니다.

저장 후 마지막 등록 표시의 **상세 보기**로 해당 참가자를 다시 열 수 있습니다. **촬영으로**를 누르면 등록한 참가자를 선택한 상태로 촬영 기록 화면으로 이동합니다.

입력 오류가 있으면 해당 칸 아래에 안내가 나오고 첫 오류 칸으로 이동합니다. 화면 이동 시 저장하지 않은 입력에 대한 확인이 나타나면 계속 입력할 것인지, 저장하지 않고 이동할 것인지 판단하세요.

## 4. 참가자를 찾고 자료 현황을 확인하는 방법

1. **검색**에 순번, 참가자 ID, 반려견 이름 또는 보호자명을 입력합니다.
2. **행사 필터**에서 해당 행사를 선택합니다. 이름이 같은 대상이 여럿이면 행사와 참가자 ID를 함께 대조하세요.
3. **자료 상태**에서 필요한 조건을 고릅니다.

| 자료 상태 | 목록에 나오는 대상 |
|---|---|
| 전체 | 검색·행사 조건에 맞는 모든 참가자 |
| 설문·영상 등록됨 | 현재 선택된 회차의 설문 등록 수가 28이고 영상이 한 개 이상인 참가자 |
| 설문·영상 보완 필요 | 위 두 조건을 함께 만족하지 않는 참가자 |
| 설문 미등록 | 현재 회차의 설문 등록 수가 28보다 적은 참가자. 일부 응답만 있는 대상도 포함 |
| 영상 없음 | 현재 회차에 영상이 없는 참가자 |

목록은 순번이 있는 참가자를 먼저 순번순으로 표시하고, 같은 조건에서는 참가자 ID순으로 정렬합니다. `설문`의 `28/28`은 화면에서 센 응답 현황입니다. 등록 완료에 관한 별도 기준이 확정되었다거나 채점·발급까지 끝났다는 뜻은 아닙니다.

`영상`, `구간`, 채점 진행 표시는 다음 작업을 찾는 참고입니다. 영상이 한 개 있다고 해서 필요한 모든 카메라 자료가 갖춰졌거나 영상 분석이 가능한 상태로 검증됐다는 뜻은 아닙니다. 자세한 상태는 해당 기능 화면에서 확인하세요.

다른 직원의 변경을 반영하려면 **새로고침**을 누릅니다. 검색 결과가 없으면 검색어를 지우고 행사·자료 상태 필터를 차례로 `모든 행사`·`전체`로 돌려 확인하세요.

## 5. 기본 정보 정정과 결과 확인

1. 대상 행 또는 **열기** 버튼을 누릅니다.
2. 상세 위쪽에서 행사 ID, 참가자 ID, 순번, 반려견 이름, 보호자명, 예약 시각을 확인합니다. 옆에 현재 **입력 버전**이 표시됩니다.
3. **자료 관리 → 참가자 기본 정보 정정**을 펼칩니다.
4. 필요한 항목만 고칩니다. 이 양식에서는 행사 ID를 변경하지 않습니다.
5. **기본 정보 정정 저장**을 누릅니다.
6. `기본 정보를 정정했습니다.` 알림과 저장된 내용을 확인합니다. 정정은 새 입력 버전으로 저장되며 이전 자료는 보존됩니다.

입력 중 다른 직원이 먼저 수정했거나 최신 자료를 다시 확인해야 한다면 **최신 기본 정보 불러오기**를 사용합니다. 저장 전 편집 내용을 버리고 최신 정보로 다시 시작하는 기능이므로, 필요한 정정 내용을 메모한 후 누르세요. 자료가 바뀌어 저장이 거절된 경우에도 최신 내용을 확인한 뒤 다시 수정합니다.

상세의 **촬영 세션**에는 현재 회차의 영상 수, 구간 상태, 설문 수, 촬영 메모가 나옵니다. **기술 정보**를 펼치면 촬영 기준과 설문 판본을 확인할 수 있습니다. 접수 목록으로 돌아가려면 **← 접수 목록**을 누릅니다.

## 6. 자주 생기는 실수와 해결 방법

| 상황 | 확인·해결 방법 |
|---|---|
| `참가자 ID` 오류로 저장되지 않음 | 한글·공백을 없애고 영문·숫자·밑줄·하이픈만 사용합니다. 같은 행사에 같은 ID가 있는지 검색합니다. 기존 대상이면 새 등록 대신 상세에서 정정합니다. |
| 순번이 중복이라고 나옴 | 행사 필터에서 같은 순번을 찾고, 대상의 순서를 확인한 뒤 다른 번호를 쓰거나 비웁니다. |
| `0001` 대신 `1`로 등록함 | 참가자 상세에서 ID를 정정합니다. 설문 파일의 ID도 정정된 값과 정확히 맞추세요. |
| 나이에 소수나 개월을 입력함 | 정수 세 단위만 입력합니다. 확인할 수 없다면 빈칸으로 둡니다. |
| 등록했는데 검색되지 않음 | 저장 알림을 확인하고 새로고침합니다. 행사·자료 상태 필터와 검색어를 해제해 봅니다. |
| 설문 필터에서 일부 응답자도 `설문 미등록`으로 나옴 | 이 필터는 28문항에 도달하지 않은 대상도 포함합니다. 설문 현황에서 빠진 문항을 확인하세요. |
| 저장할 때 자료가 바뀌었다는 알림이 나옴 | 다른 직원의 변경이 반영될 수 있습니다. 최신 기본 정보를 불러와 대조한 후 다시 저장합니다. |
| 잘못된 행사로 접수함 | 상세 정정에는 행사 ID 변경 기능이 없습니다. 같은 대상을 임의로 재등록하기 전에 책임자에게 올바른 데이터 정리 방법을 확인하세요. |
| 세션이 만료되어 로그인 화면으로 돌아감 | 다시 로그인한 뒤 대상과 최신 내용을 확인하고 저장합니다. 저장 성공 알림을 확인하지 못한 경우 먼저 목록을 확인해 중복 등록을 피합니다. |

- 응답 여부와 누락 문항을 확인하려면 [설문 현황](K-DOG_설문현황_사용설명서_v1.0_20261013.md)을 엽니다.
- 촬영 파일을 등록하려면 [영상 파일 업로드](K-DOG_영상파일업로드_사용설명서_v1.0_20261013.md)를 사용합니다.
