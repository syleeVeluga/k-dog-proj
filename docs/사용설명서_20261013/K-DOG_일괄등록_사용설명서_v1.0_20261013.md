## 1. 무엇을 등록하는 화면인가요?

참가자 명단과 보호자 설문 28문항 원응답을 CSV 또는 Excel 파일로 등록합니다. Google Forms 등에서 내려받은 응답 파일도 열 이름을 연결해 사용할 수 있습니다. 파일을 올린 뒤 **열 연결 → 미리보기 → 확정** 순서로 진행합니다. 파일 선택이나 미리보기만으로 참가자·설문 저장이 완료되지는 않습니다.

| 상황 | 권장 방법 |
|---|---|
| 여러 참가자의 기본 정보를 한 번에 접수 | `명단만` 표준 양식 |
| 새 참가자의 명단과 설문을 함께 접수 | `명단 + 설문 28문항` 표준 양식 |
| 이미 접수한 참가자의 설문 보완 | 같은 행사 ID·참가자 ID가 있는 파일로 갱신 |
| 기존 촬영 회차를 지정해 설문 전체를 교체 | 고급 `기존 참가자·회차에 명시적으로 연결` 사용, 전체 대체 범위 확인 필수 |
| 과거 설문 판본의 원파일을 참고로 보관 | 고급 `과거 판본 원자료 참고만 등록` 사용 |

**이 화면은 행동 점수 Excel을 채점 시트로 가져오는 기능이 아닙니다.** G01/G04 원본 파일 확인이 필요한 S1 점수 Excel import는 미활성 상태입니다. 참가자·설문 일괄 등록이 가능하다는 사실을 점수 가져오기 완료로 해석하지 마세요.

## 2. 로그인별 사용 범위와 준비 조건

운영자 `operator`, 교수자·검토자 `reviewer`, 관리자 `admin`, 개발자 `developer` 모두 참가자·설문 파일을 등록하고 기존 참가자 자료를 수정할 수 있습니다. 운영자·교수자·관리자는 화면에서 **업무 계정**으로 표시됩니다. 다른 직원의 참가자와 회차를 사용하기 위한 배정이나 승인 절차는 없습니다. 실제 확정 계정과 원파일·원행·열 연결의 출처는 기록됩니다.

다음 조건을 확인한 후 시작하세요.

1. 활성 계정으로 로그인합니다.
2. 등록할 **행사 ID**를 확인합니다. 한 번의 등록은 한 행사 기준입니다.
3. 원파일을 준비합니다. 지원 확장자는 `.csv`, `.xlsx`이며 한 번에 파일 하나를 올립니다. `.xls`는 지원하지 않습니다.
4. 파일은 비어 있지 않아야 하고 **32 MiB 이하**여야 합니다. 일반 배치는 헤더를 포함해 최대 10,001행, 최대 100열입니다. 더 큰 파일은 나누어 등록하세요.
5. 일반 배치에서는 첫 행이 항목 이름이고 2행부터 참가자입니다. 머리글은 빈칸이거나 중복되어서는 안 됩니다. 공백만 다른 머리글도 중복으로 취급됩니다.
6. 수식 셀 대신 확인한 원응답 값을 넣습니다. 이 등록 기능은 수식 셀을 받지 않습니다.

현재 설문 원문 판본은 **`survey-20260929-v3`**입니다. 이는 원문 식별자이며 현재 집계는 S1의 후속 응답 정책으로 수행합니다. Q10~Q14는 **0~4 정수**, 나머지는 **1~5 정수**입니다. 0이 허용되는 문항의 0은 정상 응답입니다. 빈칸·NA를 임의로 0으로 바꾸지 않습니다. Q26~Q28도 보호자가 답한 원값을 넣고, 역채점은 앱이 처리합니다.

동의 열은 필수가 아니며 동의 상태에 따른 등록·분석 차단은 없습니다. 현재 열 연결 화면에 연락처·동의 입력 항목은 없습니다. 화면에 남아 있는 `동의 열이 없으면 미확인` 같은 설명은 과거 기록 상태에 관한 문구이며 동의 확인을 추가로 받아야 확정할 수 있다는 뜻이 아닙니다.

## 3. 처음 사용하는 경우: 표준 양식으로 등록하기

### 3.1 양식 받기와 파일 작성

1. 메뉴에서 **일괄 등록 (CSV·Excel)**을 엽니다. 참가자 접수·설문 현황의 **일괄 등록으로 이동** 버튼으로도 들어갈 수 있습니다.
2. **① 양식 받기 (선택)**에서 `명단만 Excel 내려받기` 또는 `명단 + 설문 28문항 Excel 내려받기`를 누릅니다.
3. Excel 파일의 **안내** 시트를 읽고 **입력** 시트에 참가자 한 명씩 한 줄로 작성합니다. 1행의 머리글은 유지합니다.
4. 신규 참가자에는 반려견 이름이 필요합니다. 참가자 ID도 가능한 한 직접 적으세요. ID를 비우면 새 ID가 발급되므로 같은 파일을 고쳐 다시 올릴 때 중복 참가자가 생길 수 있습니다.
5. 참가자 ID는 텍스트로 보존합니다. `0001`을 숫자 1로 바꾸지 마세요. 표준 Excel 양식은 ID 열을 텍스트로 설정합니다.
6. 행사 ID는 업로드 화면에서 입력합니다. 선택 정보를 모르면 빈칸으로 둡니다.
7. 설문 양식에는 Q01~Q28의 원응답 숫자를 넣습니다. 미응답 문항은 비웁니다. 빈칸 사유를 보존하려면 오른쪽에 `Q01 빈칸 사유`처럼 별도 열을 추가합니다.
8. 파일을 저장합니다. CSV를 쓰는 경우 Excel의 **CSV UTF-8(쉼표로 분리)**로 저장하세요. CSV를 Excel에서 다시 열고 저장하면 ID 앞자리 0이 사라질 수 있어 Excel 양식을 권장합니다.

### 3.2 파일 올리기와 행사 선택

1. **② 파일 올리기**의 **Forms 파일**에서 파일을 선택하거나 파일을 끌어다 놓습니다.
2. 파일의 열이 읽힐 때까지 기다립니다.
3. **등록 행사 ID**에 정확한 행사 ID를 입력합니다. 마지막으로 사용한 행사 ID가 제안될 수 있으므로 이번 행사와 일치하는지 확인하세요.
4. Excel에 시트가 여러 개면 **원본 시트**에서 입력 자료가 있는 시트를 고릅니다. 표준 양식은 `입력` 시트를 사용합니다.
5. 기본 배치는 `첫 행이 질문·항목, 이후 행이 참가자`입니다. 실제 파일이 다른 형태인 경우에만 고급 설정에서 변경합니다.

### 3.3 열 연결 확인

1. **③ 열 연결 확인**에서 자동 연결 수, 확인 필요 수, 연결되지 않은 열 수를 읽습니다.
2. `연결된 항목`에서 반려견 이름·참가자 ID·설문 문항이 원하는 원본 열과 연결됐는지 확인합니다.
3. 필수 열 안내가 뜨면 드롭다운에서 맞는 원본 열을 고릅니다. 새 참가자에는 반려견 이름이 필요합니다.
4. **모든 연결 보기**를 펼치면 기본 정보 열을 직접 고를 수 있습니다.
5. 설문을 등록한다면 **28문항과 빈칸 사유 연결**에서 각 원응답과 사유 열을 확인합니다.

자동 연결은 머리글을 보고 제안합니다. 셀 내용을 읽어 열 뜻을 추정하거나 이름으로 기존 참가자를 연결하지 않습니다. 모호한 머리글이나 같은 항목에 맞는 열이 여러 개면 직접 선택해야 합니다. 한 원본 열을 두 개 이상의 항목에 중복 연결할 수 없습니다.

참가자 ID 없이 신규 등록할 계획이라면 미리보기에 발급된 ID를 반드시 확인하세요. 기존 대상 갱신이 목적이라면 ID 열을 빠뜨린 채 진행하지 마세요.

### 3.4 미리보기와 확정

1. **④ 미리보기·등록 → Forms 등록 미리보기**를 누릅니다.
2. 결과의 정상 원행 수와 오류 수를 확인합니다. 각 행을 펼쳐 행사·참가자 ID·반려견 이름, 문항별 **이전 원응답 / 반영 원응답**, 빈칸 사유를 확인합니다.
3. 신규 등록인지 기존 참가자 갱신인지 확인합니다. 기존 ID와 연결된 행이 있으면 **기존 참가자 갱신 확인**을 체크합니다.
4. 오류가 없으면 **Forms 전체 확정**을 누릅니다.
5. 오류와 정상 행이 함께 있으면 오류를 모두 고쳐 다시 미리보기하거나, **정상 N행 등록 · 오류 M행 제외**를 선택합니다. 이 버튼을 누르면 정상 행만 확정되고 오류 행은 저장되지 않습니다.
6. `등록 결과: 정상 N행 등록`과 완료 알림을 확인합니다. 오류를 제외했다면 제외 행 수까지 확인하세요.
7. [참가자 접수](K-DOG_참가자접수_사용설명서_v1.0_20261013.md)에서 대상이 있는지, [설문 현황](K-DOG_설문현황_사용설명서_v1.0_20261013.md)에서 응답이 반영됐는지 확인합니다.

파일·행사·시트·열 연결·라벨·대상을 변경하면 이전 미리보기는 무효가 됩니다. 변경 후에는 반드시 다시 미리보기합니다. 이미 확정한 **같은 미리보기**를 재확정해도 참가자가 추가되지는 않지만, ID 없는 파일을 새로 올려 새 미리보기를 만드는 것은 새 ID를 발급할 수 있습니다.

## 4. 기존 참가자의 설문만 보완하는 방법

### 4.1 정확히 같은 ID로 자동 연결: 일반적인 보완 작업

1. 파일에 **참가자 ID 열**을 넣고 접수된 ID와 정확히 같게 작성합니다.
2. 등록 행사 ID도 기존 대상의 행사와 같게 선택합니다.
3. 참가자 ID·수정할 설문 문항을 연결하고 미리보기합니다.
4. 결과가 **기존 참가자 갱신**으로 표시되는지 확인합니다. ID 연결은 현재 선택된 촬영 회차를 대상으로 합니다. 필요한 회차는 공통 화면에서 먼저 확인하세요.
5. 파일의 반려견 이름이 접수된 이름과 다르면 경고가 나옵니다. 이름이 아니라 ID로 연결한 결과이므로 ID 오타인지 확인하세요.
6. 이전·반영 값을 대조한 뒤 **기존 참가자 갱신 확인**을 체크하고 확정합니다.

이 방식은 **설문만 갱신**합니다. 파일의 이름·견종·순번 등 기본 정보로 접수 정보를 덮어쓰지 않습니다. 기본 정보는 참가자 상세에서 정정합니다.

| 같은 ID로 갱신할 때 파일 내용 | 기존 설문의 반영 결과 |
|---|---|
| 문항에 유효한 숫자·명시한 라벨이 있음 | 해당 문항을 파일 값으로 변경하고 기존 빈칸 사유 제거 |
| 문항이 빈칸이며 사유도 없음 | 기존 응답·사유 유지 |
| 문항 열을 연결하지 않음 | 기존 응답·사유 유지 |
| 문항은 빈칸이고 빈칸 사유가 명시됨 | 해당 문항을 미응답으로 변경하고 사유 기록 |
| 모든 응답·사유가 기존과 같음 | 출처는 기록하지만 새 입력 버전을 만들지 않음 |

예를 들어 기존 Q01=3, Q02=4인데 파일에서 Q01=5, Q02는 빈칸이면 Q01만 5로 변경하고 Q02=4는 유지합니다. Q02를 실제 미응답으로 바로잡으려면 Q02를 비우고 **Q02 빈칸 사유**에 확인한 사유를 입력·연결한 뒤 미리보기합니다. 사유를 추정해 적지는 마세요.

### 4.2 특정 회차에 명시적으로 연결: 전체 대체가 필요한 경우

여러 회차 중 지정한 회차를 대상으로 하거나 ID 열이 없는 원파일을 확인된 기존 대상에 연결할 때 사용합니다. 단순한 누락 보완에는 위 ID 갱신 방식을 권장합니다.

1. **모든 연결 보기 → 기존 참가자·회차에 명시적으로 연결**을 펼칩니다.
2. **기존 대상 연결 추가**를 누릅니다.
3. **원행 번호**를 입력합니다. 일반 파일은 첫 참가자가 2행, 전치 파일은 첫 참가자 열이 2입니다.
4. **기존 참가자**를 행사·ID·반려견 이름으로 확인하고 선택합니다.
5. **촬영 회차**에서 대상 회차를 고릅니다. 한 파일에서 여러 행을 같은 참가자에 연결할 수 없습니다.
6. **Forms 등록 미리보기**를 누르고 행의 전후 값을 반드시 확인합니다.
7. 의도한 전체 응답 구성인지 확인한 후 확정합니다.

**명시적 연결은 ID 자동 갱신의 빈칸 유지 방식과 다릅니다.** 해당 회차 설문 전체를 미리보기의 응답 구성으로 대체하므로 파일의 빈칸과 연결하지 않은 문항은 미응답이 될 수 있습니다. 필요한 모든 문항과 빈칸 사유를 준비하고, 미리보기에서 사라질 기존 값까지 확인하세요. 파일에 참가자 ID를 적었다면 선택한 대상 ID와도 일치해야 합니다.

대상이 미리보기 전후로 수정되어 충돌하면 **대상 최신 상태로 다시 연결**을 누르고 다시 미리보기합니다. 연결할 원행을 잘못 지정했다면 **이 연결 제거**로 지우거나 번호를 수정합니다.

## 5. 문장 응답, 저장한 연결 설정, 다른 배치 사용

### 5.1 문장 응답을 숫자 원응답에 연결하기

1. 설문 열을 연결한 뒤 해당 문항의 **원라벨=원점수** 칸에 원파일의 문장과 원점수 관계를 한 줄씩 적습니다.
2. 예: `전혀 그렇지 않다=1`, `그렇다=4`. 문장의 의미를 임의로 정하지 말고 실제 설문에서 사용한 원척도와 일치시킵니다.
3. 여러 문항이 같은 척도를 쓰면 **선택 문항에 같은 라벨 적용**을 펼칩니다.
4. **적용할 문항**에 `1-9, 15-28`처럼 범위를 적고 라벨을 입력한 뒤 같은 이름의 버튼을 누릅니다. 비우면 연결된 모든 문항에 적용합니다.
5. Q10~Q14는 0~4만 허용하므로 5가 들어 있는 라벨은 이 문항들을 제외해 적용합니다.
6. 미리보기에서 실제 반영 숫자를 확인합니다.

숫자 원응답은 허용 범위이면 그대로 읽습니다. Q26~Q28에 `6-원응답`으로 미리 변환한 숫자를 입력하지 마세요. 원응답을 넣어야 앱의 역채점 결과가 맞습니다.

### 5.2 열 연결 설정 저장·불러오기

같은 Forms 양식의 파일을 자주 받는다면 **열 연결 설정 저장·불러오기**를 사용합니다.

1. 열·문항·라벨 연결을 확인한 상태에서 **새 설정 이름**에 알아보기 쉬운 이름을 적습니다. 예: `2026 가을 신청폼`.
2. **현재 연결 저장**을 누릅니다. 이 기능은 열 연결을 저장하며 참가자 확정을 대신하지 않습니다.
3. 다음 파일을 올린 뒤 저장된 설정을 선택하고 **선택한 설정 불러오기**를 누릅니다.
4. 파일에 없는 열은 연결되지 않았다는 안내를 확인하고 수정합니다. 배치가 다르다는 안내가 나오면 고급 설정을 확인합니다.
5. 적용 후 다시 미리보기합니다.

저장된 설정은 같은 서버를 사용하는 다른 PC에서도 보입니다. **선택한 설정 삭제**는 확인창을 거쳐 연결 설정을 삭제합니다. 참가자·설문을 삭제하는 기능은 아닙니다.

### 5.3 고급 설정이 필요한 경우

| 설정 | 언제 사용하며 무엇을 확인하나요? |
|---|---|
| 파일 배치 | 첫 열이 항목이고 이후 열이 참가자라면 `첫 열이 질문·항목, 이후 열이 참가자` 선택. 전치 표는 각 행의 열 수가 같아야 합니다. |
| 원자료 프로필 | 파일의 출처·양식 식별용 값. 기본 `google-forms`에서 바꿨다면 담당자와 식별 이름을 맞춥니다. 비울 수 없습니다. |
| 매핑 버전 | 열 연결 방식의 식별용 값. 기본 `forms-map-1`. 임의로 비우지 않습니다. |
| 과거 판본 원자료 참고만 등록 | 현재 판본과 다른 원자료를 참고로 보존할 때 선택하고 `원문 설문 판본` 입력. 과거 척도를 자동 환산하거나 S1 집계에 넣지 않습니다. |

전치 파일도 원자료 기준 행·열 수 제한을 먼저 검사합니다. 일반 배치의 10,000명 제한이 전치 배치에 그대로 적용된다고 생각하지 말고, 큰 전치 파일은 나누거나 일반 배치로 정리하세요.

## 6. 오류 해결과 제외 행 재등록

| 안내·상황 | 해결 방법 |
|---|---|
| 미리보기 버튼이 비활성 | 버튼 옆 사유를 읽습니다. 파일·열 읽기·행사 ID·필수 열·과거 판본·프로필/버전을 차례로 확인합니다. |
| 참가자 ID는 텍스트여야 한다고 나옴 | Excel ID 셀을 텍스트로 다시 입력합니다. 이미 숫자 1이 된 값을 서식만 바꿔도 0001이 복구되지는 않으므로 원ID를 확인하세요. |
| 신규 행에 반려견 이름이 없음 | 이름을 추가하거나 확인된 기존 대상에 연결합니다. 기존 ID가 정확히 일치하면 이름 없이 설문 갱신이 가능합니다. |
| 원행 행사 ID가 선택한 행사와 다름 | 파일의 연결된 행사 열과 등록 행사 ID를 맞추거나 행사별로 파일을 나눕니다. |
| ID·순번 중복 | 파일 내부와 기존 접수 명단을 확인합니다. 같은 기존 참가자를 가리키는 행이 두 개이면 한 행으로 정리합니다. |
| 척도 범위·라벨 오류 | Q10~Q14=0~4, 나머지=1~5 정수를 확인합니다. 문자 응답은 원라벨=원점수를 명시합니다. |
| 빈칸 사유 오류 | 값이 있는 문항에 빈칸 사유를 적지 않습니다. 실제 미응답인 문항의 사유만 문자로 적습니다. |
| 열 수·헤더·수식 오류 | 헤더 빈칸/중복, 각 행의 열 수, 수식 셀을 정리하고 원값 파일을 다시 올립니다. |
| 미리보기 이후 다른 변경으로 확정 거절 | 최신 참가자 상태를 확인하고 다시 미리보기합니다. 명시 연결이면 `대상 최신 상태로 다시 연결`도 사용합니다. |
| 응답 없이 명단만 등록됨 | 설문 열을 연결했는지 확인합니다. 참가자 ID를 유지한 설문 파일로 다시 갱신합니다. |
| 과거 판본 회차에서 S1 결과를 볼 수 없음 | 원자료 참고 상태는 정상적으로 S1 집계에서 제외됩니다. 판본 이름만 현재 것으로 바꿔 결과를 만들지 않습니다. |

오류 행이 있으면 **오류 행 CSV 내려받기**로 원행과 오류 사유를 받습니다. 정상 행을 먼저 확정했다면 이 오류 행 파일만 고쳐 다시 올리고 이미 확정한 정상 행을 반복 등록하지 않도록 확인하세요. 참가자 ID가 있는 수정 파일은 같은 행사에 연결합니다.

전치 파일의 오류도 **일반 배치 CSV**로 내려받습니다. 재등록할 때 고급 설정의 파일 배치를 일반으로 바꾸세요. 원행이 없는 오류는 CSV에 없을 수 있으므로 화면의 오류 안내도 확인합니다. 내려받은 파일에는 참가자 정보가 들어 있으므로 현장 PC에서 필요한 작업을 마친 뒤 삭제하세요.
