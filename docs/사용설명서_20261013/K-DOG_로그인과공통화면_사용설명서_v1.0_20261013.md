# K-DOG 로그인과 공통 화면 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 제품 기준: `main / 53889b7` · 평가 기준: S1.1

운영자와 교수자가 업무를 시작하고, 올바른 참가자와 촬영 회차를 선택하는 방법을 설명합니다. 처음 사용하시면 이 설명서를 먼저 읽고 [기능별 안내](README.md)에서 필요한 업무로 이동하세요.

## 1 로그인별 사용 범위

현재 운영자·교수자·관리자 계정은 모두 같은 업무 메뉴를 사용합니다. 교수자라는 이유로 접수나 영상 등록을 할 수 없는 제한은 없습니다. 자료를 만든 사람에게 배정·공개·재개방 허가를 받을 필요도 없습니다. 각자 본인의 계정으로 로그인하면 실제 작업한 사람이 기록됩니다.

| 계정에 저장된 구분 | 로그인 후 표시 | 사용할 수 있는 기능 |
| --- | --- | --- |
| 운영자 `operator` | 업무 계정 | 모든 공통 업무 |
| 교수자·검토자 `reviewer` | 업무 계정 | 모든 공통 업무 |
| 관리자 `admin` | 업무 계정 | 모든 공통 업무 |
| 개발자 `developer` | 개발자 | 모든 공통 업무와 개발 설정 |

공통 업무에는 참가자 접수, 일괄 등록, 설문, 영상 업로드, 촬영 기록, 전처리, 채점, AI 분석, 해석·최종 결과, 리포트, 비교 조건, 연구 내보내기, 검수 자료, 직원 계정, 백업이 포함됩니다. 개발 설정의 공급자 키와 AI 설정은 개발자 로그인에서만 관리합니다.

## 2 언제 로그인하나요

촬영 당일 접수·자료 등록을 시작할 때, 교수자가 관찰값이나 해석을 검토할 때, 리포트를 발급할 때 로그인합니다. 공동 PC에서 담당자가 바뀌면 이전 사람이 로그아웃하고 다음 사람이 자기 계정으로 로그인하세요. 동일 계정을 여러 사람이 나누어 쓰면 기록만으로 실제 작업자를 구별할 수 없습니다.

준비할 것은 활성 계정과 비밀번호, 접속 주소입니다. 계정이 없다면 [직원 계정 안내](K-DOG_직원계정_사용설명서_v1.0_20261013.md)에 따라 기존 업무 계정으로 추가합니다. 앱 계정은 Windows 로그인 계정과 별개이고 기본 비밀번호는 없습니다.

## 3 실행하고 로그인하기

1. 개인 PC에 설치했다면 K-DOG 바로가기 또는 설치 폴더의 `Start.cmd`를 실행합니다. 중앙 서버를 사용하는 촬영 PC에서는 담당자가 전달한 같은 HTTPS 주소를 브라우저로 엽니다.
2. 실행 창에서 준비가 끝나면 브라우저가 열립니다. 자동으로 열리지 않으면 실행 창에 표시된 주소를 브라우저에 입력하세요.
3. 로그인 화면의 **계정**, **비밀번호**에 발급받은 값을 입력하고 **로그인**을 누릅니다.
4. 상단의 계정 이름을 확인합니다. 일반 업무 계정은 보통 **참가자 접수**, 개발자는 **개발 설정**으로 들어갑니다. 유효한 메뉴 주소를 열어 둔 경우 해당 메뉴로 진입할 수 있습니다.
5. 왼쪽 메뉴에서 필요한 기능을 선택합니다. 화면이 좁으면 상단 메뉴 버튼을 열어 같은 메뉴를 선택합니다.

실행 창은 업무 중 최소화해 두세요. 브라우저 탭을 닫아도 서버 작업은 계속됩니다. 실행 창을 닫거나 `Ctrl+C`를 누르면 API와 작업 프로그램이 종료됩니다. 중앙 서버를 다른 직원도 사용 중이라면 서버 종료는 담당자와 함께 조정합니다.

## 4 참가자와 회차를 정확히 선택하기

참가자를 사용하는 화면에서는 행사·참가자 ID·반려견 이름으로 대상을 찾습니다. 이름만 보고 고르지 말고 행사와 참가자 ID를 함께 확인하세요. 같은 이름이 다른 행사나 참가자에 존재할 수 있습니다.

1. 목록에서 대상을 열고 화면의 **행사 / 참가자 ID / 반려견 / 촬영 회차**를 확인합니다.
2. 회차를 바꾸어야 한다면 **저장 대상 회차 선택**을 이용합니다. 이 선택은 저장 대상을 바꿉니다. 이전 설문·영상·촬영 기록은 보존되며 새 회차에 자동 복사되지 않습니다.
3. 저장 직전에 대상과 회차를 다시 확인합니다. 다른 직원이 저장 대상 회차를 바꾸었다는 안내가 나오면 선택값을 확인하고 필요한 회차를 다시 지정하세요.
4. **회차 안내·바로가기**를 펼치면 설문·촬영 자료·전처리 상태로 이동할 수 있습니다. **전체 목록으로 돌아가기**는 대상 선택을 해제합니다.

전처리의 지정 실행처럼 과거 회차를 고정해 조회하는 화면은 그 실행의 회차를 사용합니다. ‘조회 회차’와 ‘저장 대상 회차’ 안내를 읽고, 과거 결과를 현재 입력의 결과로 오인하지 마세요.

## 5 저장과 판본 이해하기

‘판본’ 또는 `r숫자`는 자료를 저장한 버전입니다. 새 저장은 이전 자료를 덮어 지우지 않고 새 판본을 남깁니다. 제출한 채점표도 수정할 수 있지만, 최초 제출본과 이후 수정본은 구분됩니다.

저장 성공 알림을 확인한 뒤 다른 메뉴로 이동하세요. 미저장 입력을 버릴지 묻는 창은 현재 화면에 아직 저장하지 않은 값이 있다는 뜻입니다. 계속 작성하려면 이동을 취소하고 먼저 저장합니다.

다른 사람이 먼저 저장하여 충돌이 발생하면 현재 입력을 바로 덮어쓰지 마세요. 해당 화면의 새로고침·최신 판본 확인 기능으로 변경 내용을 확인하고 자신의 수정값을 다시 적용합니다. 판본 충돌과 잘못된 회차 연결은 공유 권한과 별개로 계속 검사합니다.

## 6 누가 작업했는지 확인하기

참가자와 주요 자료 상세에서 **최근 열람·수정·실행 기록**을 펼칩니다. 계정·시각·작업 종류·해당 판본 등을 확인할 수 있습니다. **최근 기록 새로고침**으로 갱신하고 **이전 기록 더 보기**로 앞선 기록을 확인합니다.

이 기록은 서버가 자료를 제공하거나 저장·실행한 사실입니다. 실제 내용을 끝까지 읽었거나 종이를 인쇄했다는 확인은 아닙니다. 목록 검색과 자동 상태 조회가 모두 열람 사건으로 기록되는 것도 아닙니다.

## 7 문제가 생겼을 때

| 상황 | 확인하고 진행할 방법 |
| --- | --- |
| 로그인 실패 | 계정·비밀번호를 확인합니다. 반복 실패로 잠겼다면 잠시 기다린 뒤 다시 시도합니다. 비활성 계정은 로그인할 수 없습니다. |
| 사용 중 로그인 화면으로 돌아감 | 세션 만료·다른 곳에서 같은 계정 로그인·계정 활성 상태 저장 가능성을 확인하고 다시 로그인합니다. 로그인 세션은 8시간입니다. |
| 비밀번호를 잊음 | 설치·서버 담당자가 로컬 관리 명령으로 재설정합니다. 화면에서 비밀번호를 바꾸는 기능은 없습니다. |
| 개발 설정이 보이지 않음 | 일반 업무 계정에서 정상입니다. 키·AI 설정 문제는 개발자에게 해당 준비 오류를 전달합니다. |
| 참가자 일부가 목록에 없음 | 검색 조건을 확인합니다. 입력 자료 검증 실패 안내가 있으면 담당자가 원본 저장소를 확인해야 합니다. 정상 자료는 계속 사용할 수 있습니다. |
| 작업 상태가 오래 바뀌지 않음 | 해당 기능의 상태 새로고침과 실행 상세를 확인합니다. 같은 작업을 무작정 새로 만들지 말고 [전처리](K-DOG_전처리_사용설명서_v1.0_20261013.md) 또는 [AI 분석](K-DOG_AI분석_사용설명서_v1.0_20261013.md)의 복구 순서를 따릅니다. |
