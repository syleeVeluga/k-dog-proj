# K-DOG 비교 조건 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 제품 기준: `main / 53889b7` · 평가 기준: S1.1

메뉴 경로는 **분석·평가 → 리포트 → 비교 조건**입니다. 운영자·교수자·관리자·개발자 모두 사용합니다. 실제 설문으로 자체 비교집단을 만들고, 근거가 있는 외부 기준을 등록하는 방법을 설명합니다.

## 1 언제 사용하나요

같은 원문과 계산 정책으로 수집한 참가자들의 설문 평균을 참고하려면 자체 비교집단을 사용합니다. 외부 연구의 평균과 비교하려면 해당 연구의 실제 수치·원척도·문항·산식·대상 조건을 확인한 뒤 외부 기준을 사용합니다. 비교집단을 넣지 않아도 일반 리포트와 연구 파일을 만들 수 있습니다.

자체 집단의 평균은 전국 규준·백분위·정상 경계가 아닙니다. 외부 평균도 대상 조건이 다르면 계산에 쓰지 않습니다. 실제 수치가 없는 출처에 예시 숫자를 입력해 비교를 완성하지 마세요.

## 2 시작 전에 확인할 조건

| 사용하려는 기능 | 필요한 조건 |
| --- | --- |
| 자체 집단 저장 | 같은 설문 원문 판본의 S1 입력, 대상별 명시한 한 회차, 집단 이름·선택 사유, 현재 입력 판본 일치 |
| 영역 평균 계산 | 해당 영역에 계산 가능한 응답이 있어야 함. 영역마다 유효 표본 수가 달라질 수 있음 |
| 외부 기준 등록 | 출처 선택, 실제 평균·표준편차·유효 n·전체 n, 근거 파일, 비교 대상 범위·수치 위치·변경 기록 |
| 특정 출력에 외부 비교 포함 | 해당 외부 기준 문항의 모든 유효 원응답과 계산 가능한 평균, 출력 원자료의 대상·회차·문항·척도·산식·대상 조건에 맞는 고정 외부 비교 |

동의 확인이나 관리자 승인·공개 허가는 현재 접근·계산 조건이 아닙니다. 화면 일부에 남아 있는 ‘분석 동의가 확인된’·‘동의와 같은 원문 판본’ 문구를 승인 절차로 해석하지 마세요. 실제 검사는 계정 활성 상태, 자료 판본·내용·무결성 및 비교 조건을 대상으로 합니다.

## 3 자체 비교집단 만들기

1. **비교 조건** 메뉴를 열고 **같은 판본의 자체 비교집단**을 확인합니다.
2. **집단 이름**에 알아보기 쉬운 이름을 입력합니다. 예: `10월 행사 1차 설문 참고집단`.
3. **집단 선택 사유**에 대상과 회차를 고른 이유를 적습니다. 예: `같은 행사에서 동일 설문을 완료한 참가자의 1차 응답 비교`.
4. **집단 후보 검색**에 행사·참가자 ID·반려견 이름을 입력하여 대상을 찾습니다.
5. **포함**을 체크합니다. 회차가 하나라면 그 회차가 선택되고, 여러 회차라면 사용할 회차를 직접 선택합니다.
6. 대상별 **선택 입력 판본**과 회차를 확인합니다. 한 대상은 한 회차만 포함할 수 있습니다.
7. **선택 응답으로 새 집단 고정**을 누릅니다. 집단은 선택 당시의 원응답과 판본으로 저장됩니다.
8. 저장된 집단의 영역별 **평균 · 유효 n**과 **포함·제외**를 확인합니다.

카메라가 세 대라도 참가자 표본 수가 세 배가 되지 않습니다. 다른 행사에 같은 개체가 나타났는지를 이름만으로 자동 합치지도 않습니다. 행사 간 같은 개체 여부가 중요한 연구라면 별도의 식별 확인이 필요합니다.

## 4 결과를 읽고 과거 집단 확인하기

`n`은 해당 영역 평균에 실제로 포함된 대상 수입니다. 선택한 대상 수와 다를 수 있으므로 평균 옆의 `n`을 함께 읽습니다. **개별 포함·제외 근거**에서 미응답 등 제외 이유를 확인합니다. 유효 응답이 없으면 평균은 숫자 0이 아니라 계산되지 않은 상태로 표시됩니다.

**보존 비교집단**의 **집단 이름 열기** 버튼으로 다른 직원이 만든 집단도 확인할 수 있습니다. **고정 입력과 출처**에는 회차·입력 판본·설문 정책 등이 남습니다. 원응답이 이후 바뀌어도 이전 평균은 자동 변경되지 않습니다.

새 응답으로 비교하려면 후보를 다시 선택하여 **새 집단**으로 저장합니다. **선택 후 입력이 변경됐습니다** 안내가 있으면 **이 대상 선택을 최신 판본으로 교체**를 누르기 전에 실제 변경을 확인하세요.

## 5 외부 비교 기준 정의하기

실제 기준표가 준비되어 있을 때만 진행합니다. 현재 실제 외부 기준 수령·적용 상태는 [리포트 실행 기록](../archive/리포트개편_20261007/K-DOG_리포트구현실행기록_v1.0_20261007.md)과 [실측 및 확인 후속 대장](../archive/개발반영_20261003/K-DOG_실측및확인후속대장_v1.0_20261003.md)을 확인합니다. 입력 기능이 있다는 사실만으로 실제 연구 기준이 준비된 것은 아닙니다.

1. **외부 비교 기준 정의**를 펼칩니다.
2. **연구 출처**에서 사용할 연구를 선택합니다. 표시된 문헌·DOI·영역·문항·원척도·방향·집계·결측 정책을 확인합니다.
3. 실제 기준표의 **외부 평균**, **외부 표준편차**, **외부 유효 표본 n**, **외부 전체 표본 n**을 입력합니다. 표본 수는 1 이상의 정수이고 유효 n은 전체 n보다 클 수 없습니다. 평균은 원척도 범위 안이어야 하고 표준편차는 음수가 될 수 없습니다.
4. **비교 대상 범위**에 연구의 모집단과 적용 범위를 적고 **수치 출처·표 위치**에 어느 표·영역에서 읽은 수치인지 적습니다.
5. **기준 근거 파일**로 0바이트 초과, 16 MiB 이하의 근거를 첨부합니다. 근거 선택을 제거해도 원본 연구 수치가 바뀌는 것은 아닙니다.
6. 필요하면 **대상 조건 추가**로 접수 정보와 정확히 맞아야 할 조건을 입력합니다. 예를 들어 `dog.sex`처럼 실제 필드와 값이 확인된 조건을 사용합니다. 문항·척도 등 고정된 출처 조건을 임의로 바꾸지 않습니다.
7. **새 계산에 사용**을 체크하고 **기준 변경 기록**에 등록·수정 이유를 적습니다.
8. **기준 정의 저장·적용**을 누릅니다. 유효한 기준은 바로 적용하며 별도 관리자 결재는 없습니다.

사용을 중단하려면 해당 출처를 다시 선택하고 **새 계산에 사용**을 해제하여 변경 기록과 함께 저장합니다. 기존 발급 파일은 보존되고 새 계산에서 해당 기준을 사용하지 않습니다.

### 5.1 전달 기준표로 SF·NF 기준 등록하기 (2026-10-21 추가)

**SF·NF 기준은 앱이 처음 시작할 때 자동으로 설치됩니다.** 별도 입력 없이 리포트에 미국 연구 비교가 연결됩니다. 화면의 기준 이력에는 기록자 `builtin-reference`(내장 전달 기준)로 표시됩니다. 아래 순서는 실제 전달표 파일을 근거로 다시 저장하거나 수치를 정정할 때만 사용합니다.

2026-10-08 전달 기준표에 따라 미국 연구 참고 평균은 **낯선 사람 두려움(SF)**과 **비사회적 두려움(NF)** 두 지표에만 연결합니다. 나머지 7개 설문 지표는 외부 기준 없이 우리 누적 평균과 비교합니다.

1. **외부 비교 기준 정의**를 펼치고 **연구 출처**에서 SF 출처를 선택합니다. 화면에 전달 문항 매핑 판본과 기준표 파일 이름이 보입니다.
2. **전달 기준 수치 불러오기**를 누릅니다. 평균 0.66, 표준편차 0.91, 유효 n 42,926, 전체 n 43,517과 수치 출처가 양식에 채워집니다. 이 버튼은 **저장하지 않습니다**.
3. **비교 대상 범위**를 확인하고 **기준 근거 파일**로 전달 기준표를 첨부합니다. **새 계산에 사용**을 체크하고 변경 기록을 적은 뒤 **기준 정의 저장·적용**을 누릅니다.
4. NF 출처로 같은 과정을 반복합니다. NF 값은 평균 1.03, 표준편차 0.78, 유효 n 42,764, 전체 n 43,517입니다.
5. 저장 후 정의 목록에 **현재 기준 정의가 전달 기준과 다릅니다** 안내가 없는지 확인합니다. 이 안내가 보이는 기준은 리포트에서 해당 지표의 미국 연구 비교만 미준비로 처리됩니다.

SF와 NF는 따로 판단합니다. 한쪽만 등록하면 그쪽만 비교에 표시됩니다. 미국 연구 참고 평균은 국내 표준이나 진단 기준이 아니며, 기준표를 받았다는 사실이 한국어 설문과의 측정 동등성이나 사용 허가를 뜻하지는 않습니다. 운영 PC에서 실제 등록을 마쳤는지는 [실측 및 확인 후속 대장](../archive/개발반영_20261003/K-DOG_실측및확인후속대장_v1.0_20261003.md)에서 확인합니다.

## 6 리포트나 연구 파일에 비교 포함하기

자체 집단은 [리포트 발급](K-DOG_리포트발급_사용설명서_v1.0_20261013.md) 또는 [연구 내보내기](K-DOG_연구내보내기_사용설명서_v1.0_20261013.md)에서 사용할 집단을 선택합니다. 비교 조건 저장만으로 모든 기존 리포트가 바뀌지는 않습니다.

2026-10-21부터 [리포트 발급](K-DOG_리포트발급_사용설명서_v1.0_20261013.md)의 새 발급은 등록된 SF·NF 기준을 자동으로 연결하므로 아래 선택이 필요하지 않습니다. 아래 절차는 연구 내보내기와 리포트의 **이전 방식** 선택에 해당합니다.

외부 비교는 출력 화면의 **이 출력의 외부 비교**에서 사용합니다.

1. 먼저 출력할 원자료 또는 최종본을 선택합니다. 해당 외부 기준 문항의 모든 설문 원응답이 있는지 확인합니다. 자체 집단에서 일부 영역만 산출할 수 있는 상태여도 외부 기준 문항이 누락되면 그 외부 비교는 고정할 수 없습니다.
2. 이미 고정한 유효 비교를 선택하거나 **확인된 출처로 새 비교 고정**을 펼칩니다.
3. 사용 가능한 출처를 체크하고 **외부 비교 고정 사유**를 입력합니다.
4. **선택 조건으로 외부 비교 고정**을 누릅니다. 해당 대상·회차의 원문·응답·척도·조건을 검사해 비교 판본이 고정됩니다.
5. 고정된 비교가 선택되었는지 확인하고 출력 생성을 진행합니다. 비교가 준비되지 않았으면 **외부 비교 없음**으로 나머지 결과를 출력할 수 있습니다.

## 7 문제 해결

| 상황 | 해결 방법 |
| --- | --- |
| 집단 저장 버튼이 비활성 | 이름·사유·대상 체크·대상별 회차를 확인합니다. |
| 선택 판본이 현재 입력과 다름 | 후보 새로고침 후 실제 변경을 확인하고 해당 대상 선택을 최신 판본으로 교체합니다. |
| 외부 출처가 미준비 | 실제 수치·근거가 준비되어 있는지 확인합니다. 없는 값은 보완 추정하지 말고 외부 비교 없이 출력합니다. |
| 외부 비교 기준 문항에 미응답이 있음 | 설문 현황에서 해당 기준의 누락 문항을 확인하고 실제 원응답을 일괄 등록으로 보완합니다. 새 응답이 반영된 원자료·최종본으로 다시 선택하거나 **외부 비교 없음**으로 출력합니다. 누락을 0으로 채우지 않습니다. |
| 기준 저장 충돌 | **기준 정의 새로고침**으로 최신 상태를 확인합니다. 초안을 보존한 뒤 **최신 기준으로 새 작성**을 통해 명시적으로 다시 입력합니다. |
| 새 출력 선택 불가 | 기준 사용 중단·조건 불일치 등의 사유를 읽고 **외부 비교 없음** 또는 현재 기준으로 새 비교를 선택합니다. |
| 집단·출력별 외부 비교 고정 응답이 유실됨 | 선택을 바꾸지 않고 이력을 먼저 확인합니다. 같은 내용으로 재요청하면 동일 요청 ID를 사용합니다. |
| 외부 기준 정의 저장 응답이 유실됨 | **기준 정의 새로고침**으로 보존 판본과 내용을 확인합니다. 이미 저장되었으면 반복 저장하지 않습니다. 미저장이 확인된 경우 최신 기준으로 다시 작성합니다. 이 저장은 입력 판본 검사 방식이므로 그대로 재저장하면 충돌할 수 있습니다. |

## 8 기준 근거
