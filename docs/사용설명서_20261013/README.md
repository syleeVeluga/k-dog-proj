# K-DOG 운영자와 교수자 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 제품 기준: `main / 53889b7` · 평가 기준: 2026-10-02 통합명세 v1.3 / S1.1

현재 K-DOG의 운영자와 교수자가 로그인 후 사용하는 기능을 주요 업무별로 나누었습니다. 각 설명서에서 **언제 사용하는지**, **필요한 조건**, **화면에서 따라 할 순서**, **결과 확인**, **오류 해결**을 확인할 수 있습니다. 설치본이 다른 버전이면 해당 설치본의 `release.json`과 배포 안내를 함께 확인하세요.

## 1 처음 사용할 때

먼저 [로그인과 공통 화면](K-DOG_로그인과공통화면_사용설명서_v1.0_20261013.md)을 읽으세요. 접속 주소, 개인 계정, 대상과 촬영 회차 선택, 저장 판본과 작업 기록을 설명합니다. 설치가 필요하면 [설치 매뉴얼](../K-DOG_설치매뉴얼_v1.0_20261005.md)과 [운영 안내](../PILOT_OPERATIONS.md)를 확인합니다.

로그인 구분과 실제 사용 범위는 다음과 같습니다.

| 로그인 구분 | 화면 표시 | 업무 기능 | 개발 설정 |
| --- | --- | --- | --- |
| 운영자 `operator` | 업무 계정 | 모두 사용 | 접근 불가 |
| 교수자·검토자 `reviewer` | 업무 계정 | 모두 사용 | 접근 불가 |
| 관리자 `admin` | 업무 계정 | 모두 사용 | 접근 불가 |
| 개발자 `developer` | 개발자 | 모두 사용 | 키·AI 설정 관리 |

운영자와 교수자 전용으로 서로 다른 업무 메뉴가 제공되는 구조는 아닙니다. 모든 활성 계정이 함께 자료를 조회·편집·실행·발급·다운로드하며 실제 행위자가 기록됩니다. 소유·배정·공개·재개방 승인 및 동의·삭제 이력은 현재 업무 접근 조건이 아닙니다. 이전 원본·최초 제출·독립성·후속 수정 출처는 보존합니다.

## 3 운영자가 촬영 당일 따라갈 순서

1. 본인 계정으로 로그인합니다. 서버 실행·저장공간·업무 계정을 확인하고 필요하면 백업을 만듭니다.
2. **참가자 접수**에서 대상과 첫 촬영 회차를 만들거나 **일괄 등록**으로 파일을 미리보기한 뒤 등록합니다.
3. **설문 현황**에서 응답과 빈칸 사유를 확인합니다. 미응답을 0으로 채우지 않습니다.
4. **영상 파일 업로드**에서 파일을 수신하고 참가자·회차를 지정하여 영상 정보를 저장합니다. 접수보다 영상이 먼저 도착하면 수신 후 나중에 연결할 수 있습니다.
5. **촬영 기록 (8구간)**에서 실제 시간과 사건·관찰 근거를 입력하여 확정합니다.
6. **전처리**를 명시 실행하고 완료·일부 완료·확인 필요 상태와 현재 입력에 맞는 결과인지를 확인합니다.
7. 채점·AI 분석·해석 담당자와 대상 및 회차를 함께 확인합니다. 같은 자료를 공유하므로 배정 승인 절차는 없습니다.
8. 최종 결과가 준비되면 **리포트 발급**에서 HTML/PDF를 생성하고 내용을 확인합니다. 행사 종료 시 백업을 만듭니다.

## 4 교수자가 평가와 결과 검토를 따라갈 순서

1. 본인 계정으로 로그인하고 **독립 채점**에서 행사·참가자·반려견·회차를 확인합니다.
2. 독립 평가 자료를 남길 목적이라면 AI나 다른 사람의 결과를 보기 전에 직접 영상을 관찰하고 본인 채점값·근거를 제출합니다. 기존 행사 의견은 참가자 채점 화면 진입 때 자동 조회·열람 기록되므로, 행사 의견 등록 전에 독립 평가자의 최초 제출을 먼저 마치는 순서로 운영합니다. 같은 촬영의 타인·AI 기반 또는 타인 작성 의견에 이미 노출되었다면 시트 목적·노출 이력을 확인하고 검수로 작업합니다. 타 결과 열람은 허용되며 사전 노출 사실이 평가 분류에 반영됩니다.
3. 기본 계산의 값·결측·보류 이유와 판정을 확인합니다. AI 분석이 필요하면 준비 조건을 확인하고 실행하거나 보존 결과를 엽니다.
4. 원관찰과 근거를 대조하여 사람 해석 또는 행사 의견을 작성합니다. 완료 조건을 충족한 의견만 최종 결과에 반영됩니다.
5. **해석과 최종 결과**에서 사용할 계산본과 완료 의견을 확인하여 최종본을 저장합니다.
6. **리포트 발급**에서 그 최종본으로 결과를 만들고 사람 의견·AI 설명·보류 이유·비교 출처를 확인합니다.
7. 연구용 표가 필요하면 **연구 내보내기**에서 최초 제출·후속 수정·AI 판본을 정확히 선택합니다. 전달 검수표는 **검수 자료**로 별도 보존합니다.

## 5 단계와 상태를 구분하는 방법

| 표시 또는 개념 | 업무상 의미 |
| --- | --- |
| 업로드 완료 | 서버가 파일을 받았음. 참가자 연결·촬영 확정·분석 완료와 별도 |
| 영상 정보 저장 | 파일을 특정 참가자·회차와 연결하고 처리 정보를 저장함 |
| 촬영 기록 확정 | 실제 구간·사건 기록을 검증한 상태. 전처리는 별도 실행 |
| 전처리 완료 | 해당 실행의 클립·관찰창 결과가 보존됨. 입력이 바뀌면 현재 입력과 다를 수 있음 |
| AI 완료·일부 완료 | 해당 실행 단계의 결과 상태. 사람 채점·최종 결과·리포트 발급과 별도 |
| 제출·완료 의견 | 시트·의견의 상태와 판본. 수정할 수 없는 영구 잠금이 아니며 최초 제출·이전 판본은 보존 |
| 최종 결과 저장 | 출력에 사용할 계산·해석·의견을 특정 판본으로 고정함 |
| 정상 발급 | 리포트 HTML/PDF가 검증되어 제공 가능함. 화면 열기·PDF 저장·실제 인쇄는 별도 동작 |
| 미응답·미관찰 | 관찰 또는 응답이 없는 상태. 숫자 0과 다름 |
| 규칙 확인 대기 | 계산·판정 규칙이 미확정인 상태. 값을 임의 입력해 해소하지 않음 |

## 6 현재 기능의 적용 경계

360 통합 MP4의 보관과 처리 정보 등록을 지원하지만, 360 펼침 영상의 직접 분석·실제 Studio 영상 품질·장시간 시간 대응·GB급 성능은 별도 실측 대상입니다. 파일 수신 성공이 미세 행동 판독 품질을 보장하지 않습니다.

S1 점수 Excel import는 빈 원본·교정 파일 검증 조건을 충족하기 전까지 활성화되지 않습니다. 설문 CSV·Excel 일괄 등록과 검수 참고 XLSX 등록은 각각 지원되는 별도 기능입니다. 개21 등 미정 규칙, 실제 외부 기준표 적용, 실제 AI 품질·교수 검토·물리 3PC 인수는 해당 설명서와 후속 대장의 조건을 따릅니다.
