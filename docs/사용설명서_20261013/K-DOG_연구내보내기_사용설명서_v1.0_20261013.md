# K-DOG 연구 내보내기 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 제품 기준: `main / 53889b7` · 평가 기준: S1.1

메뉴 경로는 **분석·평가 → 리포트 → 연구 내보내기**입니다. 운영자·교수자·관리자·개발자 모두 평가자·AI 자료의 현재 또는 보존 판본으로 연구 파일을 만들고 공유 파일을 내려받을 수 있습니다.

## 1 언제 사용하나요

항목별 원관찰과 자동 계산을 연구용 표로 확인할 때, 사람과 AI의 비교 자료를 정리할 때, 검수 참고 자료와 실제 점수를 분리해 전달할 때 사용합니다. 보호자에게 읽기 쉬운 결과를 전달하려면 [리포트 발급](K-DOG_리포트발급_사용설명서_v1.0_20261013.md)을 이용하세요.

이 기능은 어떤 자료를 몇 판본으로 내보냈는지를 고정합니다. 이후 채점표를 수정해도 이미 만든 파일은 자동 갱신되지 않습니다. 최신 내용을 전달하려면 새 파일을 생성합니다.

## 2 시작 전에 준비할 조건

선택 대상·촬영 회차에 S1 채점 원자료 판본이 있어야 합니다. 기본 결과·최종 결과·리포트·검수 참고·비교 출처는 필요한 것만 포함할 수 있습니다. 추가 결과를 포함할 때는 원자료와 같은 판본에서 파생된 자료여야 합니다.

생성 사유가 필요하고, 자유서술 속 식별정보를 확인해야 합니다. 이름·참가자 및 행사 식별자·평가자 계정 등 직접 식별정보와 공급자 키는 제외하지만, 자유문장에 적은 별도 연락처·호칭 등도 검토하여 제거 문구를 추가하세요.

**기준 시트나 최종본을 선택하는 동작도 실제 자료 열람으로 기록됩니다.** 독립 평가를 남길 원평가자가 자신의 제출 전에 다른 사람·AI 자료를 선택하면 사전 노출로 분류될 수 있습니다. 독립 작성이 목적이면 자신의 관찰과 제출을 먼저 마치고 연구용 자료를 선택하세요. 열람은 허용되며, 제3자의 나중 열람이 이미 보존된 최초 독립 제출본을 소급 변경하지는 않습니다.

## 3 원자료와 결과를 고정 선택하기

1. **연구 내보내기** 메뉴에서 참가자와 촬영 회차를 엽니다.
2. **내보내기 후보 새로고침**을 눌러 현재 후보를 확인합니다.
3. **기준 시트**에서 평가자 또는 AI 시트를 선택합니다. 다른 직원의 시트도 선택할 수 있습니다.
4. **내보낼 원자료 판본**에서 정확한 현재 또는 보존 판본을 선택합니다. 선택창의 현재 시트·보존 시트 `r숫자`와 독립·후속 검수 표시를 읽습니다. 최초 제출과 후속 수정의 구체적인 이력은 [독립 채점](K-DOG_독립채점_사용설명서_v1.0_20261013.md)의 보존본·원평가자 출처에서 먼저 확인합니다.
5. 자동 계산이 필요하면 **같은 원자료의 기본 결과**에서 원하는 계산본을 선택합니다. 필요 없으면 **기본 결과 포함 안 함**을 유지합니다.
6. 확정 출력이 필요하면 **최종 결과**를 선택합니다. 원자료 판본이 다르면 선택이 거절되므로 일치하는 최종본을 사용합니다. 최종본 선택 시 그 최종본의 기본 계산도 함께 고정됩니다.
7. 최종본을 선택했다면 **같은 최종본의 발급 리포트**에서 포함할 정상 발급본을 고를 수 있습니다. 최근·이전 발급과 이전 입력 여부를 확인합니다.
8. 외부 비교가 필요하면 **이 출력의 외부 비교**에서 해당 입력 조건에 맞는 비교를 선택합니다. 선택 방법은 [비교 조건 안내](K-DOG_비교조건_사용설명서_v1.0_20261013.md)를 따릅니다.
9. **고정 선택 목록에 추가**를 누릅니다. 목록의 원자료·기본 결과·최종본·리포트·외부 비교가 의도한 자료인지 확인합니다.
10. 같은 참가자·회차에서 추가할 다른 평가자 판본이 있으면 3~9번을 반복합니다. 같은 원자료 판본을 중복 추가할 수는 없습니다.

현재 화면에서 고정 선택은 참가자·회차 문맥에 속합니다. 다른 대상이나 회차로 이동하기 전에 생성 또는 선택 정리를 마치세요. 기준 시트를 바꾸면 아직 고정 목록에 넣지 않은 결과 선택이 초기화됩니다.

## 4 파일 생성하고 다운로드하기

1. **연구 파일 형식**에서 **CSV 묶음 ZIP** 또는 **XLSX**를 선택합니다. CSV ZIP은 항목별 CSV를 묶고, XLSX는 항목별 시트가 있는 통합 문서입니다.
2. **추가 식별정보 제거 문구 (한 줄에 하나)**에 자유서술에서 제외할 실제 문구를 입력합니다.
3. 필요하면 **검수 참고 출처**를 체크합니다. 이는 현재 점수와 별도 참고 출처로 포함되며 확정 독립 정답으로 바뀌지 않습니다.
4. 필요하면 **자체 집단 비교 출처**를 선택합니다. 이전 응답 기준 집단이라면 그 기준이 필요한지 확인합니다.
5. **연구 내보내기 사유**에 범위와 목적을 적습니다. 예: `1차 촬영의 교수 최초 제출과 AI 최초 관찰을 항목별 검토하기 위함`.
6. **선택 판본으로 연구 파일 생성**을 누릅니다.
7. **연구 파일 준비 완료 · 포함 …개 · 제외 …개**를 확인합니다.
8. **공유 연구 파일**에서 해당 시각·형식의 항목을 펼치고 **연구 파일 다운로드**를 누릅니다. 브라우저 다운로드 위치에 저장된 파일을 확인합니다.

다른 직원이 만든 연구 파일도 공유 목록에서 다운로드할 수 있습니다. 생성자 비활성화가 공유 파일 접근 조건은 아닙니다. 다운로드 시 파일과 고정 출처의 무결성을 다시 검사합니다.

## 5 내려받은 파일 읽기

| 표 또는 시트 | 확인할 내용 |
| --- | --- |
| `raw_observations`, `linked_memos`, `walk_exceptions` | 항목·관찰창별 원값, 개59 연결 메모, 동선 근접 예외 등 |
| `automatic_calculations`, `decisions` | 자동 산출과 판정 근거 |
| `opinions`, `final_results`, `reports` | 최종본에 고정된 의견 원문과 상태(작성 중·완료·철회 포함), 고정 최종 출력·리포트 출처 |
| `survey_responses`, `survey_domains` | 설문 원응답과 영역별 산출 상태 |
| `comparisons` | 선택한 비교집단·외부 비교 출처 |
| `independent_pairs`, `item_denominators` | 비교 가능한 쌍과 항목별 유효 분모 |
| `quality`, `reference_sources`, `excluded` | 품질 상태·검수 참고 출처·제외 사유 |

숫자 0·음수·횟수와 결측을 구분합니다. 빈 값은 0으로 채우지 말고 상태·사유 열을 함께 읽으세요. 카메라 수는 참가자 표본 수가 아니고, 범주 일치·횟수 차이·유형 일치를 하나의 정확도로 합치지 않습니다.

의견 표에 원문이 있다는 사실만으로 완료·적용 의견이라고 해석하지 않습니다. `opinions`의 `state`로 작성 중·완료·철회 상태를 확인하고, 영역에 실제 적용된 출처는 `final_results`의 `source`를 함께 읽습니다. 작성 중·철회 의견도 최종본에 고정되었다면 출처 기록으로 내보내질 수 있습니다.

사람과 AI의 비교에는 원평가자의 사전 노출과 최초 제출·후속 편집 이력이 영향을 줍니다. 다른 사람이 나중에 자료를 열었다는 이유만으로 최초 독립 제출 분모가 소급 변경되지는 않습니다. 참고 자료를 ‘사람 확정으로 전달됨’으로 등록했더라도 독립 정답으로 자동 채택되지 않습니다.

## 6 문제 해결

| 상황 | 해결 방법 |
| --- | --- |
| 생성 버튼이 비활성 | 고정 선택이 있는지, 생성 사유가 있는지, 참고·비교 출처에 유실된 선택이 없는지 확인합니다. |
| 최종본 원자료 판본 불일치 | 내보낼 원자료 판본과 같은 최종본을 선택합니다. 원자료만 내보내려면 최종 결과를 포함하지 않습니다. |
| 같은 원자료가 이미 선택됨 | 고정 목록에서 기존 선택을 제거한 뒤 포함할 결과를 다시 지정합니다. |
| XLSX 긴 셀·제어문자·행 수 오류 | 원값을 보존하는 **CSV 묶음 ZIP**으로 생성합니다. |
| 응답 유실 후 결과를 모름 | 공유 파일 이력을 먼저 확인하고 같은 선택으로 재요청합니다. 입력이 같으면 동일 요청 ID를 사용합니다. |
| 제공 차단 표시 | 파일 유실·해시 오류 등 표시된 이유를 확인합니다. 정상 다른 파일은 계속 사용할 수 있습니다. |
| 새로고침했는데 선택이 옛 판본 | 새로고침은 고정 선택을 자동 교체하지 않습니다. 최신판을 원하면 선택을 제거하고 새 판본으로 추가합니다. |

## 7 다음 업무와 기준 근거

다운로드한 자료의 포함·제외와 자유서술 식별정보를 확인한 뒤 목적에 맞게 보관·활용합니다. 검수 참고 파일 등록은 [검수 자료](K-DOG_검수자료_사용설명서_v1.0_20261013.md), 비교 출처는 [비교 조건](K-DOG_비교조건_사용설명서_v1.0_20261013.md)을 확인합니다.

기준 구현은 [연구 파일 화면](../../frontend/src/ResearchExportsV4.tsx), [생성·비식별 처리·표 구성](../../backend/app/exports_v4.py), [업무 권한 계획](../plans/K-DOG_업무권한단순화계획_v1.1_20261011.md)입니다. 실제 사람 정답·영상 품질 검증의 남은 조건은 [실측 후속 대장](../archive/개발반영_20261003/K-DOG_실측및확인후속대장_v1.0_20261003.md)을 따릅니다. [목차로 돌아가기](README.md).
