# K-DOG 독립 채점 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 확인 기준: `main`의 `53889b7`, S1(`20261002`, `intake-4.0`)

대상: 운영자·교수자 및 함께 평가 업무를 수행하는 직원. 이 문서의 「교수자」는 관찰과 해석을 맡은 사람을 뜻합니다. 현재 화면에서 `operator`·`reviewer`·`admin` 계정은 모두 **업무 계정**, `developer`는 **개발자**로 표시합니다. 네 계정 모두 이 기능을 사용할 수 있습니다.

## 1. 언제 사용하는 기능인가요?

실제 촬영 영상에서 확인한 행동을 항목별로 기록하고, 그 기록을 고정해 계산할 때 사용합니다. 운영자는 촬영 입력을 확인하고 시트 생성·진행 관리를 맡을 수 있고, 교수자는 영상을 관찰해 원값·근거·판정을 기록할 수 있습니다. 이 역할 분담은 팀의 업무 방식이며 앱의 접근 권한 차이가 아닙니다.

화면의 이름은 **독립 채점**, 대상 안의 작업 제목은 **공유 채점**입니다. 모든 직원은 다른 사람이 만든 시트도 열고 수정할 수 있습니다. 독립성은 결과를 못 보게 하는 잠금이 아니라 **원평가자, 최초 제출본, 다른 결과를 본 시점, 후속 수정의 출처**로 구분합니다.

다른 사람·AI의 결과와 비교하지 않은 최초 관찰을 남기려면 자신의 관찰과 제출을 먼저 마친 뒤 참고 결과를 여는 순서로 작업하세요. 화면은 열람을 허용하지만, 원평가자의 사전 열람과 후속 수정은 검수 기록으로 분류될 수 있습니다. 제3자가 나중에 읽었다는 이유만으로 원평가자의 최초 독립 제출본이 바뀌지는 않습니다.

**기존 행사 의견이 있는 회차는 참가자의 독립 채점 화면을 여는 것만으로 의견 본문이 자동 조회되고 열람이 기록됩니다.** 같은 촬영의 타인·AI 자료를 기반으로 하거나 다른 직원이 작성한 의견이면 원평가자의 제출 전 조회가 사전 노출로 분류될 수 있습니다. 별도의 **시트 열기** 버튼을 피하는 것만으로 독립성이 유지되지는 않습니다. 독립 평가가 목적이면 행사 의견을 등록하기 전에 평가자의 최초 관찰·제출을 먼저 마치세요. 이미 노출된 경우 시트의 목적·노출 이력을 확인하고 검수 기록으로 작업합니다. 새 평가자 ID나 시트를 만들어 노출 이력을 초기화할 수는 없습니다.

## 2. 화면으로 들어가기와 시작 조건

**분석·평가 → 독립 채점**으로 이동합니다. 주소의 메뉴 경로는 `#/scoring`입니다. 참가자 목록에서 **「참가자번호 독립 채점 열기」**를 누릅니다. 반려견 이름과 선택한 촬영 회차를 확인한 뒤 진행하세요.

| 확인할 것 | 사용 조건과 확인 방법 |
| --- | --- |
| 로그인 | 활성 계정으로 로그인해야 합니다. 다른 사람의 계정을 빌려 쓰지 않아야 실제 작업자가 정확히 기록됩니다. |
| 참가자·회차 | 평가하려는 대상과 촬영 회차가 맞아야 합니다. 다른 회차의 근거를 섞으면 저장할 수 없습니다. |
| 실제 촬영 기록 | 새 현재 입력으로 시트를 만들려면 실제 촬영 기록이 확정되어 있어야 합니다. [촬영 기록](K-DOG_촬영기록_사용설명서_v1.0_20261013.md)을 먼저 마칩니다. |
| 원본 영상·카메라 | 실제 파일을 읽을 수 있고 영상의 카메라·해시·동기화가 촬영 기록과 일치해야 합니다. 보관 전용 파일은 판독 근거로 선택할 수 없습니다. |
| 비교할 입력 | 여러 평가자를 비교할 때는 같은 고정 촬영 입력을 선택해야 합니다. 같은 참가자 이름만 같아서는 충분하지 않습니다. |
| 배정·소유·동의 | 채점 배정이나 공개·재개방 승인은 필요하지 않습니다. 옛 동의·삭제 상태는 접근 차단 조건이 아닙니다. |

사람 채점을 시작하려고 AI 분석을 먼저 실행할 필요는 없습니다. AI 분석에는 별도로 현재 입력의 전처리와 활성 AI 설정이 필요합니다.

## 3. 새 채점 시트 만들기

1. 대상 화면에서 **채점 시트 만들기**를 펼칩니다.
2. **평가자 ID**와 **평가자 표시 이름**을 확인합니다. 기본값은 현재 로그인 계정 이름입니다. ID는 영문·숫자로 시작하고 영문·숫자·밑줄·하이픈을 사용합니다. 표시 이름은 목록에서 평가자를 알아보기 쉽게 적습니다.
3. **기록 목적**을 고릅니다.
4. **촬영 입력 선택**에서 **현재 확정 촬영 입력** 또는 기존 평가자와 **동일한 고정 입력**을 선택합니다.
5. **채점 시작**을 누릅니다. 만들어진 목록에서 해당 평가자의 **시트 열기**를 누릅니다.
6. 목록의 **원평가자 출처**를 펼쳐 평가자·계정·사람/AI 구분과 입력 연결을 확인합니다.

| 기록 목적 | 언제 선택하나요? |
| --- | --- |
| 독립 원자료 | 다른 평가 결과에 기대지 않고 최초 관찰을 남길 때 |
| 검수 기록 | 사람·AI 결과를 확인한 뒤 재검토하거나 타인의 시트를 보완할 때 |
| 합의 기록 | 평가자들이 함께 검토한 결론을 별도 기록으로 남길 때 |

**촬영 입력 선택**은 원점수 복사 기능이 아닙니다. 다른 시트와 같은 영상·창·촬영 입력을 고정하여 새 기록을 시작하는 기능입니다. 새 시트나 새 입력 묶음을 만든다고 같은 촬영의 독립성이 다시 시작되지는 않습니다. 중복 평가자·동일 입력·동일 목적이면 생성이 거절될 수 있으므로 기존 시트를 먼저 확인하세요.

만드는 중 다른 직원이 접수를 수정했다면 **현재 접수 버전 새로고침**으로 상태를 확인합니다. 입력을 버리고 다시 시작할 때는 **채점 입력 버리고 다시 시작**을 누르고 화면의 확인 안내에 따릅니다.

## 4. 항목을 하나씩 기록하기

시트 상단에서 **8구간 필터**로 입장·기준·혼자·재회·무시·걷기·낯선 사람·퇴장을 나눠 볼 수 있습니다. **원코드/항목 검색**에 `개19` 같은 코드나 항목 문구를 넣으면 해당 행을 찾습니다.

현재 구조는 **숫자 83개 + 관찰 메모 3개 + 자동 계산 4개**입니다. 직접 입력하는 86행 가운데 **84행은 필수**, **바54·바55는 선택**입니다. 자동 계산 행에는 직접 값을 입력하지 않으며, 별도의 **개59 연결 메모**는 90행과 별도로 보존합니다.

각 항목에는 구간·축·척도·선택 순서가 표시됩니다. 항목의 문구와 척도를 먼저 읽은 다음 아래 순서대로 작성합니다.

1. **기록 상태**를 선택합니다.
2. 관찰했다면 **원값**을 입력합니다. 범주형은 화면에 나온 설명에 맞는 값을 선택하고, 횟수형은 실제 횟수를 기록하며, 메모형은 실제 관찰 내용을 적습니다.
3. 원값을 쓰지 못한다면 **빈값 사유**를 구체적으로 적습니다.
4. **관찰 기회**를 있음/없음/미확인으로, **시행 유효 상태**를 유효/주의/유효하지 않음/미확인으로 기록합니다.
5. 전체 구간을 실제 확인한 경우에만 **실제 전체 구간 관찰 완료**에 체크합니다.
6. **F 관찰 근거·영상**에서 실제 확인한 영상과 시각을 연결합니다.

| 기록 상태 | 사용 조건과 예시 |
| --- | --- |
| 미기록 (빈칸) | 아직 작업하지 않은 행입니다. 필수 행이면 제출 전 해결해야 합니다. |
| 관찰한 원값 | 해당 항목을 실제 확인했고 척도에 맞는 값을 기록할 수 있을 때 |
| 미관찰 | 실시 여부와 별개로 필요한 행동을 확인하지 못했을 때. 사유를 함께 적습니다. |
| 기회 없음 (NA) | 행동이 나타날 실제 기회가 없었을 때. 단순히 행동이 없었다는 이유로 선택하지 않습니다. |
| 미실시 | 해당 절차를 실제로 하지 않았을 때 |
| 유효하지 않음 | 관찰은 있었지만 절차·조건이 해당 평가에 유효하지 않을 때 |
| 관찰량 부족 | 필요한 구간 일부만 보거나 들은 경우 |
| 규칙 확인 대기 | 관찰 원근거는 있으나 종합·대표값 규칙이 아직 확정되지 않은 경우 |

**0은 관찰한 값**입니다. 빈칸, NA, 미관찰을 0으로 대신 입력하지 마세요. 예를 들어 가려진 영상에서 행동을 못 봤다면 「0회」가 아니라 실제 부족 상태와 사유를 남깁니다. 「필수 84행」은 모든 행을 숫자로 채우라는 뜻이 아니라, 각 행에 **값 또는 명시한 빈값 상태·사유**가 있어야 한다는 뜻입니다.

## 5. 영상 근거를 친절하게 남기는 방법

1. 해당 항목의 **F 관찰 근거·영상**을 펼칩니다. 위에 표시된 실제 관찰창과 확인 범위를 읽습니다.
2. **영상 근거 추가**를 누릅니다.
3. **근거 관찰창**에서 해당 항목의 실제 창을 선택합니다. 확정·부분 확인된 창만 선택할 수 있습니다.
4. **근거 원본 영상**에서 확인한 카메라 영상을 선택합니다. 카메라와 확정 오프셋이 함께 표시됩니다.
5. 영상 재생기의 재생·일시정지를 사용해 행동을 확인합니다. **「○~○초 원본 범위 시작으로 이동」**을 누르면 해당 카메라의 원본 시각으로 이동합니다.
6. **원본 근거 시작 초**, **원본 근거 끝 초**, **실제 확인 초**를 작성합니다. 입력하는 시각은 선택한 **그 원본 영상의 시각**입니다.
7. **F 관찰 근거**에 무엇을 확인했는지 적습니다. 예: 「보호자가 돌아온 뒤 반려견이 접근하여 접촉함」처럼 관찰 사실을 먼저 씁니다.
8. 다른 구간의 근거도 필요하면 같은 절차로 추가합니다. 잘못 추가한 줄은 **이 영상 근거 제거**로 제거합니다.

영상·창을 고르는 것만으로 관찰량이 자동 입력되지는 않습니다. 여러 카메라로 같은 시간을 봤더라도 실제 확인량을 중복 합산하지 마세요. 원본 시각이 창 밖이거나 영상 실제 길이 밖이면 저장이 거절됩니다. 카메라가 다르면 확정 오프셋을 적용한 실제 범위도 맞아야 합니다.

전체 관찰이 필요한 항목은 실제 전체창을 덮는 유효 근거가 있어야 합니다. 체크 표시만으로 충족되지 않습니다. 화면에 「전체 관찰 필수」가 나오는데 일부만 확인했다면 관찰량 부족으로 남기고, 못 본 구간을 추정해 숫자를 만들지 않습니다.

## 6. 특별 입력: 발성·거리 예외·메모

### 전체 청취·누적 발성량

바6·개11·개47~개50에는 **전체 청취·누적 발성량** 입력이 있습니다. **청취 기록 추가**를 누르고 **실제 청취 초**, **누적 발성 초**, **전체 실제 구간 청취 판독 완료**, **청취·발성량 근거**를 기록합니다. 청취 분모는 카메라 중복을 뺀 실제 전체 구간입니다. 0·1/3·2/3 경계를 항목의 선택 값과 대조하세요. 음성이 유실된 범위를 전체 청취로 처리하면 안 됩니다.

### 걷기 거리 예외

개38~개43은 각 실제 걷기 국면의 **걷기 거리 예외**를 펼쳐 확인합니다. 촬영 기록의 예외가 먼저 표시됩니다. **거리 예외**에서 예외 없음 확인/보호자가 다가옴/안전·거리 재확인/미확인을 선택하고, 필요한 **거리 예외 근거**와 영상 근거를 연결합니다. 다른 걷기 국면의 시각을 가져오면 저장이 거절됩니다.

### F와 G, 개59의 차이

**F 관찰 근거**는 실제 분석 근거입니다. **G 양식 검토메모**는 양식 자체를 검토하는 메모이며 분석과 보호자용 문장의 입력에서 제외됩니다. 양식에 있던 예시를 실제 관찰처럼 옮겨 적지 마세요.

**개59 연결 메모 · 별도 보존**을 펼치고 **개59 연결 메모 추가**를 누르면 메모·연결 항목·영상 근거를 작성할 수 있습니다. 이 메모는 연결한 항목의 숫자·기회·상태를 바꾸지 않습니다. 더 이상 필요 없는 줄만 **이 연결 메모 제거**로 제거합니다.

보5·보6·보9·보14에는 입장·퇴장 근거를 각각 남기고 퇴장 종합값을 한 번 기록하라는 안내가 있습니다. 미정 복수 사건 규칙은 화면의 대기 표시를 따르며 임의의 평균·대표값으로 채우지 않습니다.

## 7. 저장 → 제출 → 계산

### 먼저 초안 저장

1. **저장·정정 사유**에 현재 작업을 알아볼 수 있는 이유를 적습니다. 예: 「재회 구간 근거 확인 후 초안 저장」.
2. **채점 초안 저장**을 누릅니다.
3. 저장 후 판본 `r숫자`, 직접 입력 기록 수, **저장본 필수 미기록**을 확인합니다. 화면에 입력한 내용은 버튼을 누르기 전까지 서버에 저장되지 않습니다.

### 준비된 원자료 제출

1. 필수 미기록이 0개인지 확인합니다.
2. 마지막 편집 내용이 저장되어 있는지 확인합니다. 미저장 입력이 있으면 제출 버튼이 비활성화됩니다.
3. 기록 목적에 따라 표시되는 **독립 원자료 제출**, **공개 후 검수 제출**, **합의 기록 제출**을 누릅니다.
4. **제출본** 상태를 확인합니다. 바54·바55를 관찰하지 않았다면 제출 시 선택 관찰 미실시로 보존됩니다.

제출은 승인 요청이 아닙니다. 계산에 사용할 원자료 판본을 남기는 작업입니다. 다른 직원의 승인·공개 허가·재개방 승인을 기다릴 필요가 없습니다.

### 제출 원자료로 기본 결과 계산

1. 시트 아래 **계산과 기본 판정**을 봅니다.
2. **입장·퇴장 같은 물건 확인**을 미확인/같은 물건/다른 물건으로 기록합니다. 확인한 선택을 했다면 **같은 물건 확인 근거**도 적습니다. 모르는 상태를 억지로 확인 처리하지 마세요.
3. **제출 원자료로 계산**을 누릅니다.
4. **기본 결과 선택**에서 원자료 판본과 결과 판본을 확인합니다.
5. 보호자 배점의 사용·제외 근거, 계산별 값·분자·분모·보류 사유, 안전기지의 실제 사건 순서를 살펴봅니다.

계산은 해당 제출 판본을 고정합니다. 이후 접수나 시트를 수정해도 기존 계산이 자동으로 새 입력의 결과로 바뀌지 않습니다. 최신 입력으로 계산하려면 적절한 시트 판본을 새로 저장·제출하고 계산해야 합니다.

## 8. 기본 판정을 검토하거나 수정하기

자동 초안과 다른 판단을 남길 때 **기본 유형 선택**에서 작업합니다. 대상은 **보호자 교육태도**와 **반려견·보호자 관계**입니다.

1. **자동**과 **적용** 값을 먼저 비교합니다.
2. 해당 **선택**에서 유형 또는 판정보류를 선택합니다.
3. **상태**를 작성 중/완료/판정보류로 고릅니다. 작성 중 선택은 자동 초안을 유지하고, 완료·판정보류로 저장한 수동 선택은 기본 판정에 적용됩니다.
4. **근거·반대 근거 선택**에서 실제 유효 관찰을 선택합니다. 반대 근거 항목도 먼저 근거 목록에 포함한 뒤 반대 근거로 체크합니다.
5. **반대 근거 검토 메모**와 **판단 이유**를 적습니다. 완료 판정에는 실제 확인량이 있는 해당 영역 근거와 반대 근거 또는 검토 후 없다는 이유가 필요합니다.
6. **기본 판정 수정 사유**를 적고 **기본 판정 저장**을 누릅니다.

교육태도에는 실제 관찰 기회가 있는 배점 근거가 필요합니다. 기회 미확인·직원 중단 뒤·배점 합계 0인 근거를 지지 근거로 쓰면 거절될 수 있습니다. 분리·재회 미실시는 관계 판정보류이며, 개21의 미승인 집계 하나로 관계 유형을 확정할 수 없습니다. 수동 판정은 자동 비율과 원값을 덮어쓰지 않습니다.

## 9. 이미 제출한 기록을 정정하기

시트를 열어 현재 작업본에서 필요한 행을 수정하고 사유를 쓴 뒤 **제출본 수정 저장**을 누릅니다. 원제출본은 보존되고 새 초안 판본이 만들어집니다. 새 초안을 확인해 다시 제출합니다. 다른 직원이 수정했다면 실제 저장 계정이 기록되고, 원평가자 정보는 유지되며 후속 판본은 검수로 구분됩니다.

**보존본 조회**에서 이전 시트 판본을 읽을 수 있습니다. 보존본은 읽기 전용이며, 수정하려면 **현재 작업본**을 선택해야 합니다. 미저장 입력이 있으면 보존본 선택이 잠기므로 먼저 저장하거나 버릴 내용을 결정합니다. 기본 결과도 **보존 결과 ○판**으로 확인하고 **최신 기본 결과 불러오기**로 현재 결과에 돌아옵니다.

AI 시트를 사람이 수정하면 **AI 원본의 사람 수정 판본**으로 표시됩니다. 최초 AI 출력은 이전 판본에 남습니다. 이 수정 결과를 최초 독립 AI 출력이라고 해석하면 안 됩니다.

## 10. 잘 안될 때

| 화면 상황 | 해결 순서 |
| --- | --- |
| 실제 촬영 기록을 먼저 확정하라는 안내 | 촬영 기록 메뉴에서 해당 회차를 확인·확정한 뒤 현재 접수 버전을 새로 조회합니다. |
| 같은 평가자·입력·목적의 시트가 있음 | 목록의 기존 시트를 엽니다. 새 ID로 중복 독립본을 만들지 않습니다. |
| 제출 버튼이 비활성화됨 | 미저장 입력, 초안 여부, 필수 미기록 수를 차례로 확인합니다. 필수 행에는 값 또는 빈값 상태·사유를 남깁니다. |
| 원값 또는 빈값 사유가 필요함 | 안내에 나온 원코드를 검색하고 해당 값·사유를 보완합니다. |
| 근거 영상/해시/카메라/동기화 오류 | 시트의 고정 입력과 현재 원본 파일 연결을 확인합니다. 시각을 임의로 맞추거나 해시를 변경하지 않습니다. 필요한 파일 복구는 담당자와 진행합니다. |
| 전체창 근거 또는 음성 청취 분모 오류 | 실제 확인한 범위를 다시 점검합니다. 전체 확인이 안 되었으면 관찰량 부족 등 알맞은 상태로 기록합니다. |
| 다른 변경이 저장됨·409 충돌 | 미저장 입력은 유지됩니다. 입력을 별도로 확인해 두고 **미저장 입력 버리고 최신 조회**로 최신판을 읽은 후 필요한 내용만 다시 반영합니다. 버리기 동작은 미저장 편집을 없앱니다. |
| 접수·촬영 입력 변경 안내 | 이 시트는 기존에 고정한 영상·창을 유지합니다. 이전 입력 평가인지 최신 입력 평가인지 정하고, 최신 촬영을 평가하려면 그 입력으로 새 시트를 만듭니다. |
| 규칙 확인 대기·판정보류 | 원근거와 부족 사유를 보존합니다. 자료 부족은 실제 자료로 보완하고, 규칙 대기는 확인된 규칙이 반영될 때까지 임의 값을 만들지 않습니다. |
| Excel 가져오기 준비 중 | 현재 채점 화면에서 직접 입력합니다. 점수 있는 참고 파일 등록과 실제 채점 Excel import는 다른 기능입니다. |
| 로그인 만료 | 다시 로그인하고 현재 대상·회차·판본을 확인합니다. 서버에 저장하지 않은 내용은 저장본으로 간주하지 않습니다. |

## 11. 마무리 확인과 다음 작업

평가자, 목적, 원자료 판본, 제출 상태, 유효 근거, 미관찰/규칙 대기 사유를 확인합니다. **열람·수정 기록**과 **고정 입력·revision/hash·노출 이력**은 누가 어떤 판본을 작업했는지 확인할 때 펼칩니다.

사람 독립 채점은 **최종본·리포트 발급의 필수 단계가 아닙니다.** 게시된 AI 기본 결과만으로도 최종본을 만들 수 있으며, 이 경우 영역별 상태가 초안·근거 부족·보류(규칙 확인 대기)일 수 있습니다([해석과 최종 결과 §9](K-DOG_해석과최종결과_사용설명서_v1.0_20261013.md)). 사람 채점은 독립 원자료를 남기거나 AI 결과를 검수·비교할 때 사용합니다.

다음 단계는 [AI 분석](K-DOG_AI분석_사용설명서_v1.0_20261013.md)과 비교하거나, [해석과 최종 결과](K-DOG_해석과최종결과_사용설명서_v1.0_20261013.md)에서 행사에 사용할 기본 결과를 선택하는 것입니다. 연구 목적의 독립본·검수본 구분은 [연구 내보내기](K-DOG_연구내보내기_사용설명서_v1.0_20261013.md)를 함께 읽습니다. [설명서 목록](README.md)으로 돌아갈 수 있습니다.
