# K-DOG 촬영 기록 사용설명서

버전: v1.0 · 작성일: 2026-10-13 · 기능 확인 기준: `main / 53889b7` · 평가 기준: S1(`20261002`, `intake-4.0`)

대상: 현장 운영자, 교수자·검토자, 관리자, 개발자 중 로그인 가능한 활성 계정. [사용설명서 목차](README.md)

## 1. 이 기능을 언제 사용하나요?

촬영 영상에서 **실제로 언제 어떤 구간·사건이 있었는지** 기록할 때 사용합니다. 기록한 시각은 전처리 클립과 항목별 관찰창의 근거가 됩니다. 예정표의 시간을 입력하는 화면이 아니며, 점수나 최종 해석을 입력하는 화면도 아닙니다.

주로 영상 업로드·참가자 연결을 마친 뒤, 전처리와 채점 전에 사용합니다. 교수자가 영상 검토 중 실제 부름 시각·접촉·가림·오디오 손실을 발견했거나 운영자가 구간 경계를 잘못 기록한 경우에도 이 화면에서 새 입력 판본으로 정정합니다. 재촬영은 새 회차를 추가하고 그 회차의 실제 사실을 기록합니다.

| 로그인 계정 | 촬영 기록 업무 |
| --- | --- |
| 운영자(`operator`) | 모든 공유 참가자의 촬영 기록 작성·초안 저장·확정·확정본 수정·회차 추가 |
| 교수자·검토자(`reviewer`) | 운영자와 동일. 타 직원의 기록을 검토하고 수정 가능 |
| 관리자(`admin`) | 운영자와 동일 |
| 개발자(`developer`) | 운영자와 동일 |

운영자·검토자·관리자의 화면 표시명은 **업무 계정**입니다. 교수자 전용 승인을 받아야 확정·수정할 수 있는 구조가 아닙니다. 동의·배정·소유자·공개·재개방 승인은 사용 조건이 아니며, 실제 행위자와 이전 입력 판본은 보존됩니다.

## 2. 메뉴와 사전 조건

메뉴 경로: **현장 운영 → 촬영 → 촬영 기록 (8구간)**.

다음 세 가지를 먼저 준비합니다.

1. **올바른 참가자와 회차:** 참가자 ID·반려견·행사를 대조하고 상단 촬영 회차를 확인합니다. 회차 선택은 저장 대상을 바꾸므로 다른 직원과 같은 참가자를 작업할 때 특히 확인합니다.
2. **회차에 연결된 기준 영상:** [영상 파일 업로드](K-DOG_영상파일업로드_사용설명서_v1.0_20261013.md)에서 파일 전송뿐 아니라 **영상 정보 저장**까지 마쳐야 합니다. INSV 원본 보관 전용 파일은 기준 영상 목록에서 제외됩니다.
3. **실제 절차·시각을 확인할 수 있는 근거:** 마이크 음성·진행자 신호·영상의 실제 행동으로 구간과 사건을 확인합니다. 화면의 **영상 열기**가 브라우저에서 재생되지 않으면 보관 파일을 확인할 수 있는 재생 환경에서 실제 시각을 확인합니다. 재생 성공과 전처리 판독 성공은 별도입니다.

화면의 **사용 가능** 영상 수는 마지막 전처리에서 실제 클립이 만들어진 영상 수입니다. 처음 기록할 때 **영상 읽기 확인 대기**로 표시되는 것은 자연스럽습니다. 이 수치를 올리려고 사실 확인 전 촬영 확정을 서두르지 않습니다. 입력이 바뀌면 **입력이 바뀌어 전처리를 다시 해야 합니다** 안내가 나옵니다.

### 2.1. 360 통합 MP4를 기준으로 사용할 때

360 통합 영상의 **촬영 시간의 순서·속도 유지**를 실제로 확인해야 기준 영상·사건·관찰 근거·확인된 동기화의 시간 근거로 확정할 수 있습니다. **잘 모름** 또는 **구간 편집·속도 변경 있음**인 시간 정보는 초안으로 남길 수 있지만 확정·전처리의 시간 앵커로 사용할 수 없습니다.

영상 배치와 시간 대응은 다른 조건입니다. **360 펼침 영상 + 촬영 시간 유지**는 촬영 시각 근거로 사용할 수 있으나 그 영상의 클립 제작은 제한됩니다. 전처리용으로는 **일반 화면 + 촬영 시간 유지** MP4를 마련합니다. 정보 정정 방법은 [영상 업로드 설명서 §5.2](K-DOG_영상파일업로드_사용설명서_v1.0_20261013.md#52-360-통합-영상의-처리-정보-정정)를 따릅니다.

## 3. 처음 기록하는 순서

1. **촬영 기록 (8구간)** 메뉴에서 검색·행사 필터로 참가자를 찾습니다.
2. 해당 행의 **열기 ↗**를 누릅니다. ID와 반려견 이름, 화면의 **…차 촬영**을 확인합니다.
3. **실제 촬영 절차**를 선택합니다. 실제 영상이 현재 절차를 따른 경우 **현재 절차 확인**, 확인하지 못하면 **미확인**, 다른 절차면 **이전·다른 절차**를 사용합니다.
4. **절차 확인 근거**에 무엇을 확인했는지 적습니다(선택 입력, 비워 두어도 저장·확정할 수 있습니다). 예: “진행자 신호와 문 개폐 시각으로 8구간 순서 확인. 혼자 구간은 복지 중단 후 즉시 재회.” 실제 확인 사실을 적고 예시 문장을 그대로 복사하지 않습니다.
5. **기준 영상**을 선택합니다. 모든 8구간과 걷기 6국면의 시각은 이 영상의 초를 기준으로 기록합니다.
6. **영상 열기**를 눌러 구간 경계를 확인합니다. 시간 입력란은 숫자 **초**입니다. 예를 들어 영상의 1분 23.5초는 `83.5`로 입력합니다. 이 화면에 `1:23.5`를 넣는 방식은 아닙니다.
7. **실제 8구간**을 펼쳐 상태·시작·끝·예외 사유를 입력합니다.
8. 걷기를 실시했다면 **걷기 실제 6국면**을 기록합니다.
9. 필요한 사건·수동 오프셋·실제 관찰 근거와 선택 관찰 기록을 입력합니다. 각 항목의 사용 시점은 아래 설명을 따릅니다.
10. 작업 중간에는 **촬영 기록 초안 저장**을 누릅니다. 절차 확인 근거는 선택이지만, 사건·관찰 근거를 추가했다면 그 행의 필수 사실도 채워야 합니다.
11. 실제 시각과 예외를 검토한 뒤 **촬영 기록 확정**을 누릅니다.
12. 화면의 **촬영 기록 확정** 상태와 **저장된 실제 관찰창 확인**을 확인하고 전처리로 이동합니다.

기준 영상을 바꾸면 구간·걷기 국면 시각은 비워지고 다른 영상의 동기화는 다시 확인해야 합니다. 기존 사건·관찰 근거는 원래 영상에 연결된 채 보존됩니다. 기준 영상만 바꾸고 이전 시각을 그대로 쓸 수 있다고 생각하지 않습니다.

## 4. 실제 8구간과 걷기 6국면

### 4.1. 8구간 상태와 시간

현재 순서는 **입장 → 기준 → 혼자 → 재회 → 무시 → 걷기 → 낯선 사람 → 퇴장**입니다. 화면 진행 안내의 예정 길이는 순서대로 30·20·60·30·20·30·30·30초이며 전환은 별도입니다. 이 숫자는 실제 시작·끝을 대신하는 값이 아닙니다.

| 상태 | 언제 선택하나요? | 기록 방법 |
| --- | --- | --- |
| 실시 | 해당 구간을 실제 실시한 경우 | 실제 시작·끝 초. 끝은 시작보다 뒤여야 함 |
| 단축 | 예정보다 짧게 실시한 경우 | 실제 시작·끝과 단축 사유 |
| 미실시 | 해당 구간을 수행하지 않은 경우 | 시각을 만들지 않고 빈값 유지, 미실시 사유 입력 |
| 복지 중단 | 복지·안전 때문에 진행을 중단한 경우 | 실제 시작·중단 끝 시각과 중단 사유 |

확정할 때 실시·단축·복지 중단 구간의 시작·끝이 필요합니다. 구간끼리 겹치거나 현재 절차의 순서와 모순되면 저장이 거절됩니다. 실제 전환 시간이 있다면 주 구간을 억지로 이어 붙이지 않고 별도 사건으로 남깁니다.

분리를 미실시했다면 현재 S1 절차에서 재회도 미실시입니다. 혼자 구간을 단축·복지 중단하여 보호자가 즉시 돌아왔으면 **혼자 구간 끝 = 재회 시작**을 같은 실제 시각으로 기록합니다. 이 조건을 만족시키기 위한 예정 시각을 만들어 넣지 않습니다.

### 4.2. 걷기 실제 6국면

걷기는 **이동1 → 정지1 → 이동2 → 정지2 → 이동3 → 정지3**으로 기록합니다. 첫 실제 이동 시작이 걷기 시작이고 마지막 실시한 정지 끝이 걷기 끝입니다. 걷기 시간을 단순히 여섯 등분하지 않습니다.

1. 각 국면의 상태와 실제 시작·끝을 영상에서 확인합니다.
2. 실시한 국면은 걷기 구간 안에 있어야 하며, 연속 국면의 경계가 맞아야 합니다.
3. 미실시·단축·중단 국면은 실제 사유를 남깁니다. 전체 걷기를 정상 **실시**로 두면서 일부 국면만 미실시로 만드는 기록은 확정할 수 없습니다. 실제 중단 상황에 맞게 전체 상태도 확인합니다.
4. **거리 예외**는 **예외 없음 / 보호자가 접근 / 안전상 재확인 필요 / 미확인** 중 실제 사실을 고릅니다.
5. 보호자 접근·안전상 재확인이 있으면 **예외 근거**를 적습니다. 예외 표시는 거리 측정값을 대신하지 않으며, 앱이 현장 정지선·거리·추가 무효 기준을 임의 확정하지 않습니다.

## 5. 실제 사건·전환·기회 기록

이 부분은 특정 실제 사건을 기준으로 관찰창을 만들거나, 미접촉·가림·소실·복지 중단을 설명할 때 사용합니다. 모든 메뉴 사건을 형식적으로 추가할 필요는 없습니다. 해당 영상의 실제 사실과 필요한 미발생·미관찰을 기록합니다.

1. **실제 사건·전환·기회**를 펼칩니다.
2. **추가할 사건**에서 해당 사건을 선택합니다.
3. **사건 영상**이 실제 확인한 영상인지 확인합니다. 기준 영상과 다르면 그 영상의 원래 초로 사건을 적고 동기화를 별도로 확인합니다.
4. **사건 상태**를 고릅니다.

   | 사건 상태 | 시각과 의미 |
   | --- | --- |
   | 관찰됨 | 실제 사건 초 입력. 구간 사건이면 해당 구간 내부여야 함. 지속 사건이면 끝 초도 실제대로 입력 |
   | 미발생·미접촉 | 없었다는 사실을 기록. 시각은 빈값이며 임의 `0`을 넣지 않음 |
   | 미관찰·판독 불가 | 있었는지 판단하지 못한 상태. 미발생과 구별하며 시각은 빈값 유지 |

5. **해당 구간**, **실제 맥락·사유**를 채웁니다. 준비·전환 사건은 **전환·구간 밖**으로 기록합니다. 재회·낯선 사람 전용 사건은 각 구간에 속해야 합니다.
6. 필요한 경우 **영향 항목 (쉼표로 구분)**에 실제 관련된 S1 항목 코드를 적습니다. 예: `바54,바55`. 코드 연결만으로 점수가 입력되지는 않습니다.
7. 초안 저장 후 **저장된 실제 관찰창 확인**에서 사건으로 계산한 시각을 확인합니다.

| 사건 묶음 | 언제 사용하나요? |
| --- | --- |
| 바닥 첫 접촉·물건 가까이 진입·물건 앞 정지·물건 접촉·통과·자유 이동 | 입장 구간의 실제 기회와 행동 시작점 기록 |
| 보호자 나가기 준비·완전히 문 밖으로 나감·직원 신호 | 실제 분리 시작과 진행 신호를 구별 |
| 재회 실제 부름·접촉 시작/끝·첫 명확한 고개 전환·보호자 확인 | 재회 사건과 관련 관찰창·선택 관찰의 기준 기록 |
| 요원 안전문 밖 대기·입실·접근·부름·접촉·대기·퇴장·고개 전환 | 낯선 사람 구간의 실제 절차와 접촉 기회 기록 |
| 걷기 전 이름·S로 이동 시작/끝·걷기 뒤 착석·전환 대기·목줄 채우기 | 주 걷기 구간 밖 준비·전환 사실 기록 |
| 영상 가림·신체 미관찰·오디오 손상·소실 | 무엇을 어느 범위에서 관찰할 수 없었는지 기록 |
| 외부 자극·복지 중단·중단 뒤 조치·경로 이탈·먹이 제공 | 정상 절차와 다른 맥락·중단 이유 기록 |
| 안전기지 보호자 접근·접촉·탐색 재개 | 실제 사건의 연결 순서를 남길 때 |

부름·직원 신호·접촉은 서로 다른 사건입니다. 접촉을 못 보았다고 접촉 횟수를 0으로 확정하지 않습니다. 접촉 끝은 시작보다 앞설 수 없습니다. 메모·꼬리 변화·안전기지에 연결한 사건은 연결을 먼저 해제해야 **사건 기록 삭제**를 할 수 있습니다.

## 6. 다른 영상 수동 오프셋

같은 회차의 여러 카메라 영상에서 같은 사건을 공통 시각으로 비교할 때 사용합니다. 한 영상만 사용한다면 다른 영상의 오프셋을 만들 필요가 없습니다.

공식은 **다른 영상 초 = 기준 영상 초 + 오프셋**입니다. 예를 들어 같은 박수 신호가 기준 영상 `40`초, 다른 영상 `42`초이면 오프셋은 `+2`초입니다. 다른 영상이 `37`초이면 `-3`초입니다. 예시는 계산 설명이며 실제 값은 같은 사건으로 확인합니다.

1. **다른 영상 수동 오프셋**을 펼칩니다.
2. 두 영상에서 같은 명확한 신호·사건을 찾아 각 시각을 비교합니다.
3. 파일별 **오프셋 초**와 **동기화 근거**를 입력합니다.
4. 실제 대응을 확인한 뒤 **수동 동기화 확인**을 체크합니다. 오프셋이나 근거를 고치면 확인이 해제되므로 다시 검토합니다.
5. 기록을 저장합니다. 확인 전 영상의 사건은 원사실로 남지만 공통 채점 시각으로 사용하지 않습니다. 전처리에서는 미확인 오프셋 영상이 클립 제작에서 제외됩니다.

## 7. 창별 실제 관찰 근거

파일이 존재하는 것과 사람이 실제로 보거나 들은 것은 다릅니다. 관찰창의 어느 범위를 실제 관찰했는지, 전체인지 일부인지 기록할 때 사용합니다.

1. **창별 실제 관찰 근거 → 관찰 근거 추가**를 누릅니다.
2. **관찰 창**과 **근거 영상**을 선택합니다.
3. **근거 종류**를 **영상 관찰** 또는 **연속 오디오 청취**로 고릅니다. 영상 전체를 보았다고 오디오도 들은 것으로 기록하지 않습니다.
4. 해당 원영상에서 확인한 **관찰 근거 시작·끝**을 초로 입력합니다.
5. **관찰 범위**를 고릅니다.

   | 관찰 범위 | 실제 관찰 초 |
   | --- | --- |
   | 일부 관찰 | 실제 관찰한 초를 직접 입력. 입력 범위 길이보다 클 수 없음 |
   | 위 범위 전체 관찰 | 입력한 시작~끝 범위의 길이로 자동 계산 |
   | 미관찰 | 0초로 기록. 관찰하지 못한 범위와 설명은 남김 |

6. **관찰 근거 설명**에 실제 보인·들린 범위와 제한을 적습니다.
7. 저장한 뒤 관찰창 표의 **전체 관찰 근거**에서 영상·오디오 확인을 각각 봅니다.

**위 범위 전체 관찰**은 그 행에 입력한 범위를 전부 관찰했다는 뜻입니다. 관찰창 전체가 자동으로 확인되었다는 뜻은 아닙니다. 같은 시간에 두 카메라로 보았다고 관찰 초를 두 배로 더하지 않습니다. 파일 길이·클립 길이·오디오 가용 초를 실제 청취 초나 발성 초로 대신하지 않습니다.

## 8. 선택 관찰·연결 메모·안전기지

### 8.1. 선택 관찰 · 꼬리 변화

`바54`(재회), `바55`(낯선 사람)의 꼬리 변화에 필요한 실제 맥락을 기록할 때 사용합니다.

1. 해당 **첫 명확한 고개 전환** 사건을 먼저 기록합니다.
2. **선택 관찰 · 꼬리 변화**에서 **바54 선택 관찰 기록** 또는 **바55 선택 관찰 기록**을 누릅니다.
3. 실제 고개 전환 사건을 선택하고 **첫 명확한 전환 확인**을 검토합니다.
4. 같은 자세·같은 움직임·전 2초 꼬리 관찰·후 3초 꼬리 관찰을 각각 **미확인 / 확인됨 / 아님·관찰 불가**로 기록합니다.
5. 선택 근거를 적고 저장합니다. 가림·걷기 전환 등으로 비교 조건을 확인할 수 없으면 값을 만들지 않습니다. 이 화면은 꼬리 점수를 자동 확정하는 화면이 아닙니다.

### 8.2. 개59 연결 메모

정량 점수로 대신할 수 없는 실제 맥락을 관련 항목·사건과 연결할 때 사용합니다. **개59 연결 메모 → 연결 메모 추가**를 누르고 메모 내용, 연결 항목, 실제 사건을 선택합니다. 개59는 별도 메모이며 점수 행을 추가하는 기능이 아닙니다. 연결 사건을 삭제하려면 메모의 연결부터 해제합니다.

### 8.3. 안전기지 실제 순서

실제로 **보호자 접근 → 보호자 접촉 → 탐색 재개**가 있었는지 사건 순서를 남길 때 사용합니다. 먼저 각각의 사건을 기록하고 **안전기지 사건 연결**에서 대응 사건과 순서 근거를 연결합니다. 확인하지 못한 단계는 **미확인**으로 남깁니다. 단순한 탐색 분류나 인상으로 접근·접촉·재개 순서를 만들어 넣지 않습니다.

## 9. 초안·확정·확정본 수정·재촬영

| 동작 | 언제 사용하나요? | 결과 |
| --- | --- | --- |

| 촬영 기록 확정 | 실제 절차·구간·예외를 확인했을 때 | 새 입력 버전과 확정 기록 저장. 현재 절차가 확인된 경우 전처리 가능 여부 확인 |

| 현재 촬영 메모 수정 | 마이크·진행 등 회차 특이사항을 메모할 때 | 회차 메모 저장. 구간 시각·점수·관찰 근거를 대신하지 않음 |

확정은 기록의 검토 완료 상태입니다. 파일 품질이나 채점 정확도를 인증하는 상태는 아닙니다. **미확인 / 이전·다른 절차**를 사실대로 저장한 기록도 보존되지만, 현재 절차 확인·확정 조건을 만족하지 않으면 S1 전처리를 시작할 수 없습니다.

입력 수정 후 기존 전처리·시트·리포트는 이전 판본의 결과로 보존됩니다. 새 결과가 필요하면 촬영 재확정 후 새 전처리·새 분석을 명시적으로 진행합니다. 화면의 **보존된 이전 촬영 원기록**은 역사 자료이며 현재 절차를 다시 확인한 기록으로 자동 변환되지 않습니다.

## 11. 결과 확인과 다음 단계

**저장된 실제 관찰창 확인**은 마지막 저장본을 기준으로 계산합니다. 미저장 편집 중에는 방금 바꾼 내용의 결과가 아닙니다. 저장 후 기준 영상 초, 창 상태, 영상·오디오의 전체 관찰 근거를 확인합니다.

시각 확정·일부 구간·미관찰·미실시·접촉 기회 없음·규칙 확정 대기·절차 적합성 검토 필요는 서로 다른 상태입니다. 미관찰을 0점으로 바꾸거나 **규칙 확정 대기**를 촬영 시각 조작으로 해소하지 않습니다. 개21 등 미확정 평가 정책과 최종 카메라 배치·현장 절차 회신은 별도 대기 범위입니다.

- 실제 촬영 절차가 현재 S1로 확인되고 기록이 확정되었으면 [전처리](K-DOG_전처리_사용설명서_v1.0_20261013.md)에서 실제 클립·파일별 제한을 확인합니다.
- 파일 출처·360 처리 정보·참가자 연결을 고쳐야 하면 [영상 파일 업로드](K-DOG_영상파일업로드_사용설명서_v1.0_20261013.md)로 돌아갑니다.
- 전처리 결과 확인 후 [독립 채점](K-DOG_독립채점_사용설명서_v1.0_20261013.md)으로 진행합니다.

실제 공간에서의 동선·정지선·거리·요원 진행·복지 중단 리허설, 실제 참가자 영상의 판독 품질과 Studio 시각 대응, 물리 PC 3대 운영 검증은 별도 대기입니다. 합성 시각·합성 영상의 검증 성공을 실제 현장 운영 인수나 정확도 보장으로 읽지 않습니다.
