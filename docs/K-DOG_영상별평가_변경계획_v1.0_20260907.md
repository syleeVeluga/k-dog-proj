# K-DOG 영상별 직접 평가 변경 계획

버전: v1.0 · 2026-09-07

## 수용 범위

동일 검사의 영상마다 전체 행동 55항목과 원문 선택지를 제공하여 Gemini가 직접 평가한다. 영상 파일 결합·전체 자동 동기화는 하지 않는다. 영상별 판단·근거·관찰 범위를 보존하고 항목별 최종 선택지를 결정한 후 기존 서버 산술과 리포트를 사용한다. 신규 실행은 새 방식이 기본이며 기존 run의 설정·산출물은 유지한다. 개발자 설정에서 기존 방식과 비교 실행할 수 있다.

## 구현 순서와 완료 기준

1. 영상별 평가 계약·프롬프트: 55항목의 누락/중복, 없는 선택지, 다른 영상 근거, 범위 밖 시간, 무음의 음성 근거를 거절한다. 충분한 관찰 범위 없이 채점하지 않는다. 횟수·시간 측정을 근거와 저장한다.
2. 항목별 병합: 같은 선택지는 한 번 채택하고 관찰 불가 영상은 유효한 판단을 취소하지 않는다. 평균·최댓값·다수결·모델 자신감으로 선택하지 않는다. 불일치 항목만 영상별 한 차례 재검토하고 여전히 다르면 근거와 함께 보류한다. 재검토는 원본 파일을 개별 제공하고 해당 항목·근거 구간을 지정한다.
3. 실행·화면: 성공한 영상 단계 재사용, 실패 단계 재시도, 점유/중지/삭제 검사와 호출 예산을 유지한다. 영상별 결과와 재검토 이력, 최종 채택 근거를 조회·재생한다. 구 방식의 프롬프트는 새 평가에 혼합하지 않는다.
4. 검증: 합성 계약·3시야 병합·재검토·복구·예산·권한·기존 실행 회귀 시험, frontend build/e2e, 원본 카탈로그 대조, 허용된 실제 3영상의 별도 시험. 실제 AI 시험과 합성 시험을 구분한다.
5. 독립 cold review의 지적을 수정하고 해당 검증을 반복한 후 commit·push한다.

실호출 검증에 따른 보완: 항목→관찰의 명시 참조로 서버가 역방향 후보 태그를 생성한다. 구조/출처 오류와 의미적 측정 근거 부족을 분리하여 후자는 해당 항목만 보류한다. 보류 이유에 측정값·근거 범위를 남기며, 정상 항목과 명시적 충돌 상태는 보존한다. 두 보완은 독립 cold review를 거쳤다.

## 유지할 평가 규칙

원문 55항목·선택지·점수는 변경하지 않는다. DOG-12/OWN-14 등 미정 시간 경계는 보류한다. 설문은 영상별 평가에 제공하지 않는다. 검사 전체의 행동 부재는 그 범위를 충분히 관찰한 경우에만 판단한다. 한 시야의 가림·미녹화와 검사 미실시를 구분한다. 최종 리포트의 유효 항목 수와 결측을 보존한다.
