# PR-RP06 교수 확정 기준표에 따른 외부 비교 적용

버전: v1.0 · 2026-10-07 · 상태: 수령 전 기술 검증·독립 검토·원격/로컬 병합 완료, 실제 확정표 적용은 미수령 대기 · 선행: RP05 기술 검증·원격/로컬 병합 완료, 실제 교수 검토 대기

상위: [수용안 적용 계획](K-DOG_리포트수용안적용계획_v1.0_20261007.md). 연결: A04/A06, D06/P06, R19, S13/S17, O09, RP-T13/14.

브랜치 제안: `veluga/rp06-external-reference-tables` · PR 제목: `feat: apply researcher-confirmed comparison tables`

## 목적과 역할

회신으로 외부 연구값 출력 및 종전 일괄 보류 해제 의사는 확인했다. 그러나 문항 대응·비교 지표·산식·참고 수치·표현 범위는 아직 없다. **교수님이 전문적인 비교 가능성을 판단하고 두 기준표를 작성·확정하며, 개발 측은 전달 기준의 기계적 구현과 검증을 담당한다.** 종전 보류 문구를 이유로 개발 방향 승인을 다시 요청하지 않되, 출력 의사만으로 모든 문항의 동등성 확인을 대체하지 않는다.

RAG·임베딩·벡터 DB·파인튜닝·논문 전문을 AI에 전달하는 기능은 구현하지 않는다. 개발 측이 논문을 독자적으로 해석하여 대응표·임계값을 확정하지 않는다.

## 교수님께 요청할 두 기준표

### 표 1 문항별 대조표 — 비교에 사용할 문항당 한 행

| 필드 | 작성할 내용 |
| --- | --- |
| 현재 문항 | K-DOG 문항 번호와 질문 원문 |
| 원척도 문항·출처 | 대응하는 문항 번호·원문, 논문/부록 이름 및 위치. 본문에 없다면 해당 자료 제공 |
| 소속 지표 | 하위척도·영역 이름 |
| 양쪽 척도 | 점수 범위·선택지 의미·높은 점수의 뜻·역채점 여부 |
| 문항 차이 | 번역/표현 변경·추가/삭제·일부 문항만 사용 여부 |
| 비교 판정 | 직접 비교 가능 / 조건부 가능 / 비교 불가 / 판단 보류 |
| 적용 조건 | 변환·제한·필요 문구. 개발자가 유추하지 않도록 구체적으로 작성 |

### 표 2 지표별 산출·출력 기준표 — 실제 표시할 지표당 한 행

| 필드 | 작성할 내용 |
| --- | --- |
| 지표·현재 계산 | 표시 이름, 포함 문항, 합계/평균, 역채점·변환·미응답 처리 |
| 비교 대상 | 논문·연도·정확한 연구 집단/하위집단. 어느 집단 값을 사용할지 지정 |
| 수치·출처 | 사용할 평균·표준편차·유효 표본수, 필요한 전체 표본수, 표/페이지 위치 |
| 허용 출력 | 개인 점수와 직접 비교 / 별도 연구 참고값 소개 / 비교 제외 |
| 해석 범위 | 사용할 설명, 제한 문구, 높고 낮음 등 판정을 원할 경우 확정된 판정 기준 |
| 확인 정보 | 교수 확인자·확인일·표 판본, 적용 대상/조건, 관련 척도 사용·번안 조건의 확인 범위 |

두 표는 엑셀의 별도 시트 또는 같은 내용을 담은 문서로 받을 수 있다. 28개 전체가 아니라 외부 비교에 사용할 항목이 대상이다. 계산 방법은 실행 코드나 자유 수식 실행 파일 대신 검토 가능한 수식·설명으로 받는다. 현재 실제 표·확정 수치·추가 회신은 수령하지 않았으며 요청 메일도 이 계획으로 자동 발송하지 않는다.

## 수령 전·후 작업

| 시점 | 진행할 일 | 진행하지 않을 일 |
| --- | --- | --- |
| 수령 전 | 위 요청 항목 정리, 기존 S13/S17 재사용 경계·합성 fixture 검토 | 실제 출처 상태를 동등성 확인 완료로 변경, 임의 논문 평균·변환·국내 집단 선택 |
| 수령 후 | 파일/hash·판본·확인자 기록, 누락/중복/모순 검출, 지정 표의 수치 전사 확인, 기존 앱 계약과 연결 | 전사 검증을 연구 타당성 판단으로 표시, 범위 밖 지표 자동 확대 |
| 일부만 확정 | 확인된 항목만 새 비교 자산·snapshot에 적용 | 나머지 미정 항목 때문에 본인 결과 전체 차단 |

교수표와 논문 지정 위치의 수치가 다르면 차이만 전달하여 정정을 받는다. 임의로 값을 고치거나 교수 확인을 추정하지 않는다. 조건부/참고 소개 방식이 지정되지 않았다면 개발 측이 자동 선택하지 않는다.

## 변경 범위와 구현 순서

1. `resources/report/comparison-sources-v4.json` 및 새 판본 자산에 표의 허용값·조건·출처를 등록한다. 기존 출처 자료와 원문 hash를 보존하고 전달 표의 판본을 추가한다. 입력은 허용된 문항 ID·숫자·집계 종류로 검증하며 문서의 수식을 임의 실행하지 않는다.
2. `backend/app/domain/comparisons_v4.py`, `comparisons_v4.py`, `external_comparisons_v4.py`의 기존 확인자료/기술 활성화/snapshot 기능을 재사용한다. 새로운 플랫폼을 만들지 않는다. 출력 의사 확인과 항목별 전문 기준 확인을 구분해 UI·차단 사유를 갱신한다.
3. 확정된 설문 문항·척도·방향·결측/역채점·집단 조건을 정확히 연결한다. 새 RP01 정책과 표의 정책이 다르면 해당 비교를 보류한다. 설문 연구값을 S1 영상 점수에 적용하지 않는다.
4. RP03/04 리포트에 확정된 방식으로 비교를 표시한다. 직접 비교 조건이 충족된 경우만 개인 점수와 같은 비교 그래프를 사용한다. 교수님이 참고 소개만 지정한 경우 별도 설명·출처로 표시하고 평균 대비 판정을 생성하지 않는다.
5. `report_runs_v4.py`·렌더러·`exports_v4.py`·관련 frontend 비교 화면에서 같은 대상/설문/외부 기준 snapshot을 사용한다. 유효 표본수와 본인 응답 문항 수를 구분한다. 평균/표준편차만으로 백분위·정규분포·정상/위험 등급을 만들지 않는다.
6. 새 기준/철회는 새 실행과 현재 제공 조건에 반영하되 기존 발급 파일 bytes를 덮어쓰지 않는다. 기존 hash·권한·동의·삭제·철회 검사와 기술 활성화 이력을 유지한다. 교수 확인 상태 전체를 일괄 true로 바꾸는 우회는 하지 않는다.

## 2026-10-08 수령 전 기술 검증

RP05 [PR #58](https://github.com/syleeVeluga/k-dog-proj/pull/58)을 원격 병합하고 merge commit `edeb63b`로 로컬 `main`/`origin/main` 일치를 확인했다. 해당 기반에서 수령 전 합성 회귀만 추가했다. 실제 교수표를 전사한 기능 구현과 구분한다.

- 새 [조건부 발급 회귀](../../backend/tests/test_external_report_acceptance_v4.py)는 기존 연구 확인·활성화·snapshot 계약을 임시 합성 저장소에만 적용한다. 실제 교수 승인 파일이나 임의의 새 참고 평균을 추가하지 않았다.
- 새 RP03 문장→RP04 사진 없는 출력에 기존 조건부 snapshot의 정확한 대상/원입력 hash·문항 s10/s11·RP01 정책을 연결한다. 본인 유효 0 평균·응답 문항 수 2개와 외부 참고 평균·유효 연구 표본을 구별한다. HTML뿐 아니라 실제 PDF 텍스트도 확인한다.
- 발급 후 철회는 제공을 차단하되 보관 bytes를 보존한다. 문장 생성 중 철회가 발생하면 정상 발급을 하지 않는다. 공급자 응답은 합성이고 실제 호출은 0회다.
- 신규·기존 외부 비교/CSV·XLSX/자체 집단 39개, 41.145초 및 renderer/실행 27개, 68.976초에 통과했다. frontend build 및 S1 외부 비교/자체 집단/내보내기/리포트 E2E 9개, 1.0분에 통과했다. 브라우저의 실제 비교 PDF 6쪽에서 0 평균·참고 평균·유효 연구 표본 텍스트를 확인했다. 6쪽은 이 사례 결과이며 고정 요구가 아니다. 교수의 실제 표 기대값 검증으로 확대하지 않는다.
