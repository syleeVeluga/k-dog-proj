# PR-RP05 통합 검증과 교수 테스트 반영

버전: v1.0 · 2026-10-07 · 상태: 기술 종단 시험 구현·통과, 전체 회귀 진행 · 선행: RP04(RP01~RP03 포함) 원격·로컬 병합 완료

상위: [수용안 적용 계획](K-DOG_리포트수용안적용계획_v1.0_20261007.md). 연결: A01~A03/A05/A06, D04/G02, RP-T01~12.

브랜치 제안: `veluga/rp05-report-acceptance` · PR 제목: `test: verify accepted report flow and review outcomes`

## 목표와 범위

설문 입력→AI 원관찰/계산→애착 판단→최종 의견 반영→AI 문장→HTML/PDF 생성·다운로드를 통합 검증한다. 교수님이 검토한 실제 판단·문장 사례의 수정 사항을 회귀 기준으로 남긴다. 새 평가자 관리 시스템이나 매 발급의 승인 절차를 구축하지 않는다.

## 변경 대상

- 기존 `backend/tests/test_survey_v4.py`, `test_scoring_ai_v4.py`, `test_final_results_v4.py`, `test_report_runs_v4.py`, `test_report_api_v4.py` 및 RP02/RP03 신규 시험에 필요한 종단 사례 추가.
- `frontend/tests/survey-v4.spec.ts`, `judgements-v4.spec.ts`, `opinions-v4.spec.ts`, `report-v4.spec.ts`, `report-print-v4.spec.ts`의 사용자 흐름 연결.
- 구현 중 확인된 `maintenance.py`·manifest·버전 조회 관련 누락만 수정. 테스트 단계에서 무관한 구조 개편이나 추가 요구를 끼워 넣지 않음.
- 이 폴더와 기존 요구사항·인수·후속 대장에 실제 결과를 추가. 민감한 실제 영상·설문·리포트는 저장소 밖에서 관리.

## 검증 순서

1. 합성 자료로 RP-T01~11을 실행한다. 유효 0/null, 원점수 불변, 의견 우선, 생성 근거, 장면 제거, 출력 일치를 검사한다.
2. 입력/의견 수정 중 실행, 취소·삭제, 옛 token 응답, 공급자 오류·응답 유실·호출 예산, 명시 재사용, 새 정책과 기존 S1 결과의 판본 혼용을 검사한다.
3. HTML/PDF 전체 시각 검토와 모바일/인쇄 회귀, 다운로드 권한·정확한 입력/최종본·출력 hash, 백업/복원 후 삭제 상태를 검증한다.
4. 실제 AI 검증용 자료의 동의·대상/기준 판본·호출 예산을 확인한 뒤 실제 공급자 결과를 만든다. 합성 fixture와 실제 공급자 시험을 구분하고 기존 3PC/360도/시간 실측 전체 완료로 확대하지 않는다.
5. 교수님에게 판단과 근거·반대근거·보류 사유·문장·조언을 검토받는다. 정상 사례뿐 아니라 근거 부족·상충·설문/영상 차이·완료 의견 우선 사례를 포함한다. 이 문서 작성만으로 자료 제공·검토 일정·정확도 목표가 정해졌다고 보지 않는다.
6. 수정 사항은 해당 지침·규칙·표현 자산의 새 판본에 반영한다. 같은 사례와 영향받는 다른 사례를 재검증하고 최초 AI 결과와 교수 수정 결과를 분리 보존한다. 개발자가 임의 정확도 백분율이나 합격 표본 수를 만들지 않는다.

## 교수 검토 기록 형식

`사례 참조 / 입력·관찰 기준 판본 / AI 최초 유형·근거·반대근거 / 생성 문장·조언 / 교수 의견·수정 이유 / 수용·보류·불수용 / 반영 판본 / 재실행 결과 / 검토자·일자 / 미확인 항목`

AI 결과를 본 교수 의견은 AI 비노출 독립 정답으로 취급하지 않는다. 공개 저장소에는 합성 회귀 사례와 비식별 요약만 저장한다. 모든 발급본에 일괄 수동 승인을 요구하는 운영 규칙은 추가하지 않는다.

## 실행 명령과 완료 경계

신규 [종단 시험](../../backend/tests/test_report_acceptance_v4.py) 1개, 51.733초에 통과했다. 원입력→43개 AI 단계 예약→실제 독립 제출/공개→AI 최종 발급→명시 완료 의견·D39 우선 발급→다운로드·재사용→백업/복원·삭제를 연결한다. 원관찰/문장 공급자 응답·물리 영상 probe·전처리 bytes는 합성이다. 실제 교수 의견으로 오인하지 않도록 fixture를 명시했다. 관련 개별 RP의 세부 경계와 시각 검수는 [실행 기록](K-DOG_리포트구현실행기록_v1.0_20261007.md)에 연결한다.

전체 회귀·독립 cold review는 진행 중이다. 실제 공급자용 동의된 사례/예산 및 교수 검토 기록은 미수령·미실행이다. 교수 검토를 받지 못한 경우 ‘기술 검증 완료·교수 검토 대기’로 남긴다. 배포·실운영 활성·고객 자료 발송은 실행하지 않는다.
