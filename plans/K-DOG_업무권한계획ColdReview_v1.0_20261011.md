## 1 검토 기준

사용자 2026-10-11 결정에 대해 계획의 누락·모순·불필요한 확대·허위 완료·기존 자료 파괴 위험을 검토한다. 모든 일반 계정의 동등 업무, 개발자의 설정+전체 업무, 소유/배정/승인 제거, 동의 거절/철회/삭제요청 워크플로 제거, 실제 행위 기록을 기준으로 한다. 미수령 평가 규칙·원본을 만들어 권한 제거를 구현한 것처럼 표시해서는 안 된다.

독립 reviewer는 초안 작성자와 다른 에이전트로 지정한다. 구현은 수행하지 않으며 필요한 code discovery는 Graft를 사용하고 조사 기준 HEAD의 정확한 범위를 확인한다. 현재 U08 로컬 변경은 이번 diff와 검증 근거에서 제외한다.
