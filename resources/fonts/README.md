# PDF 글꼴

2026-09-06 Google Fonts 원본을 내려받았다. PDF에 필요한 부분을 임베딩하며 실행 시 외부 글꼴 서버에 접속하지 않는다. 원본 파일과 라이선스를 함께 배포한다.

- `NanumGothic-Regular.ttf`: [Google Fonts Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic), SIL OFL 1.1, [OFL.txt](OFL.txt). SHA-256 `76f45ef4a6bcff344c837c95a7dcc26e017e38b5846d5ae0cdcb5b86be2e2d31`.
- `NotoSansSymbols.ttf`: [Google Fonts Noto Sans Symbols](https://github.com/google/fonts/tree/main/ofl/notosanssymbols), SIL OFL 1.1, [OFL-NotoSansSymbols.txt](OFL-NotoSansSymbols.txt). 원본 `NotoSansSymbols[wght].ttf`의 파일명만 단순화했다. SHA-256 `f7e7e04b4a24b6c78893d50cbfd2b2f6cae49617ab047bfef668d252adb128f7`.

나눔고딕에 없는 ②④는 Noto Sans Symbols로 표시한다. Excel은 글꼴 이름을 지정하며 설치된 글꼴/대체 글꼴로 표시한다. Excel 파일에 글꼴 파일을 임베딩하지 않는다.
