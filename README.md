# K-DOG S1.1

K-DOG는 반려견·보호자 자료의 접수, 설문, 촬영, 독립 채점, AI 분석, 검수와 리포트 발급을 지원하는 운영자용 앱입니다. 현재 개발 기준은 **2026-10-02 통합명세 v1.3 / S1.1**이며 기본 API 판본은 `20261002`입니다. 구현·검증 근거는 [실행 기록](docs/개발반영_20261003/K-DOG_구현실행기록_v1.0_20261003.md), [인수 검증 대장](docs/개발반영_20261003/K-DOG_인수검증대장_v1.0_20261003.md)을 확인하세요.

Forms 자료 가져오기, 카메라별 수신·연결, 실제 구간·사건 기록, 1fps AI용 전처리, 독립 사람/AI 원자료, 계산·판정·의견·최종결과, HTML/PDF 발급 이력, 자체 비교 집단과 연구 내보내기를 제공합니다. 동의·권한·삭제 상태와 결과의 고정 판본을 확인합니다. 실행 버튼을 누르기 전에는 AI 호출이나 리포트 발급을 시작하지 않습니다.

실제 영상 품질·처리시간, 실제 중앙 서버와 촬영 PC 3대의 현장 검수는 [실측 및 확인 후속 대장](docs/개발반영_20261003/K-DOG_실측및확인후속대장_v1.0_20261003.md)에 분리했습니다. 미수령 S1 빈 Excel 양식, 미확정 규칙, 미승인 외부 비교값은 해당 범위만 보류합니다. 합성 검증은 실제 AI 정확도나 연구 승인 근거가 아닙니다.

## 설치와 실행

S1 설치 ZIP은 개발자가 확인한 ZIP과 같은 이름의 `.sha256` 파일로 전달합니다. 기존 GitHub v0.2.0 릴리즈는 구판이며 S1 설치 파일이 아닙니다. ZIP에는 Python과 FFmpeg가 들어 있어 따로 설치할 것이 없습니다. ZIP은 빈 새 로컬 폴더에 풀고 [운영 안내](docs/PILOT_OPERATIONS.md)대로 계정을 만든 뒤 `Start.cmd`로 실행합니다. 기본 계정은 없습니다. 자세한 설치·중앙 서버/3PC 구성·백업·전환은 [운영 안내](docs/PILOT_OPERATIONS.md)를 따르세요.

기본 자료 경로는 `%LOCALAPPDATA%/K-DOG/data`입니다. 자료·영상·키는 프로그램 폴더 밖에 둡니다. **기존 설치는 백업 후 명시적인 S1 초기화가 필요합니다.** 구판 점수·파생 결과를 버리고 원입력과 운영 기록을 보존하며, 구판 점수를 새 판으로 이관하지 않습니다. 새 S1 결과는 초기화 재실행으로 지워지지 않습니다.

개발 실행은 [개발 안내](docs/DEVELOPMENT.md), 작업 순서와 자료 출처는 [S00–S17 계획](docs/개발반영_20261003/K-DOG_개발반영계획_v1.0_20261003.md)을 참고하세요.

배포 ZIP에는 운영 안내·계획·후속 대장이 오프라인 문서로 포함됩니다. 개발용 시험·빌드·실측 스크립트는 포함하지 않습니다. 개발 명령과 시험 근거 링크는 [소스 저장소](https://github.com/syleeVeluga/k-dog-proj)에서 ZIP의 `release.json`에 기록된 commit을 선택한 뒤 확인하세요.
