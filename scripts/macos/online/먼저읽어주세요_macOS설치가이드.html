시작 전에 세 가지만 준비하세요

  • macOS 15 이상인 Mac — 화면 왼쪽 위 Apple 메뉴() → 이 Mac에 관하여에서 확인하세요. 칩이 Apple M 계열인 Mac을 기본 대상으로 합니다. Intel이라고 나오면 먼저 담당자에게 설치 환경을 확인해 주세요.
  • 인터넷 연결 — 처음에는 필요한 도구를 내려받습니다. 설치 중에는 Mac을 끄거나 덮개를 닫지 마세요. AI 분석할 때도 인터넷이 필요합니다.
  • 맥 로그인 비밀번호 — 준비 도구 설치 중 요청할 수 있습니다. K-DOG 계정 비밀번호는 나중에 따로 만듭니다. 회사 Mac에서 설치 권한이 없다면 관리자에게 요청하세요.

이 배포본은 설치용 ZIP입니다. App Store 앱이나 앱 아이콘을 옮기는 설치 방식과는 다릅니다. 현재 맥 실기기 설치·동작 검증은 아직 완료되지 않았습니다.

압축을 풀고 K-DOG 폴더를 두세요

  1. 받은 kdog-s1-macos-online.zip을 더블클릭합니다. 압축이 풀리면서 폴더가 생깁니다.
  2. 생긴 폴더를 한 번 클릭하고 Return을 누른 뒤 이름을 K-DOG로 바꿉니다. 다시 Return을 누릅니다.
  3. 그 폴더를 선택한 상태에서 Command ⌘ + C를 누릅니다. Finder 위쪽 메뉴에서 이동 → 홈을 선택합니다.
  4. 홈 폴더에서 Command ⌘ + Option ⌥ + V를 함께 누릅니다. K-DOG 폴더가 여기로 이동합니다.
  5. 홈 → K-DOG 폴더를 열고 아래 파일들이 있는지 확인합니다.
K-DOG 폴더
  Install.command     ← 처음 설치할 때
  Start.command       ← 매일 실행할 때
  먼저읽어주세요_macOS설치가이드.html  ← 지금 읽는 안내
  backend / frontend / resources 등

여기서 확인: Install.command와 Start.command가 보이면 맞는 폴더입니다. 내부 파일은 함께 있어야 하므로 두 파일만 바탕화면으로 빼내지 마세요.

이미 홈 폴더에 K-DOG가 있다면 덮어쓰지 말고 담당자에게 업데이트 방법을 확인하세요. 설치를 마친 폴더는 이름이나 위치를 바꾸지 마세요.

준비 도구 Homebrew를 설치하세요

Homebrew는 K-DOG에 필요한 도구를 설치해 줍니다. 이미 Homebrew가 설치되어 있다면 다음 단계로 가세요.

  1. 아래 버튼으로 Homebrew 공식 설치 파일을 받습니다. 이 방법은 Apple M 계열 Mac용입니다.
  2. 다운로드한 Homebrew.pkg를 더블클릭합니다.
  3. 설치 창에서 안내에 따라 계속 → 설치를 선택합니다. 요청하면 맥 로그인 비밀번호를 입력합니다.
  4. 설치 성공 안내가 나오면 닫고 다음 단계로 갑니다. 이 파일은 준비 도구이며 K-DOG 설치는 다음 단계에서 합니다.
Homebrew.pkg 받기 ↗

버튼으로 파일이 받아지지 않으면 Homebrew 공식 홈페이지의 .pkg installer 링크를 이용하세요. 이미 uv·FFmpeg·ffprobe가 설치된 Mac은 이 준비 단계를 건너뛸 수 있습니다.

설치 중 개발자 도구를 설치하라고 나와요

Command Line Tools 또는 개발자 도구 설치 안내가 표시되면 설치를 완료한 뒤 진행하세요. 창이 멈췄다고 생각해 여러 번 설치 파일을 열지 말고, 현재 창의 안내를 확인하세요. 회사 정책으로 막히면 관리자에게 요청하세요.

처음 한 번 · 3 / 5

Install.command를 여세요

  1. 홈 → K-DOG 폴더로 돌아옵니다.
  2. Install.command를 더블클릭합니다.
  3. 글자가 흐르는 터미널 창이 열립니다. K-DOG가 필요한 도구를 받는 과정입니다. 창을 닫지 말고 기다려 주세요.
  4. 아래의 New operator account name이라는 질문이 나오면 다음 단계의 계정 만들기를 진행합니다.

컴퓨터와 인터넷 환경에 따라 설치 시간은 달라집니다. Downloading, Installing, Resolved 같은 글자는 진행 안내입니다. 화면에 Password:가 보이면 맥 로그인 비밀번호를 입력하고 Return을 누르세요. 터미널에서는 입력한 비밀번호가 보이지 않을 수 있습니다.

더블클릭했는데 차단되면? 보안 경고 해결 방법을 확인하세요.

처음 한 번 · 4 / 5

업무용·설정용 계정을 만드세요

설치 창에서 아래 질문이 차례로 나옵니다. 처음 설치라면 두 계정을 모두 만들어 두세요. 계정 이름 예시는 원하는 이름으로 바꿔도 됩니다.

설치 창에 나오는 글자이렇게 입력하세요
New operator account name (Enter to skip):매일 업무할 계정입니다. 예: manager를 입력하고 Return.
새 비밀번호 (12자 이상):본인이 정한 12자 이상 비밀번호를 입력하고 Return. 입력 중 글자나 ●가 안 보여도 정상입니다.
비밀번호 확인:방금 정한 비밀번호를 똑같이 한 번 더 입력하고 Return.
New developer account name (Enter to skip):AI 연결 등 개발 설정을 관리할 계정입니다. 앞 계정과 다른 이름(예: kdogadmin)을 입력하고 위와 같이 비밀번호를 두 번 입력합니다.

설치 완료 표시:

Installation complete. Open Start.command.

이 문구가 나오면 설치가 끝났습니다. 설치 창을 닫아도 됩니다. 기본 아이디·비밀번호는 없으니 만든 계정 이름과 비밀번호를 안전하게 보관하세요.

재설치 중이고 계정이 이미 있다면 이름 질문에서 아무것도 입력하지 않고 Return을 누르면 건너뜁니다. 비밀번호 오류로 설치가 멈췄다면 Install.command를 다시 열고, 앞에서 이미 만든 계정은 건너뛰세요.

설치 후 · 5 / 5

다음부터는 Start.command만 여세요

실행하기

  1. 홈 → K-DOG → Start.command를 더블클릭합니다.
  2. 실행 창이 뜨고 브라우저가 열리면 업무 계정으로 로그인합니다.
  3. 브라우저가 안 열리면 Safari나 Chrome 주소창에 http://127.0.0.1:8000을 입력합니다. 이 주소는 K-DOG가 실행 중인 이 Mac에서 접속할 때 사용합니다.
업무 중에는 실행 창을 열어 두세요.
창을 작게 내려두는 것은 괜찮습니다. 브라우저 탭만 닫으면 K-DOG는 계속 실행됩니다.

종료하기

  1. K-DOG에서 하던 작업을 저장하고 진행 중인 분석이 끝났는지 확인합니다.
  2. Start.command로 열린 터미널 실행 창을 클릭합니다.
  3. Control을 누른 상태에서 C를 누릅니다. Command ⌘ + C가 아닙니다. 종료된 뒤 실행 창과 브라우저를 닫습니다.
로그인은 되는데 AI 분석이 안 돼요

AI 기능은 별도 연결 설정이 필요합니다. 개발자 계정으로 로그인해 개발 설정 → 공급자 키 관리 → Gemini에 담당자가 준비한 API 키를 등록하세요. 키 발급·결제·모델 설정은 담당자에게 확인하세요. 키체인 접근 확인이 표시되면 K-DOG에서 시작한 요청인지 확인하고 허용하세요. 업무 계정에서는 개발 설정이 보이지 않습니다.

막혔을 때, 이 순서로 확인하세요

“개발자를 확인할 수 없음” 등 보안 경고가 나와요
  1. 담당자에게 받은 올바른 파일인지 확인합니다. 이 ZIP은 Apple의 서명·공증을 받은 앱이 아닙니다.
  2. 열기를 시도한 뒤 Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안을 엽니다.
  3. 아래쪽 보안 항목에 방금 차단된 파일이 표시되면 확인 없이 열기 / 그래도 열기(Open Anyway)를 선택하고 확인창에 따릅니다. 이름은 macOS 버전에 따라 다를 수 있습니다.

해당 버튼이 없거나 .command가 문서처럼 열리면 아래 방법을 사용할 수 있습니다. 파일 손상·악성 소프트웨어 경고는 무시하지 말고 담당자에게 확인하세요.

터미널에서 직접 여는 방법

  1. Command ⌘ + Space를 누르고 터미널을 검색해 엽니다.
  2. 아래에서 필요한 두 줄을 선택해 Command ⌘ + C로 복사합니다.
  3. 터미널에 Command ⌘ + V로 붙여넣고 Return을 누릅니다. 이 명령은 1단계처럼 홈 폴더에 K-DOG를 둔 경우입니다.

처음 설치할 때:

cd "$HOME/K-DOG"
bash Install.command

설치 후 실행할 때:

cd "$HOME/K-DOG"
bash Start.command
“Install uv and FFmpeg first”가 나와요

준비 도구를 찾지 못한 상태입니다. 2단계 Homebrew 설치를 완료한 뒤 Install.command를 다시 여세요. 설치했는데도 같다면 Homebrew를 기본 위치에 설치했는지 담당자에게 확인해 주세요.

설치 중 실패하거나, 파일을 찾을 수 없다고 나와요

인터넷 연결을 확인하고 Install.command를 다시 여세요. 이미 만든 계정은 이름 질문에서 Return으로 건너뜁니다. SHA, checksum, hash mismatch가 보이거나 파일이 빠졌다면 ZIP을 다시 받아 새 폴더에 전부 압축 해제하세요. 설치된 폴더의 일부 파일만 교체하지 마세요.

브라우저에 “연결할 수 없음”이 나와요

Start.command를 먼저 실행했는지, 실행 창이 아직 열려 있는지 확인하세요. 잠시 기다린 뒤 주소를 다시 여세요. 실행 창에 다른 프로그램이 포트를 사용한다고 나오면 기존 K-DOG 실행 창을 찾아 종료하세요. 사용하는 프로그램을 알 수 없으면 담당자에게 해당 문구를 전달하세요.

아이디나 비밀번호가 안 맞아요

맥 로그인 비밀번호가 아니라 4단계에서 만든 K-DOG 계정을 입력하세요. 한/영 입력과 Caps Lock도 확인하세요. 기억나지 않으면 담당자에게 계정 비밀번호 재설정을 요청하세요. 자료 폴더를 지우거나 재설치해서 초기화하지 마세요.

키체인 오류가 나와요

처음 키를 등록한 것과 같은 macOS 사용자로 실행했는지 확인하세요. 로그인 키체인이 잠겼거나 접근을 거부하면 담당자에게 잠금·권한 확인을 요청하세요. 키체인의 K-DOG 항목은 임의로 삭제하지 마세요. 삭제하면 이미 저장한 API 키를 읽지 못할 수 있습니다.

담당자에게 전달할 내용: 어느 단계인지, 화면에 보이는 마지막 오류 문구, macOS 버전, Apple M 계열인지 Intel인지 알려주세요. 오류 화면을 전달할 때는 비밀번호·API 키·참가자 정보가 포함되지 않게 가려 주세요.

자료는 어디에 저장되나요?

기본 설정에서는 설치 폴더와 별도로 아래 위치에 저장됩니다. 담당자가 다른 자료 위치를 지정한 경우에는 그 위치를 사용합니다.

~/Library/Application Support/K-DOG/data

~는 현재 맥 사용자의 홈 폴더를 뜻합니다. Finder에서 이동 → 폴더로 이동을 선택하고 위 경로를 붙여넣으면 확인할 수 있습니다.

  • 자료 폴더의 파일을 직접 바꾸거나 지우지 마세요. 자료 보관·이전은 앱의 백업·복원을 이용하세요.
  • 다른 Mac으로 옮길 때 설치 폴더를 복사해 쓰지 마세요. 새 Mac에 다시 설치하고 자료를 복원합니다. AI 연결 키도 새 Mac에서 다시 등록합니다.
  • 업데이트 파일을 받았다면 기존 폴더에 바로 덮어쓰지 말고 담당자가 안내한 백업·교체 순서를 따르세요.
