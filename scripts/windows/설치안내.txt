K-DOG 설치 안내

준비물: 이 ZIP 파일, 그리고 ZIP과 다른 경로(문자·전화 등)로 받은 발행 키와 SHA-256 값

1. ZIP 확인: ZIP이 있는 폴더의 빈 곳에서 Shift+오른쪽 클릭 → "PowerShell 창 열기"(또는 "터미널에서 열기")를 누르고
   Get-FileHash .\받은파일이름.zip 을 입력합니다. 표시된 Hash 값이 함께 받은 SHA-256 값과 같은지 확인합니다. 다르면 설치하지 말고 문의하세요.
2. 압축 풀기: ZIP을 오른쪽 클릭 → "모두 압축 풀기"를 누릅니다. ZIP 안에서 바로 실행하지 않습니다.
   (보안 경고가 나오면 ZIP 파일 속성에서 "차단 해제"를 체크한 뒤 다시 압축을 풉니다.)
3. 설치: 압축을 푼 폴더의 Install.cmd를 더블클릭합니다. "Windows의 PC 보호" 창이 나오면 "추가 정보" → "실행"을 누릅니다.
4. 키 입력: 발행 키(KDOG-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX)를 입력하고 Enter를 누릅니다. 대소문자와 하이픈은 상관없습니다. 키는 설치할 때 한 번만 입력합니다.
5. 실행: 설치가 끝나면 바탕화면의 K-DOG 아이콘을 더블클릭합니다. 검은 실행 창이 뜨고 잠시 뒤 브라우저가 열립니다. 전달받은 아이디와 비밀번호로 로그인합니다.
6. 종료: 실행 창을 닫으면 K-DOG가 종료됩니다. 작업하는 동안에는 창을 닫지 말고 최소화해 두세요.

설치가 끝난 뒤에는 압축을 푼 폴더와 ZIP을 지워도 됩니다. 자료는 따로 보관됩니다.
